## Why

AFP 聊天目前主要展示工具名称和后台任务句柄，缺少可理解的精筛依据、通过数量与失败反馈。胶囊悬浮背景会透出底下文字，思考行立即锁高也截断了收起动画，影响阅读与操作。

## What Changes

- AFP 胶囊悬浮使用现有主题的不透明背景，取消模糊效果。
- 聊天展示任务启动说明、真实后台进度、保存报告的分类计数与最终选图依据；请求失败不计为视觉淘汰。
- 相同报告的重复读取合并呈现，保留原始工具记录供检查。
- 修正思考行收起布局，沿用共享折叠组件的退出、快速反转和减少动态效果行为。
- 补充离线行为测试、会话输出快照、浏览器验证及上游集成保护说明。

## Capabilities

### New Capabilities

- `afp-visual-review-feedback`: AFP 会话反馈区分启动、运行、保存报告与最终选图，且只展示可追溯事实。
- `conversation-disclosure-motion`: 聊天折叠内容展开与收起均保持连续布局过渡。

### Modified Capabilities

无。仓库尚无归档后的主规格。

## Impact

涉及 AFP 的 Host 报告摘要、工具说明、Client 呈现、本地化与 CSS，以及 ui-chat 思考行布局。保留工具名称、现有报告字段、像素硬规则、权限、收藏夹确认和共享折叠接口；不修改 Agent 循环、发布版本、远程 Tags 或 Release。新增摘要字段通过现有工具结果与 AFP 本地结果记录保存，不新增 Session 事件类型。
