## Context

工作台使用 DSH 原生组件和语义 token。收藏夹页已有两列布局，但图库与详情一起滚动；图片只有失败占位，没有逐图加载骨架。账户表单仅读取凭据状态。AFP-Image 的 docs/api/01-auth.md 与缓存 chunk-WMPAI33C.js 给出了只读 user 查询及 credit.amount；已有选集适配可接受多种容器，但未按媒体类型区分。

## Goals / Non-Goals

**Goals:** 展示真实账户资料与积分；让收藏夹可折叠、独立滚动并保留详情；提供图片加载、选择、大图预览和可诊断错误；保持凭据保护与原有写入确认。

**Non-Goals:** 修改 AFP-Image、管理员操作、购买与下载原图、移除远端内容、浏览器自动化或新增共享 UI 原子组件。

## Decisions

1. 新增 Host account-profile 只读操作，复用 Connection 的认证与部署 Hub 地址，只允许姓名、邮箱、登录名、客户 ID、积分、计费条件及必要权限标志离开 Host。缺失金额显示未知，不转换成零；独立请求失败不影响表单或令牌成功状态。
2. 桌面收藏夹分为可折叠导航、固定标题下的可滚动图库、独立滚动详情；窄屏恢复纵向排列。折叠通过 grid 列宽过渡，隐藏导航禁止键盘进入。图库超过半屏滚动距离后显示回到顶部，减少动态效果时立即滚动。
3. 图片使用受保护的同源代理，不把 AFP 令牌或签名 CDN URL交给 Client。加载使用骨架、完成后淡入，失败可重试。详情图片通过项目 Modal 查看预览图；预览不调用购买或下载接口。
4. 只读选集解析区别图片与明确非图片条目，保留未知媒体类型的旧数据兼容；只读图片页的异常元数据不破坏整个选集。写入执行仍使用原有全成员校验。
5. 预览以字节签名确认支持的光栅格式，限制 Accept 与此一致；允许有效图像的通用二进制 Content-Type，仍拒绝 HTML/SVG。重定向释放前一响应，维持精确主机白名单和跨 CDN 去认证头。白名单错误仅暴露安全主机名与固定代码。

## Risks / Trade-offs

- AFP API 返回字段或权限不同 → DTO 按白名单投影；空字段显示未知，保留独立重试。
- CDN 域名没有配置 → 提供准确错误与配置入口，保持严格白名单，不能为了加载图片放开任意公网 URL。
- 长列表图片请求过多 → 可见图片按需请求；取消、重试和卸载释放资源，避免过期响应覆盖新图片。
- 服务端 JavaScript 缓存 → 本地发布验证哈希后使用 --no-open 重启，手动验收保持在用户侧。

## Migration Plan

保存本轮源码基线，构建 Client、验证聚焦回归及资源后同步本地安装目录。只读操作是加法，不改变已存 run/plan 和凭据。回退恢复对应源码与发布文件，再重启支持的 dsh web profile。

## Open Questions

实际账户授权范围和预览 CDN 主机只能在已认证环境确认；无法取得时展示真实失败，不填充示例数据。
