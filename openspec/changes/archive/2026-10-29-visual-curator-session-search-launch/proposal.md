## Why

“按此画像找图”目前要求先建立输出用途、填写尺寸并再次检查任务，随后只启动插件内部作业，无法直接进入选定工作区中的原生会话。用户已确认默认保留原图，需要以少量输入完成数据准备、新会话创建和真实执行。

## What Changes

- 新增简易启动弹窗：选择原生工作区，预填可修改的找图需求和数量，默认保留原图；仅选择尺寸时展开用途预设。
- 新增 Host 持有的可恢复启动操作，固定当前画像、数据包、任务参数、目标工作区及原生会话身份。
- 复用原生 Session 创建、命名、文件附件及首条消息受理能力；一次明确启动创建一个新会话，重复请求继续同一操作，不覆盖其他草稿。
- 画像数据包匹配当前版本时复用，否则自动生成；通过原生文件附件传入，首条指令只包含任务目标、固定版本与执行要求。
- 增加原图找图和交付路径，检索、去重及实际像素复核后保留原始文件；指定尺寸时继续复用现有裁剪和裁后复核。
- 原生会话与插件任务相互关联，展示进度和结果，停止本次找图联动会话及相关后台作业，保留已完成结果。
- 保留既有工具调用、显式用途裁图与历史 Run 的解读方式；不更改全局模型、权限或已有数据包格式。

## Capabilities

### New Capabilities

- `visual-curator-session-search-launch`: 简易表单、原图模式、冻结材料、工作区会话创建、启动去重与恢复、进度及停止联动。

### Modified Capabilities

无已归档规范需要修改；本变更独立于已完成的画像分析、上下文及数据集工作区变更。

## Impact

主要影响 Visual Curator 的任务解析、搜索与交付、Host 作业编排、原生能力适配、Client 工作台和任务弹窗、工具说明、类型与测试。原生 Session、Workspace、附件和 Jobs 使用已公开的服务接口；如发现接口缺口，先在设计中明确最小扩展及消费者，再改动其拥有包，不复制核心实现或修改 Agent loop。
