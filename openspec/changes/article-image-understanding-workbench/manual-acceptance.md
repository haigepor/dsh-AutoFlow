# 第一期人工语义验收

AC-25 由用户手动执行，本文件是操作与记录模板，不是通过报告。自动测试、浏览器流程和安装验证的结果见 [verification.md](verification.md)。不需要接入真实生图。

## 1. 准备

1. 保留当前 profile 数据目录；升级格式及回退步骤见[升级说明](../../../docs/upgrade-guide/v0.2.0-rc.2/article-image-workflow/guide.zh.md)。
2. 在 profile 的 `article-image` Cordis 行配置 `analysis.provider` 和 `analysis.model`，使用已经接入 DSH 的模型；有图文章需模型支持图像输入及附件服务。无需向文档或聊天粘贴密钥。
3. 检查工作台浏览器与模型就绪状态。生产抓取不复用登录浏览器，不支持登录/付费/验证墙；仅选择获准访问的公开文章。
4. 通过公开 Google 表格只读导入六篇代表文章，覆盖实际站点模板，并至少包含长文、多语言、有图、无图、列表/表格及具体事实限制；一篇可覆盖多个类型。
5. 在运行前人工记录每篇正文边界、主要章节、关键事实和原图清单，作为独立基准。不能仅用提取结果给模型自评。

## 2. 操作与判断

1. 点击获取并分析，核对正文顺序、尾段、表格/列表、图注、署名及全部原图。未知站点范围需要核对后开始分析；已知缺图/缺段应修复适配器或重抓，不能直接批准绕过。
2. 查看理解稿的主旨、结构、事实证据、限制、疑点和文图关系，点来源引用定位，确认尾段的重要限制没有遗漏；确认模型输入中确有实际原图。
3. 检查封面是否表达主旨、正文图是否各有信息目的；数量不足应有原因，不能重复凑数。概念示意不能被描述成实际事件证据。
4. 阅读每条最终提示词，确认主体、动作、环境、构图等自足，与画面字段及原文事实一致；不得依赖未提供的上文。
5. 需要修改时编辑卡片并重新核对提示词同步，保存后再次审核。审核只保存批准，不应出现生图、上传发布或表格回写。
6. 出现事实捏造、关键限制丢失、错误引用、漏图/漏章或无依据场景时退回，修正规则/适配器后对相同样例重新运行。风格满意不能抵消这些失败。
