## Context

当前找图依次取图库条目、获取原图、导入、初筛和终审。真实 Run 中两个条目经 lookup 后仍无原图，没有发生下载；另有初筛通过后终审待复核和终审不通过的图片。交付函数在合格数为零时直接返回，启动提示却只给预计目录。聊天卡片只解析工具返回的 runId，工作台仅展示已评估图片。

## Goals / Non-Goals

目标是提供可复现的错误分类、真实实时数量、紧凑原生工具卡和当前会话右上角任务胶囊。验收覆盖历史数据、会话切换、断线、关闭、窄容器和键盘。保持固定规则、预算、最终复核和资源授权；不改变运行数据，不重启用户任务，不增加外部付费调用。

## Decisions

1. 图库通过显式字段声明不可提供原图；已知受限条目不重复 lookup。搜索 checkpoint 保存仅含候选 ID、阶段和安全错误代码的诊断，不保存临时 URL。旧 checkpoint 缺少新字段时使用空列表；旧通用警告保留原文，不推断历史授权。
2. Run 投影从每张图最新阶段的 assessment 和 selection 推导分类，包含已导入但尚未评估的图片。初筛通过不能计入最终合格；失败和未知分开；分页不改变总数。
3. 仅从交付 manifest 返回实际目录。启动提示明确零合格不创建目录，Agent 通过 run-get 读取回执后才能查找交付文件。
4. 对话观察使用插件独立、按 Session 和 Run 分区的 store，不切换工作台的作用域。注册注入 hooks 提供快照，观察期间读取已有授权 run-get；最后一个观察者关闭后取消读取。断线使旧代失效，保留已确认数据并显示重连状态，旧响应不能写入新会话。历史卡片读取持久结果，不触发任务、媒体下载或模型。
5. 工作台复用现有任务列表、原生 StateDot、Tag、Button 和结果网格；增加明确分类、技术诊断和分类空状态。工具卡使用同一分类与本地化文案，原始返回可展开。
6. ui-conversation 声明通用 `conversation.body.overlay` Session 插槽，位于 body 内且在滚动层之外。TodoPanel 从 input.dock 移入该插槽；侧边空白建立 inline-size 容器，胶囊查询最近容器，在宽度不足时隐藏，避免跨 CSS Modules 的局部容器名称不匹配。定位不依赖生成类名或浏览器窗口；多会话依靠原生 Session 席位隔离。

## Risks / Trade-offs

- 历史记录只有通用警告：保留原始诊断，不能事后声称 Plus 或网络失败。
- 工具卡多实例重复观察：一个 Session/Run 共享读取，引用计数清理并按配置间隔轮询；终态停止自动读取。
- 胶囊遮住正文：限制宽度、放在正文侧边空白，容器不足隐藏，展开内容限定高度并独立滚动。
- 共享文件混有其他会话工作：实施前文本副本保留于 Temp，提交按前后差异叠加到 HEAD 独立候选，完成候选检查后提交。

## Migration Plan

不改变 Session 格式或既有记录版本；新增 checkpoint 字段可选。部署重建客户端和 Host，旧任务按已有固定参数继续。回滚仅还原本变更提交的差异，不删除用户 Run、交付文件或前序共享修改。
