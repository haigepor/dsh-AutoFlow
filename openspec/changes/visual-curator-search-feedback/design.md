## Context

当前找图依次取图库条目、获取原图、导入、初筛和终审。真实 Run 中两个条目经 lookup 后仍无原图，没有发生下载；另有初筛通过后终审待复核和终审不通过的图片。交付函数在合格数为零时直接返回，启动提示却只给预计目录。聊天卡片只解析工具返回的 runId，工作台仅展示已评估图片。

## Goals / Non-Goals

目标是提供可复现的错误分类、真实实时数量、过程外的会话唯一任务卡和当前会话右上角任务胶囊。验收覆盖历史数据、会话切换、断线、关闭、窄容器和键盘。保持固定规则、预算、最终复核和资源授权；不改变运行数据，不重启用户任务，不增加外部付费调用。

## Decisions

1. 图库通过显式字段声明不可提供原图；已知受限条目不重复 lookup。搜索 checkpoint 保存仅含候选 ID、阶段和安全错误代码的诊断，不保存临时 URL。旧 checkpoint 缺少新字段时使用空列表；旧通用警告保留原文，不推断历史授权。
2. Run 投影从每张图最新阶段的 assessment 和 selection 推导分类，包含已导入但尚未评估的图片。初筛通过不能计入最终合格；失败和未知分开；分页不改变总数。
3. 仅从交付 manifest 返回实际目录。启动提示明确零合格不创建目录，Agent 通过 run-get 读取回执后才能查找交付文件。
4. 对话观察使用插件独立、按 Session 和 Run 分区的 store，不切换工作台的作用域。注册注入 hooks 提供快照，观察期间读取已有授权 run-get；最后一个观察者关闭后取消读取。断线使旧代失效，保留已确认数据并显示重连状态，旧响应不能写入新会话。历史卡片读取持久结果，不触发任务、媒体下载或模型。
5. 工作台复用现有任务列表、原生 StateDot、Tag、Button 和结果网格；增加明确分类、技术诊断和分类空状态。工具卡使用同一分类与本地化文案，原始返回可展开。
6. ui-conversation 声明通用 `conversation.body.overlay` Session 插槽，位于 body 内且在滚动层之外。TodoPanel 从 input.dock 移入该插槽；侧边空白建立 inline-size 容器，胶囊查询最近容器，在宽度不足时隐藏，避免跨 CSS Modules 的局部容器名称不匹配。定位不依赖生成类名或浏览器窗口；多会话依靠原生 Session 席位隔离。
7. 完整找图卡片注册到已有 `conversation.body.overlay`，order 为 30，位于默认 order 为 0 的原生任务胶囊下方。共享容器纵向排列并限制在 body 内，胶囊展开时自然推开后续卡片；找图卡使用同一主题菜单材质、边框阴影和最小 280px 侧边空白显示条件。工具过程仅保留本地化回执及原始调用检查。轻量 `conversation-runs` 读取要求有效 Session grant，按创建时间列出该会话未隐藏的 search/crop，不返回图片或配置；所选 Run 才读取预览。按 Run 身份去重并独立切换，不把搜索与裁剪子执行的计数混加。目录观察随原生快照订阅建立和释放，终态 Run 停止轮询，目录状态变化可重新读取外部恢复的任务。展开使用已有 AnimatedCollapse，选择使用已有 Menu/SelectField。

## Preview search and compact task feedback

新启动默认显式 `output.kind: preview`，原图与用途输出仍独立可选，已受理任务保留原输入。预览模式仅接受 Unsplash，通过来源返回的常规公开预览 URL 复核，不请求原图、不裁剪、不创建交付目录。来源 ID 和页游标持久化，临时媒体 URL 不进入 checkpoint；恢复时按预算重新解析来源位置。原生模型服务可能获取预览像素用于分析，不能把预览审核声明为原图核验。

Agent 从所选数据集当前启用规则和备选组提出预算内的英文检索词，Host 固定其余参数。worker 每个检索词轮流处理一张候选，避免首个宽泛查询或原图超时阻塞其他召回。终审同时覆盖来源阶段与最终阶段规则。未知权重全部满足仍不能达到比例时判不匹配，其他未知结果保留待复核；不提高置信度或放宽原阈值。来源链接去重不代表像素去重，现有参考图采样策略保持不变。

会话停止和独立后台 Run 停止保持各自语义。卡片提供“停止任务”，有启动记录时停止整个启动及关联 Run，否则只取消选中的授权 Run。目录与详细投影带修订号，较旧的运行状态不能覆盖已确认终态。正在取消继续读取真实状态，不伪造已停止。

任务顶部只保留身份、状态、目标进度、操作和结果分类。需求、次要数量、结束原因、交付及候选诊断放入同一原生 Menu；存在结构化诊断时不重复显示旧警告。终态不显示过期处理阶段。预览结果改称“预览匹配”，提供公开预览操作，隐藏裁剪和原图交付提示。范围内继续复用现有 token、Menu、Button、Tag、Modal 和响应式容器规则。

项目代码回归使用实际 Run 引擎、来源适配器、视觉提供方、存储及会话观察器，只替换外部响应。浏览器 fixture 使用实际原生组件，并保存紧凑布局、菜单键盘和窄屏的预期输出；此证据不等于真实图库的风格效果验证。

## Risks / Trade-offs

新建找图启动显式选择已生成的数据集。数据集目录在分页前按素材集、模型画像和共享库访问类型筛选，只返回带实际 exportId 的成品；弹窗独立读取这些轻量元数据，不改写数据集页面的筛选。启动将 datasetId 固定在原始请求和 Launch 中，在创建会话前核对所属账户、访问范围、画像与分析身份、必要文件、校验和及包内画像摘要。新启动不再自动生成或换包，未知回执及重试继续使用同一请求。已保存输入的 datasetId 保持可选，因此旧记录解析和请求摘要不变；只有新的首次受理要求该字段，原有准备流程可继续恢复。查看或生成数据集只暂时隐藏弹窗，返回找图时复用同一表单实例并刷新数据集选择。

工作台的找图启动摘要以紧凑入口并入顶部素材集选择区，不在内容区域独占一行。入口展示状态及真实数量，使用原生 Menu 展开完整摘要、目录和现有操作；弹窗继续直接展示完整摘要。尚无 Run 时显示目标数量，已停止使用中性状态，结果不足、待确认及错误分别提示。图库导入和数据集保留原来的后台卡片，启动、重试和停止沿用同一 Store。

搜索和裁图的目标进度直接读取 resultSummary，避免重复展示 qualified；始终保留全部结果、最终入选、待复核和当前分类，其余零数量分类不占用按钮位置。结果网格使用 200–224px 的有界小卡片，移除单张或两张时放大的规则，保持完整比例预览和详情弹窗；此调整不改变任务、筛选和分页请求。

卡片的数量区突出最终入选，其余数量使用同一行的紧凑列；需求只显示一次，原生 Tag 表达状态和图片分类，零值技术诊断不占行。左侧 separator 通过 pointer capture 调整卡片自身宽度，右边缘固定；280–640px 范围同时受所属会话尺寸限制。宽度仅由当前会话的组件状态持有，拖动不修改正文宽度或重新建立任务观察。共享 overlay 外层继续检测侧边空白，内部使用按内容宽度排布的纵向列，原生任务胶囊保持最大 300px 并靠右；因此找图卡可独立向左扩宽。键盘、双击恢复及取消手势由同一尺寸规则处理。

- 历史记录只有通用警告：保留原始诊断，不能事后声称 Plus 或网络失败。
- 工具卡多实例重复观察：一个 Session/Run 共享读取，引用计数清理并按配置间隔轮询；终态停止自动读取。
- 胶囊遮住正文：限制宽度、放在正文侧边空白，容器不足隐藏，展开内容限定高度并独立滚动。
- 共享文件混有其他会话工作：实施前文本副本保留于 Temp，提交按前后差异叠加到 HEAD 独立候选，完成候选检查后提交。

## Migration Plan

不改变 Session 格式或既有记录版本；新增 checkpoint 字段可选。部署重建客户端和 Host，旧任务按已有固定参数继续。回滚仅还原本变更提交的差异，不删除用户 Run、交付文件或前序共享修改。
