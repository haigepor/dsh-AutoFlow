## Context

本文件定义第一版拟实现行为，当前尚无该插件源码。[proposal.md](proposal.md) 说明范围；[data-model.md](data-model.md) 是字段、引用和状态的唯一详细定义；能力规范定义可观察要求；[acceptance.md](acceptance.md) 将要求映射到实施验证。

当前 [自定义 bundle 机制](../../../custom-plugins/architecture.md) 已支持独立包、Host 操作、Agent 工具和 Client 入口。[AFP](../../../custom-plugins/workspace/dsh-plugin-afp/README.md) 可提供工作台及检查点模式的参考，但固定类别审核和来源私有模块不能成为新插件的隐式依赖。[存储域](../../../packages/storage/storage-domain/README.md) 提供校验后的持久记录；[jobs](../../../packages/jobs/jobs/README.md) 提供进程内任务控制，并不提供跨重启继续执行。

## Goals / Non-Goals

**Goals:**

- 用户能从正反参考图建立可确认的风格，发布固定版本，并让搜图与裁图使用完全相同的规则和样例版本。
- 用户能纠正单图、单个维度及裁剪区域，系统保存上下文、人工来源与修订关系，下一版采用经确认的反馈。
- 第一版完成导入、校准、发布、搜索、裁剪、复核、反馈、版本对比和数据导出的闭环，所有长任务可取消且可从已提交检查点恢复。
- 每次决策可追溯到实际图片、规则、模型、提示词和程序检查；执行失败与审美拒绝分开，允许未知及人工复核。

**Non-Goals:**

- 不微调模型、不生成图片、不扩图、不去水印、不购买素材、不写远端收藏夹，不提供通用模型训练调度。
- 不要求 Embedding、向量数据库、SAM、Python、GPU、FiftyOne 或 Label Studio；第一版不实现任意站点爬取、任意 JavaScript 请求脚本或多用户团队权限系统。
- 不修改 AFP 行为、核心循环、现有 Session 事件格式或 SDK；不自动重写已有 profile 的插件选择，不自动写 Home 级 AGENTS 或 Skills。

## Decisions

### D1. 一个独立 bundle 和一个 Host 业务服务

实施位置为 `custom-plugins/workspace/dsh-plugin-visual-curator/`。保持一个包，内部区分领域记录、素材处理、图片来源、视觉适配、流程、Client 和测试。插件声明 Service Definition、内置 Provider 和 Client/Agent Consumer；只有需要独立替换的图片来源及视觉适配使用注册接口，不为每个流程再拆包。

Host 统一处理校验、存储、发布、任务、下载与模型调用；Client 和 Agent 共享相同业务入口。所有注册随 Cordis effect 卸载；依赖缺失时明确报告，不能仅凭插件 mention 声称工具可用。CLI 把本独立包声明为生产依赖，Desktop 与 AFP 使用相同的自定义包打包清单。Web/Desktop 新 profile 默认启用；已有 profile 保留原 bundle 列表，并在插件管理器展示随应用携带的版本，无需另装 profile 副本。停用选择跨重启保留，headless/SDK/ACP 默认列表保持原状。

选择独立包而非扩充 AFP，可接入用户提供的来源且避免继承 AFP 固定分类。第一版不从 AFP 的 `src/vendor` 或私有 Store 直接导入；AFP 来源集成留给另一次明确变更。

### D2. 风格、用途与任务分别保存，执行前显式解析

风格描述视觉偏好；用途预设描述比例、像素、安全区域及处理约束；任务描述本次题材、数量和预算。Host 的解析步骤先校验冲突，再生成不可变 `RunSpec`，启动后的流程只读取该快照，不能在循环中查询“最新版本”。

规则分为 `required`、`preferred`、`reference-only`，并指定题材/用途适用条件及 `source` 或 `final` 检查阶段。用途安全区使用成图上的归一化矩形；它表达区域内避免明显视觉干扰的要求，不要求背景纯色，也不等于主体检测结果。

本次任务可以进一步限制题材、数量、预算和用途，但不能静默放宽已发布的 required 规则。相互冲突时在远程请求前返回 `constraint-conflict`；用户修改草稿并发布、修改用途或明确创建新的任务条件后再开始。

### D3. 发布是可恢复的提交，默认选择是另一次操作

`StyleDraft` 可修订，`StyleRelease`、`UsageRevision` 和 `EvaluationRecipe` 不可变。风格发布固定规则、样例角色及维度、审核配置、候选/评估记录摘要，号码在同一风格内单调增加。修改审核器也创建新 release，允许规则摘要相同而审核器版本不同。

校准时先生成不可变 `StyleCandidate`，固定草稿修订、规则、样例和 recipe；评估可以比较已发布 release 与 candidate，不需要提前发布待评估内容。发布前校验 required 规则均有人确认、引用资产可读取、分歧已处理、输入修订号未变化，评估报告必须匹配同一 candidate 摘要；稀少样例可发布 `provisional` 版本。`evaluated` 标记只说明完成了所声明的评估，不承诺已达到未配置的质量指标；原始指标与接受结论分别保存。

存储使用现有 storage domain，不假设存在跨表事务或多进程 CAS。一个 profile 的本插件数据只允许一个 Host writer，第二个进程在读取写入能力前报告占用。Host 对同一 aggregate 串行写入并检查 `expectedRevision`。先保存不可变依赖，最后原子替换单个 aggregate manifest；只有 manifest 引用的提交可见，失败遗留依赖不可作为已发布版本。重复操作按 operationId 恢复原提交；相同 operationId 携带不同请求摘要时拒绝。

发布不会自动替换默认版本。切换默认和回退默认都校验 profile、风格及目标 release；旧任务继续原快照。第一版只归档，不提供级联删除，避免清除仍被 release、反馈或数据集引用的资产。

### D4. 导入意图与视觉观察分别确认

```mermaid
flowchart LR
    A[本地文件或上传] --> B[检查并保存原文件]
    B --> C[规范化图片与摘要]
    C --> D[样例角色和参考维度]
    D --> E[逐图观察]
    E --> F[归纳规则及例外草稿]
    F --> G[人工校准与分歧处理]
    G --> H[发布固定版本]
```

支持 JPEG、PNG 和静态 WebP；其他格式及动画明确拒绝。部署配置限制批量数、单文件字节、解码像素、边长和总存储。每项独立提交，混合批次保留成功项并列出逐项失败，不将整批显示为全部成功。相同字节复用 blob，但图片来源、样例角色和用途关系独立保存。

逐图观察保存文件事实、模型估计及 `unknown`，不能把估计值写成程序测量。正例可只参考色彩，反例可只针对构图；未选择的维度不生成监督标签。导入角色/维度的明确确认产生同一来源的 HumanFeedback，Reference 读取有效反馈投影，不能另存一套冲突标签。用户选择“整体正例”表示整体偏好，推导出的细项仍是建议。

归纳请求只使用当前草稿纳入的学习样例和适用反馈，逐条返回支持/反例引用及待确认例外。图片中文字、标题和说明属于待分析内容，不作为操作指令；题材、主体及画面判断需要像素依据。冲突可通过缩小条件、增加例外、拆成不同风格或保留为 reference-only 处理；未解决的 required 冲突不能发布。

初期人工挑选代表正例和易混淆反例，按稳定顺序组成有数量/字节限制的 `ReviewBundle`；不依赖向量检索。任务先固定完整样例快照，再将每次实际发送的子集、图片处理版本和摘要写入辅助模型请求记录，不能从后来编辑的样例库重建。

### D5. 反馈自动入库，发布控制新标准何时生效

人工确认入口来自经过身份验证的 Client 操作，Host 从调用上下文生成操作者来源，忽略外部提供的“human”声明。Agent 可提交建议，不能调用接口把建议提升为人工标签。快捷反馈包括风格接受/拒绝、仅本次不需要、不确定及裁剪接受；详细维度、原因和规则修改建议可选。

反馈默认只作用于当前对象和任务；明确选择“纳入当前风格”才可用于该风格下一版。题材不符、用途不适配和本次不需要分别记录，不能自动变成风格反例。规则修改建议保持待确认；确认影响维度和条件后才加入草稿，正在使用的 release 不改变。

一次改判保存新记录并替代当前反馈头，旧记录不覆盖；并发改判携带相同旧头时只有一次成功，另一次收到可恢复冲突。没有明确裁剪完成确认的拖动、浏览、下载、沉默或普通“接受本批结果”不生成风格/理想裁剪监督。偏好比较只在同一风格、用途和明确比较题材下成立，允许 A、B、平局、均不合适或无法判断。

复核队列优先显示 unknown、规则分歧、缺失类别和新视觉类型，同时按配置抽取普通通过/拒绝项。反馈只描述当时看到的图片版本；预览判断不能被自动升级为原图质感判断。

### D6. 搜图使用固定标准，并保留可通过裁剪改善的候选

| 顺序 | 输入与动作 | 已提交输出或停止条件 |
| --- | --- | --- |
| 1 解析 | release、usage、题材、数量、来源及预算 | 固定 RunSpec；缺引用、冲突或能力不符则不启动远程 I/O |
| 2 规划 | 题材生成有限查询，参考风格只生成接口可表达的修饰词 | 固定 QueryPlan；规划与实际请求分开记录 |
| 3 召回 | 每个查询首屏省略 cursor，后续只用该查询返回的 cursor | 先提交页面候选、下一 cursor 和预算消耗，再前进 |
| 4 初筛 | 来源 ID/字节摘要去重、尺寸及可读性检查、可选近似指纹提示 | duplicate、unusable、pending-original 或待视觉审核 |
| 5 原图审核 | ReviewBundle 和足以判断的真实图片像素 | required 分项、偏好、unknown、crop-potential，保留依据 |
| 6 成图流程 | 用途要求裁剪时调用 D7；无需裁剪也检查最终可交付版本 | 最终图审核及可用/拒绝/待复核 |
| 7 排序补图 | required 全通过且无阻塞 unknown 的成图按已发布偏好权重排序，稳定 ID 破同分 | 仅 distinct 已合格结果计数，不足时继续预算内查询 |
| 8 收尾 | 到达数量、来源耗尽、预算用尽、停止或失败 | 保存结果、逐阶段计数、停止原因与未处理候选 |

第一版提供一个配置化 HTTP JSON source Provider。配置包含 HTTPS endpoint、GET/POST、受限 query/cursor/pageSize 请求映射、凭据引用及响应字段 JSON Pointer；不执行表达式、脚本或模型提供的 URL。响应映射必需 items、稳定 providerAssetId、previewUrl，原图 URL/可访问标识与尺寸允许缺失但不能据此宣称可交付原图。nextCursor 为字符串或 null；空/重复游标、缺失必需字段或越界页量作为来源协议错误，停止该查询并记录原因。

第一版不实现付费原图获取。缺少原图或足够像素的可交付素材可以预览和标记，但不能计为满足目标尺寸的结果。参考图检索和向量重排留给后续；第一版只保证在当前来源已召回的候选中审核，不能声称检索了完整图库。

签名媒体地址只在请求期间驻留内存；可配置按 providerAssetId 刷新媒体定位的受限 lookup 请求。来源声明是否支持刷新；不支持时，恢复只能继续已保存字节的候选，未下载定位失效项标为 media-unavailable 并保留原因，不能伪装为风格拒绝或静默重搜首屏。

源码级 required 失败可拒绝；最终构图、留白、主体占比不理想但可能裁剪改善时保留。模型拿不准时进入复核，不将网络/解析失败转换为审美拒绝。required 通过后使用 recipe 固定的有限分项评分和权重排序；缺少必要评分则复核，不能用总分抵消 required 失败。

### D7. 裁图先生成合法区域，再审核真实成图

输入必须包含已保存的图片版本、固定 release、用途快照、需要保留的对象及预算；支持独立裁图，也支持搜索流程内调用。Host 先确认源像素/方向、目标比例和最小像素，再由视觉模型分析主体与环境关系、保护对象及裁剪可行性。

模型提出有限候选区域和可核验的简短理由，不能直接提交文件。内部坐标统一为规范化方向图片上的 `[0,1]` 左上角加宽高；Host 按 [数据模型](data-model.md) 转换、约束比例和像素。程序可在合法范围内确定性调整窗口以满足比例，但必须记录调整前后区域并审核最终实际成图。越界、非有限数值和负面积拒绝，不静默夹成另一个构图。

| 阶段 | 检查内容 | 结果 |
| --- | --- | --- |
| 可行性 | 是否存在满足比例、最小像素和必要主体的区域 | feasible、infeasible 或 needs-review |
| 候选 | 保环境、突出主体、留用途空间等不同区域 | 保存候选而非宣称合格 |
| 几何 | 原图方向映射、整数区域、比例、输出像素、无放大 | 程序验证结果；不满足则拒绝该候选 |
| 成图 | sharp 实际生成并保存派生版本 | 摘要、父图、recipe、区域、处理版本 |
| 视觉复核 | final 规则、主体完整、空间感、安全区；必要时同时提供原图 | pass、reject 或 needs-review，技术失败独立保存 |
| 选优 | required 通过后按同一 recipe 排序；有限重试仍无候选则结束 | 可用、需人工或不可合理裁剪 |

比例用约分后的整数 p:q。裁剪区域采用整数 `p*k` × `q*k`，选择不越过有效源区域的 k，输出尺寸也必须符合 p:q；第一版不允许上采样。安全区坐标以最终成图为准。模型坐标解析正确不等于主体保留已通过，保护对象的视觉不确定进入复核。

人工拖动先产生未确认预览，确认后生成新派生版本并进行几何/成图复核；明确“保留人工版本”可保存有警告的选择，但程序不将其计为自动合格。用户另行选择“可纳入裁剪样例”才生成学习反馈。取消或关闭预览不生成理想裁剪标签。

例如 3840×2160 横图在 9:16 下最多保留 1215×2160 区域；若两个必要主体不能同时容纳，返回不可裁剪并继续补图，不改成扩图或拉伸。原图和每个裁后版本分别有审核记录及结果。

### D8. 任务、预算、失败和模型记录由 Host 统一管理

RunSpec 包含搜索页量、候选量、视觉调用量、下载字节、每图候选数、并发、重试次数和截止时间。值由部署 Config/用途配置显式解析，运行中不隐式补默认。每次外部尝试含重试都先占用配额；并发预留不能超额。第一版以实际调用/字节/时间为硬限制，费用估算仅在已配置价格时显示，并明确未知账单，不能承诺美元额度得到强制执行。

Run 持久状态与进程内 jobId 分开。Client 创建的任务由当前 profile 管理；Agent 创建的任务绑定 Session，其他 Session 不能读取或取消，Client 仅通过该所属 Session 的授权通道查看。该权限同时作用于候选、图片预览、审核和导出下载；将 Session 结果加入 profile 样例库需要人类显式保存独立的 library 关联，不能通过图片 ID 绕过授权。关闭页面不取消；停用插件先停止接收新工作，再取消并等待在途资源释放。重启时 running/pausing 转为 interrupted，用户显式恢复并重新校验凭据、资源和 provider revision 后创建新 attempt，保持原 RunSpec。

检查点保存完整页面、已提交图片/审核、预算账本和下一阶段。已提交结果不重复处理；进程在外部请求后、提交前退出时，记录 attempt 为 outcome-unknown，已预留配额不退回，恢复提示可能重新计费。原 cursor 失效时该查询报告 source-continuation-invalid；只有明确选择新搜索才从首屏开始，不伪造“原任务继续”。

技术失败使用 code、stage、retryable、safeMessage、suggestedAction 和 attemptId。无效参数、引用缺失、版本冲突和配置错误不可自动重试；超时/限流等允许在策略和剩余预算内有限重试。单图失败可按预算继续，来源全失败则任务 failed；来源正常耗尽或预算用尽是 completed 的明确 outcome。部分查询失败而其他查询已结束、目标未满足且没有先耗尽预算时使用 partial-failure，不能宣称来源正常耗尽；数量不足不会放宽标准。

主 Agent 工具参数、固定执行摘要、结果和安全错误通过既有 tool 记录及 presentation metadata 保存。辅助模型调用另存 ReviewBundle、图片摘要/附件引用、模型/提示词版本、参数、供应商声明版本、实际输出和校验结果；敏感 headers、完整签名 URL 和凭据不进入模型日志。任务内的完整模型输入可由不可变引用重建；外部模型未提供固定版本时标记可追溯但无法保证确定性重放。

来源、媒体及视觉请求均校验部署允许的 HTTPS 目标，DNS 解析和每次重定向都拒绝回环、私网及其他未授权地址；显式配置的本地视觉服务作为受限例外，只允许其固定 origin。来源认证仅发给配置的 API 目标，不转发给媒体 CDN 或跨 origin 重定向。下载同时约束实际字节、MIME 与解码像素，临时文件不可通过资源路由读取，校验完成并提交引用后才可见。

### D9. UI 与工具能力限制在已授权的工作区

| 入口 | 第一版主要操作 |
| --- | --- |
| 风格 | 草稿、规则支持图/例外、冲突、校准、发布、默认切换与历史 |
| 样例 | 导入、角色/维度、原图与预览区别、分歧、比较及反馈修订 |
| 找图与裁图 | 明确绑定版本的任务表单、阶段进度、原/成图、人工调整、取消/恢复 |
| 数据与评估 | 分组/划分、版本比较、指标分母、数据快照、下载与 Skill 预览 |

Client 复用项目 locale、按钮、列表、对话框与既有主题；不改公共组件或全局样式。窄窗口、键盘、焦点恢复、取消、空态及失败态随实施验证。大列表分页，图片按需加载，后台进度更新不能清掉当前筛选和选择。

Agent 只开放 `visual_style_list`、`visual_style_get`、`visual_search_start`、`visual_crop_start`、`visual_run_get`、`visual_feedback_suggest`、`visual_export_start` 和 `visual_export_get`。列表使用服务返回的分页 token；长操作返回 runId/jobId 而非等待整批完成。具体参数字段由 data-model 的输入记录约束，结果只含安全资产引用、计数及状态，不包含上游签名地址。导入文件、确认人工反馈、发布/默认切换、划分确认和生成 Skill 的启用仅由 Client 操作；Agent 建议明确显示未确认。

### D10. 数据划分、版本评估和导出共享不可变快照

同一资产、派生裁剪和已确认近似/连拍 family 不得跨 learning、development、holdout。第一版用来源 ID、精确摘要和近似指纹提示协助分组，由用户确认无法自动判定的关系；未完成分组确认的数据不能宣称独立评估。holdout 不进入规则归纳、ReviewBundle、训练导出或阈值调整。

开发比较固定数据、用途、预算与评分方法，只改变被比较的 release/candidate，记录规则与审核器变化。报告同时显示人工接受、漏选、待复核、裁剪破坏、执行失败、调用量和耗时，列明分母与样本数；技术失败不进入审美拒绝分母，但留在整批完成率。无标签或样本为空时显示 unavailable，不能生成满分。多次查看后用于修改规则的 holdout 转为 development/regression，后续独立结论使用新 holdout 快照。

导出风格包、分类 JSONL、成对偏好 JSONL、裁剪 JSONL 及 Skill Markdown；第一版不承诺某训练框架可直接加载，格式由 data-model 固定并提供转换说明。导出只纳入作用范围相符且人工明确确认的有效反馈，模型建议和仅本次不需要不自动导出为风格标签。训练导出只含 learning；开发与独立测试使用单独导出类型，均带 split/family 清单。默认以资产引用导出，显式选择并满足素材可导出状态才附带图片字节。

导出操作固定有效反馈头、release、usage、split manifest、资产摘要和格式版本，生成后修改反馈不会改写旧文件。Skill 是该快照的可读使用指南，包含 release 引用、规则、工具流程和 unknown/失败处理；参考图通过运行时资产工具访问，不能宣称一份文字文件已携带视觉能力。下载产物不写入 Home Skills，也不注入已有 Session。

## Risks / Trade-offs

- 样例偏向单题材会误学题材 → 按维度标注、展示支持及冲突、加入同题材正反例，初期保留 provisional 与人工复核。
- 模型观察和裁剪具有误差 → 保留 unknown、实际成图复核及用户修正；程序只对能测量的几何作确定性保证。
- HTTP JSON 适配不能覆盖所有商业图库 → 明确一套来源协议和配置验证，额外认证、付费及特殊协议另做适配，不在第一版执行任意脚本。
- 单 writer 限制多进程并行管理 → 第一版对 profile 明确占用并安全释放，后续若需共享部署再引入后端级并发机制。
- 模型价格或版本不可固定 → 固定可控调用预算、保留供应商版本声明，禁止把估算费用和历史输出当确定性保证。
- 反复人工调参污染独立测试 → 区分学习/开发/holdout，保留揭示记录与新测试快照。
- 素材不足或无法裁剪 → 返回已合格子集和原因，用户另开明确不同条件的任务，原图不覆盖。

## Migration Plan

第一版新增独立包、独立 `schemaVersion: 1` 数据域和命名空间，无既有 AFP 或 Session 数据迁移。应用携带本包及运行依赖；已有 profile 不自动改写选择或重启，用户可在插件管理器启用内置版本。应用安装依赖发生变化后，运行中的 Host 需要重启；独立包安装仍可用于未携带本包的环境。缺少来源或模型配置时仅禁用依赖它的操作，不能隐藏已保存的数据。

停用时释放注册、排空任务并保留素材、release、反馈和导出。恢复旧默认 release 不改历史任务；卸载包也不删除数据。后续数据版本升级需要显式迁移和拒绝不支持版本，不能覆盖旧记录或承诺旧包读取新数据。

## Open Questions

无阻塞本提案的产品决策。真实接口联调前需要部署方提供图片接口 URL、认证方式、分页与响应样本、原图可用性，以及视觉 endpoint、模型、多图/JSON 能力和调用限额；这些是部署输入，不授权扩大为爬虫、购买素材或微调平台。没有这些输入时使用 keyless fixture 验证流程，并将真实调用标为未验证。
