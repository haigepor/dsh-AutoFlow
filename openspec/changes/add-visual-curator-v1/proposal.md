## Why

现有 AFP 插件提供来源专用搜图与固定类别审核，缺少可由参考图和人工反馈持续校准的风格版本，也缺少裁后复核及可追溯的数据导出。需要一个独立插件，让同一份已发布风格用于参考图学习、图片搜索和指定用途的裁剪，并能验证新版本是否改善结果。

## What Changes

- 新增独立自定义 bundle `dsh-plugin-visual-curator`，随 CLI 和 Desktop 应用携带，新建 Web/Desktop profile 默认启用；已有 profile 通过插件管理器启用并保留原选择，复用 Host、Client、凭据、存储域、附件和 jobs 能力。
- 将风格档案、不可变风格发布版本、用途预设和本次任务分开；创建任务时固定规则、样例、审核器、用途及预算快照。
- 支持导入正例、反例和待判断图片，保存分维度参考意图，生成可确认的规则草稿、冲突列表及初始校准结果。
- 保存带上下文、操作者来源和替代关系的人工反馈；区分风格拒绝、题材不符、仅本次不需要、裁图问题和无法判断，显式发布后才改变默认标准。
- 支持一个可配置的分页 HTTP JSON 图片来源和一个兼容多图输入的视觉接口，完成查询规划、分页召回、去重、尺寸检查、视觉审核、候选排序与预算内补图。
- 实现指定比例和像素的裁剪：可行性判断、多候选、真实成图、几何检查、同版本风格复核及人工调整，保留原图和全部确认结果。
- 提供风格、样例、任务、数据与评估四个工作区，支持取消、检查点恢复、权限隔离和可诊断的失败。
- 导出版本化风格包、分类/偏好/裁剪数据及 Skill Markdown；保留数据划分和人工确认来源，不训练模型、不自动安装生成 Skill。

## Capabilities

### New Capabilities

- `visual-style-versions`: 参考图导入与意图、规则草稿、不可变发布、用途预设、默认版本切换和任务绑定。
- `visual-human-feedback`: 分维度判断、偏好比较、裁剪确认、上下文作用范围、修订和待确认建议。
- `visual-image-search`: 来源适配、查询与分页、去重、视觉审核、分层决策、预算和候选不足。
- `visual-smart-crop`: 比例及像素约束、坐标定义、裁剪候选、成图复核、人工修正和派生记录。
- `visual-curation-runtime`: 独立 bundle、工作台与 Agent 操作、任务授权、持久化、恢复、外部请求及日志。
- `visual-curation-export`: 分组数据划分、版本对比、评估状态、快照导出和生成 Skill 的使用范围。

### Modified Capabilities

无。当前仓库没有 `openspec/specs/` 主规范；既有 AFP 变更及其运行行为不纳入本次修改。

## Impact

实施目标目录为 `custom-plugins/workspace/dsh-plugin-visual-curator/`，新增 Host、Client、locale、测试和包内文档；根工作区及构建配置只增加独立插件开发和校验所必需的登记。新工具和 Remote 操作使用插件命名空间，现有 AFP 工具、收藏夹写入、凭据和记录保持兼容。

图片处理使用 `sharp`；第一版不要求向量数据库、Embedding、主体分割、Python、GPU 或外部标注平台。具体图片接口地址、响应字段映射、模型名称、限额及凭据引用属于部署配置，实施真实接口联调前提供；无配置时本地参考图、草稿和已保存记录仍可读取，依赖该配置的操作明确报错。

本 change 只新增 OpenSpec 文档，不创建插件源码、不改运行时或控制配置、不启动服务、不安装依赖、不发布产物。数据结构、任务流程及实现验证分别由 [详细设计](design.md)、[数据模型](data-model.md)、[实施任务](tasks.md) 和 [验收映射](acceptance.md) 约束。
