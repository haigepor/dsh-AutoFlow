# 自动规则风格档案

用户已确认将风格档案改为左右布局：左侧显示模型整理并默认采用的规则，右侧展示选中规则的参考图片与依据；工作台侧栏仅负责查看。分析完成后自动保存可用的参考档案，用户按需调整，无需逐条人工审核即可导出参考数据集。

变更限定于 Visual Curator 插件。模型档案与原有人工发布版本分开保存，旧数据与原有监督数据导出保持可读；模型结果不写成人工确认。模型档案使用固定版本供参考导出和视觉找图读取，原始图片继续按路径读取、不复制。
# 独立分析任务与配置更新（2026-10-25）

扩展现有变更：素材集可自由切换并并行分析，每个素材集只有一个活动分析；任务可随时取消并查看实时过程弹窗。新任务默认 high，已有 RunSpec 保持原值。保存配置显示加载动画并只读回轻量配置，视觉参数热更新不停止旧任务。系统中断自动从持久检查点恢复，主动取消不自动恢复；不重跑已完成图片，不重置预算或静默替换模型。
