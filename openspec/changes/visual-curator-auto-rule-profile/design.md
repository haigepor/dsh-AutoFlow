# 设计

模型输入从任务 request 记录读取：reserved 保存描述，committed／outcome-unknown 保存 data.bundle。详情轮询仅返回轻量请求索引，全文按需读取；新过程消息带可选 requestId 关联实际请求记录，旧消息继续读取且不按数组位置配对。输入中的 system instructions、user inputText 与图片顺序保持原值，图片通过授权资源入口交给项目 conversation.images.content Factory 预览。正文为只读请求回放，不创建 Session、不显示发送框、不改变模型配置或触发重跑。远程引用只表示当时提交的 URL，不宣称固定了供应商取得的像素。

采用现有 DSH Modal、Button、Checkbox、TabNavigation 与 DisclosureRow。宽屏弹窗左侧为按维度及风格组整理的规则，右侧联动图片、观察和差异说明；两栏独立滚动，底部固定导出操作。窄窗口在规则和依据之间切换。侧栏展示当前采用规则，不提供编辑、保存或发布操作。

新增 modelProfile 与 profileExport 持久记录，分别保存模型来源、分析任务、冻结参考与规则选择，以及版本二参考数据包。旧 release、export、人工标签与数据划分保持其原有语义。保存调整使用当前档案 ID 检查并发，创建新快照而不覆盖历史；重新分析保留用户调整，并使缺失依据的规则失效。过期、未完成、越权或零启用规则的档案不能启动导出或新找图。

跨图归纳同时输出规则分组、默认选择与理由，程序校验引用和组关系；旧分析按已有证据集合整理为默认档案。自动采用不制造人工 confirmed 状态。可迁移规则作为偏好，不自动升级成硬性要求；不同风格组按替代关系匹配，题材信息保持可选。

测试覆盖自动采用、规则来源、无需人工发布和数据划分的参考导出、选择调整、版本冲突、过期结果、权限及校验和，并保留旧数据集快照。Playwright 验证两栏联动、只读侧栏、固定底部、窄窗口、键盘、状态和实际下载。
# 独立分析任务与配置更新

继续复用 RunEngine、检查点、请求收据和 profile 存储，不建立第二套分析执行器。RunEngine 的串行受理负责同素材集互斥，配置化的分析任务容量负责排队；多个任务的模型请求共享并发额度。导航不受启动、取消或保存操作锁影响，状态按 runId/styleId 保存。当前任务冻结非秘密配置和输入；更改默认配置只影响新任务。

视觉配置使用 Cordis volatile 引用更新当前服务默认值；其他需要释放资源的配置仍走既有 Loader 生命周期。保存完成返回经过校验的当前配置和 revision，不等待完整工作区、图片和任务结果投影；相同配置不重复写入。新任务默认 high，显式服务商默认保留为独立值；读取旧 ExecutionSpec 使用原有 parser，不补入新的模型参数。

新分析持久记录系统恢复意图，系统卸载及进程中断收敛到 interrupted；用户取消持久撤销恢复意图。恢复保持 runId、冻结配置、已提交观察及预算，增加 attemptId；过期预算、不可用资源或凭据显式停止。已提交请求可回放，未知请求保留原配额且不伪装成功。旧版 cancelled 任务不批量自动唤醒。取消与完成竞争不得将终态回退到 cancelling。

新增轻量分析摘要和详情读取。摘要供素材集菜单、页面及轮询消费，详情供弹窗读取阶段事件、批次、已提交观察和有界模型输出。模型适配器支持可配置的 SSE 输出接收，保留完整 JSON 校验；上游忽略流式参数返回 JSON 时仍解析真实结果，明确拒绝流式时不自动重发付费调用。展示上游实际返回的可见说明和输出，不合成思考文本。流片段先进入有界进度缓冲，在持久检查点保存摘要，避免每个 token 重写全量 manifest。关闭弹窗只停止详情读取。

修改范围限 Visual Curator 源码、测试、README、现有 OpenSpec 和升级说明；共享 Cordis、配置编辑器及 UI primitives 保持原值。修改前快照和外部文件摘要保存在本轮独立 Temp 备份。验收使用独立 profile 和受控模型夹具，原 3080 Host 只读核对素材和已完成结果；真实旧任务不因验证而自动重新启动。

# 任务信息布局

分析过程入口与主分析按钮组成同一操作组；运行中禁止重复启动，过程查看保持可用。任务记录使用紧凑选择列表及相邻详情，展示本地化任务类型、状态和已保存计数，结果继续使用原排序和分页读取。窄屏依次排列选择列表与详情，主要操作换行而不隐藏。

过程弹窗继续使用 DSH Modal 的焦点、Escape 和关闭行为，采用实色主题背景、紧凑状态摘要及固定操作区。模型输出与运行日志通过现有 SegmentedTabs 切换，只保留当前阅读区滚动；切换日志时记录正文位置，返回后恢复。未完成的终态批次默认收起，接口原文仍可展开，已提交观察与最终归纳继续独立展示。布局修改不改变 Host 执行、模型请求或持久结果。

# 分析对话排版

过程弹窗使用右侧用户气泡、左侧模型正文的单列消息流，沿用现有 UserContent 的 bubble 主题变量、圆角、行高与图片图库。仅进入阅读区的输入按需读取，技术原文通过单一“输入详情”入口查看；长任务指令可展开，短文本不截断。推理与响应原文默认折叠，运行参数留在日志页。任务状态与计数保留在紧凑顶部，取消、关闭和回到最新输出留在固定底部。现有会话用户消息 Factory 依赖 Session，此视图只复用可独立调用的图片 Factory 和样式 token，不伪造会话或绑定无关会话。

推理正文复用 UI Chat 已注册的 root 范围 conversation.chat.reasoning.content Factory，传入原始 text 与真实 running 状态；当前消息和历史无消息列表路径均使用同一组件。保留共享 DisclosureRow，删除本地纯文本推理容器和边框样式，不复制 Markdown 解析器，不新增 Session。组件类型通过 UI Chat 的公开 client 导出读取。

# 模型输出与图标

逐图观察采用授权缩略图、批次输入编号、辅助文件名与维度正文的单列布局。编号遵循该消息的 imageIds 顺序，图片使用相同 imageVersionId 的已保存输入，进入阅读区才读取。不存在授权预览时显示图片占位图标，不以素材库中的相似图替代。风格归纳以维度、支持与反例图片、建议规则和匹配提示词分组；图片关联只来自实际返回的 ID。

视觉分析专用 SVG 使用 currentColor 和统一 16px 网格，其他动作继续使用共享图标。推理、缩略图库、预览、页签与弹窗继续调用仓库组件。输入详情默认展示指令与发送图片，完整用户消息和系统提示词保留原文页签；任务记录补充终态与已保存结果图标。没有新增 Session、模型请求或持久化字段。
