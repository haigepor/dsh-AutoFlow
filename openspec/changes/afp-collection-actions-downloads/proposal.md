## Why

AFP 工作台目前只能选择图片和查看 Mockup 预览，无法管理跨收藏夹选择，也没有原图下载流程。需要将收藏夹操作、积分确认和 Host 后台下载放到统一、可恢复且能保护认证信息的工作流中。

## What Changes

- 将图片点击改为选择、右键改为详情，并重做收藏夹侧栏和顶部批量操作栏。
- 支持跨收藏夹复制、移动和解除图片收藏关系，不删除 AFP 图片或收藏夹。
- 新增下载配置、画质与成本预览、积分确认、文件命名、目录选择和后台任务状态。
- 付费下载只有在用户确认报价后执行；订单或购买结果不明确时不自动重试购买。
- 改善回到顶部按钮的主题悬浮状态，并为交互、权限与文件处理补充回归覆盖。

## Capabilities

### New Capabilities

- `afp-collection-operations`: 选择多个收藏夹中的图片、管理收藏关系并操作收藏夹侧栏。
- `afp-image-download`: 获取 AFP 可下载画质、确认积分支出、选择落盘路径并后台下载图片。

### Modified Capabilities

无。

## Impact

改动限于 AFP 插件的 Client、Host、项目目录选择器适配、locale、测试与说明文档。新增插件内部操作与下载状态类型；复用 DSH `ctx.jobs`、现有目录选择能力及项目 UI 组件，不修改 DSH 核心公共 API或新增运行时依赖。实现前须厘清 AFP `buyPhoto` 受理结果与 `getUrls` 校验标识的关联；不以未经验证的字段启动或重试购买。
