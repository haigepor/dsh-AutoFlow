## Context

工作台私有 `photo-search`、`photo-details`、`collection-list` 和 `collection-items` 已使用认证连接、受限 DTO 和可取消读取。现有 Agent 工具只覆盖规划、分类统计及策展流程。此次为 L 级插件接口扩展，研究、设计、实现、验证和审查均在插件及本 change 内完成。

## Goals / Non-Goals

Goals：Agent 可真实搜索并沿游标翻页、查看单图和完整收藏夹；错误可分类且不泄露敏感数据；所有新能力随 `read` 注册和释放。

Non-Goals：不改核心、公共组件、页面、付费购买和写入流程；不实现翻译、Facet、高级查询、任意图片筛选和下载续传。

## Decisions

- 四个新增工具分别为 `afp_photo_search`、`afp_photo_details`、`afp_collection_list`、`afp_collection_items`，复用 `service.pageAction` 的四个只读操作，避免复制认证和分页逻辑。
- 首屏省略 cursor，后续仅使用成功响应的游标；实测无效占位值 "0" 在 Agent 校验阶段拒绝，不自动回退首屏。命名目录排除空名称项并报告排除数量；成员读取先拒绝空名称项，不将其当作共享收藏夹访问证据。
- 新工具返回页面数据的明确字段投影，图片不包含预览路径或上游媒体字段；结果附加 `meta`，包含耗时和实际语言等非敏感信息。收藏夹成员返回 `nextOffset`，图片搜索沿服务返回的 cursor 翻页。
- 工具 JSON 参数在执行前校验，包括部署 pageSize、语言枚举、ID 和互斥报告参数。固定错误描述序列化为 JSON 并作为工具错误抛出，保留 DSH 的 `isError`；未知异常始终使用通用安全代码，不回显原始异常。
- 旧工具名称、成功 JSON、写入确认及任务语义保持不变。更新两项搜索 Skill 指导真实搜索；不把搜索结果直接当作像素筛选结果。
- 会话快照通过真实 DSH Agent 循环消费模拟 AFP 接口，覆盖工具调用、结果、错误和卸载后消失；仅移除协议耗时和新工具测量耗时。

## Risks / Trade-offs

- 上游错误没有统一结构 → 仅识别插件控制的固定错误和已知 HTTP 格式，其余保守分类，禁止自动重试写入。
- 收藏夹列表可能较长 → 保留现有完整列表行为，成员和搜索均按部署 pageSize 限制。
- 新工具不会自动进入已有加载快照 → 重载 Host 后核验新注册工具，后续会话使用新工具目录。
- 源码中已有未提交配置修复 → 备份当前版本，不回滚既有修改；仅编辑本阶段需要的文件。

## Migration Plan

无需修改部署配置、持久记录或依赖。更新插件并构建客户端产物；只读核对任务空闲后沿现有 `dsh web --no-open` 路径重载 Host，保留 3080。回滚使用本阶段临时备份恢复所改文件，新文件单独移除；不恢复无关历史改动。

## Open Questions

无。本阶段外的增强保持后续独立范围。
