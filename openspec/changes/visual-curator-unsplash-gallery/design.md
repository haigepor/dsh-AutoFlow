# 图库接入设计

## 页面

上层保留图片工作区与“模型&图库设置”标签，删除重复的大标题和说明。设置内划分视觉模型和图库，图库采用紧凑账号列表与内容区域并列的结构。账号操作使用项目 Menu，收藏夹、收藏图片、全站搜索使用共享下划线 Tab。每个账号显示身份和默认状态；收藏夹显示名称、图片数和私密状态。图片可预览、查看来源、选择并加入当前素材集。窄屏以账号菜单替代整列列表。自定义 JSON 图库由工具栏“高级设置”打开弹窗，标题和底部保存按钮固定，长表单在中间滚动；任务记录只在图片工作区显示。

## 数据流

账号会话仅进入 DSH credentials；配置保存账号 ID、身份和凭据引用。连接先调用当前用户接口验证，再保存。每次私有资源读取核对当前用户 ID，避免凭据替换后跨账号串用。图库动作仅供已认证的工作台使用，Agent 找图通过已配置的来源和已有任务接口执行。

“添加账号”由 Host 使用 `playwright-core` 打开独立的 Chrome/Edge 临时配置目录并访问官方 `/login`。不连接日常浏览器、不读取 SQLite Cookie 数据库，也不向 Agent 暴露浏览器或凭据工具。Host 仅获取影响 `/napi/me` 的 Unsplash Cookie，验证身份后关闭窗口。Client 只接收安全状态和账号描述，Host 幂等写入凭据后由现有配置动作保存账号。更新会话必须匹配原账号，新连接不能重复已有用户。取消、关闭窗口、超时和插件卸载会中止校验并等待窗口关闭；已提交凭据的结果保持已保存，不伪装为取消。元数据保存失败保留已验证账号，可重试保存连接。

Magpie 当前主登录流程使用官网 OAuth 回调或厂商 CLI，并没有找到可直接复用的通用 Chrome/Edge Cookie 提取器。本实现参考其状态、取消与提交的分离，针对 Unsplash 网页会话采用受管理窗口的 Cookie API；官方 OAuth 和网页 napi 会话不混用。

`UnsplashApi` 负责外部 JSON、Bookmarks/Collections 区别、照片详情与分页。`CurlUnsplashTransport` 复用原接口包的 curl 与访问校验方式，以 TypeScript 集成，无 Python 和共享 Cookie 文件依赖。临时目录按请求隔离，限制时间、响应字节、重定向和公开目标地址；凭据不进入进程参数。

图库引用只接收账号、图片 ID 和目标素材集版本。Host 重新获取图片元数据并校验公开 CDN 链接，保存远程引用及账号来源，按逐图收据和准备/提交两步更新素材集，不复制图片字节。确认的原始本地路径读取逻辑保持不变。

搜索页可能忽略请求的每页数量；continuation 包含查询摘要、服务端页码、页内偏移与该页 ID 摘要，避免截断漏图和接受变化的半页。任务固定来源账号配置，继续使用既有预算、模型请求日志、风格标准和审查结果记录。

使用模型档案搜索且没有显式检索词时，以其保存的搜索提示召回，任务描述继续约束视觉匹配目标。

## 实测差异

本地文档将 Bookmarks 描述为数组，当前接口实际返回含 `results` 的对象；适配器同时支持经验证的两种形式。搜索请求每页两张时，服务端实际返回 20 张。已有会话实测当前收藏夹和收藏数均为零，非空及私密数据通过独立测试夹具验证。

## 后台引用任务与分页

确认加入前仍须完整读取收藏夹元数据并固定用户选择；浏览预览不授权后台写入。新增 Host 任务使用现有 jobs 和仓储 manifest，保存任务所有者、账号、目标素材集、所选图片、稳定批次操作 ID、阶段和最终回执，不保存凭据或图片字节。启动请求仅等待任务受理；工作由 Host 生命周期持有，窗口关闭不会发送取消。每个素材集同时只接受一个引用任务；归档和分析在该素材集引用结束前拒绝。账号及目标不随页面选择变化。

显式停止中止未提交的后续项目，已开始的提交先取得最终回执；registered 与整批提交成功分开计数。未知回执进入待确认状态并停止后续批次，不自动重放。任务终态持久保存；重新启动 Host 将未终结任务标记中断，不自动续跑。旧同步 gallery-import 接口保持原义。

客户端共享状态按素材集保存任务视图。当前标题、素材集菜单和页面状态区域显示加载动画与进度；关闭弹窗只隐藏视图。引用未完成时仍处于引入阶段，普通引用完成后恢复人工启动分析。轻量状态读取不构建全部规则、导出与任务图片；列表更新只在成员版本改变时刷新。

引用分页通过已有 data 读路由按 styleId 取得图片、角色总数与后续游标。游标固定已读取引用的顺序前缀，追加不使已有分页失效；前缀删除或重排明确要求刷新。观察器使用实际 .vc-library-pane 滚动容器，在底部附近加载；同一素材集仅一个在途追加请求，错误停止自动加载并保留内容供重试。旧响应不能覆盖新素材集，成功后台刷新保留已加载页、筛选和滚动位置。

验收先用隔离夹具和可控 barrier 覆盖关闭、取消、批次回执、归属、Host 中断及追加期间分页，再用 Playwright MCP 验证真实页面的弹窗关闭、素材集进度、刷新、触底、错误重试与窄屏。浏览器写操作仅在独立 profile 的合成素材集执行，保留该 profile 供复核；原 Host 只读比对素材集名称、revision 和归档状态，不重新运行已有视觉分析。性能分别测量受理、状态读取和列表分页，手工样本不作为 CI 时间阈值。

## 回退

本轮开始前的插件源码、测试和 README 已单独备份；源数据不原地转换。新账号配置与凭据分别保存，旧构建降级前应移除其不认识的图库配置字段并保留凭据备份。测试使用独立素材集，不改写现有原图和已完成的风格档案。
