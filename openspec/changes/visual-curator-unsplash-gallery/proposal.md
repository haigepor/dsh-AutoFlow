# 多账号 Unsplash 图库

## 目标

将现有模型设置调整为“模型&图库设置”，使用用户提供的 Unsplash Web 接口资料，接通多个独立账号、账号收藏夹、收藏图片、全站搜索和所选图片的参考导入。图库图片沿用现有 API 视觉分析、自动规则和引用数据包流程。找图任务复用同一来源适配器。

## 范围

插件内的配置、凭据连接、图库适配器、图库页面、导入和搜图消费者；保持现有通用 JSON 来源与视觉模型配置可用。共享组件、全局控制配置与本地原图处理不变。

## 验收

可分别连接多个账号并浏览其收藏夹与未分组收藏；凭据不进入配置或数据包；过期会话和不匹配身份有明确失败。分页不丢失服务端多返回的图片。选图后可加入素材集并通过既有视觉分析生成模型风格档案。全站搜索可通过同一生产来源适配器调用；不同账号的身份和导入收据隔离。

## 后台引用与素材分页

用户确认所选图片后，由 Host 持有固定目标素材集和账号的引用任务；关闭弹窗、切换素材集或刷新页面不停止任务。页面和素材集菜单显示同一任务的阶段及已确认数量，停止操作保留已提交结果。素材列表在自身滚动容器触底时自动追加当前素材集的分页，区分已保存总数与已加载数量。保留已有同步引用调用和现有素材数据，不自动启动视觉分析。
