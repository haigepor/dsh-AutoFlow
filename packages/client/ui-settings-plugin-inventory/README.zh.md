# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

## 概述

**插件列表**标签页让 Web 用户查看插件，而不改变其配置。它先列 agent（智能体）预设分组，再列全局清单；两个分组默认收起，搜索期间两组都展开。卡片显示可用的本地化标题与描述，以稳定的条目 id 标识实例，并展示启停状态、出处、运行状态、禁用条件与发现失败；由预设提供的全局条目会列出对应预设。搜索覆盖两个分组，并指出其他预设中的匹配。标签页处理加载、空结果、无匹配、失败与重试状态，且不暴露传输细节；没有预设 roster 时仍会展示全局清单。

## 使用本包

打开设置中的「插件」分区并选择**插件列表**标签页，即可查看宿主的插件清单。插件激活期间不会读取 Remote——首次选择该标签页时才挂载组件，并通过 `api-remotes` 懒调用 `ctx.remote.pluginInventory.list()`。

安装失败且存在待审批的 pnpm 构建权限时，页面提供“允许这些脚本并重试”。该操作展示准确包名和持久授权范围，再使用原来的包规格及启用选项重试。一次点击批准整个列表，其中可能包括此前安装留下的待审批包。关闭页面不会授予权限。

### 阅读卡片

已核对的内置模块使用精简的中英文清单字典，预设条目分别描述；未知模块保留自己的包元数据。每张收起的卡片使用插件可用的本地化标题与描述；描述使用一行截断摘要，悬停或展开详情可查看全文。设置页会缩短字面的包名或模块名回退值，移除 npm scope 以及 `cordis:`、`cordis-plugin-` 或 `dsh-`/`dsh-host-`/`dsh-client-` 前缀；locale 标题保持原样。Host 在 `meta` 中提供 locale 与包字段的回退结果，Client 选择当前语言。详情与搜索仍保留完整模块标识。缺失的描述不显示，元信息诊断随卡片展示。这种短名显示仅用于设置页，不影响侧栏的插件页。

启停标签标记已停用、条件启用、由预设提供和启动失败；普通启用的行不带标签。存活的根 fiber 阶段使用圆点：pending 为 idle，loading 和 unloading 为 ongoing，已结束的 active 和 failed 不显示圆点。紧凑卡片头部不显示条目 id 标签。独立条目 id 保留在无障碍名称、搜索和展开详情中；详情还显示完整模块标识、完整描述、来源预设、配置与运行状态，以及禁用条件。由预设提供的全局条目列出对应预设，并提供跳转到预设组的入口。内置预设通过共享 presetDisplayText 解析当前语言，用户自建预设保留自己的元数据。

### 预设切换器

切换器与通用设置各行使用同一种「选择胶囊 + 菜单」控件。它列出 roster 的每个预设——默认项带后缀、坏预设带标记——并且只改变列表显示什么：它不写任何设置，选中坏预设时在行的位置展示 discovery 报告的原因。选择默认预设或会话预设的入口仍在原处：Agent 预设分区与新会话页。

### 重试失败的读取

读取失败会在标签页内渲染共享 error 标记。加载时在卡片网格中显示骨架卡片，当前页面同步使用共享 ongoing loading。重试会重新执行懒 `list()` 调用，且不会暴露传输细节。

插件列表还显示当前页面的同步失败。重试会重新应用最新客户端图，不改变 Host 启用状态，也不刷新页面。

-----

插件清单填满设置内容栏，使用 36px 高的搜索框、只读标识，以及开发工具、检索与上下文、智能体与协作和其他基础功能筛选。功能筛选与文字搜索组合应用于两组及其他预设，不写入配置；清除筛选后恢复各组的折叠状态。已知模块系列复用共享插件图案，文件类使用配套的蓝绿填充文件夹，未知模块使用通用图案。卡片头部统一为 64px，图标、文字和末尾操作垂直居中。较长名称和摘要截断显示，详情保留完整文字与条目身份。不透明的双列卡片使用细边框与轻阴影，容器较窄时改为单列。筛选变化时，卡片展开状态仍绑定原条目。分组与详情首次展开才挂载，之后保留已访问内容，以 250ms 高度和透明度过渡；收起内容不可操作，减少动画偏好关闭过渡。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

该标签页是宿主拥有快照的只读投影；插件激活期间不执行任何 Remote 读取，首次选择时才取快照。

### 注册

浏览器插件注册一个 id 为 `all` 的本地化 `settings.plugins.tab` 贡献；「插件」分区拥有导航入口与标签栏。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

### 渲染

行键带作用域（global:、preset:<id>:<index>），因此同一模块在两组中的展开状态相互独立。条目 id 保留在详情和无障碍名称中，紧凑头部不显示其标签。由预设提供的标记在客户端计算：只有全局停用且至少一个预设明确启用的条目才显示；条件启用或停用的预设行不会被视为已提供。

</details>

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>


这些限制定义清单视图的新鲜度与触达范围；它们是当前包约束。

- **每次 Settings 挂载或重试只读取一份快照**：标签页不订阅 Loader 变化，也不会在重连后自动重新读取；切换标签页会保留当前快照，重新打开 Settings 则会取得新快照。
- **两个平面都只读**：标签页展示全局与预设的启停状态但都不修改；写回自定义预设组合文件的启停控件是刻意留作后续的工作。
