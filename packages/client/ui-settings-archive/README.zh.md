# @deepseek-ai/dsh-client-ui-settings-archive

[English](README.md) | 中文

<a id="summary"></a>
## 概述

本插件在设置中提供“归档会话”页面。用户可以按标题、工作区、更新时间和收藏状态查找会话，单条或批量归档、恢复会话，也可以恢复后打开对话。页面复用已有会话目录、工作区归档集合、导航服务和共享设置文档。

## 使用本包

Web bundle 为 Web 和 Desktop 组合本插件。设置分区 id 为 `archived-sessions`，仅在当前 Peer 可以订阅工作区时注册。页面默认显示已归档会话，排除子代理来源和空白会话。切换页签或筛选条件会清空选择，折叠分组不改变选择。“全选当前结果”包含折叠组中匹配条件的会话。日期筛选依据最后更新时间，以浏览器本地时区包含起止当天，支持快捷范围和自定义日期。排序依据更新时间或标题，Host 归档集合不提供归档时间。

收藏独立于侧栏置顶，以 `favoriteSessionIds` 保存到 Host 设置命名空间 `ui-settings-archive`，归档和恢复均保留收藏。写入携带命名空间版本；冲突时重新读取已接受的偏好，不覆盖其他客户端的更改。恢复保留原工作区位置，“恢复并打开”仅在恢复成功后导航，也不会覆盖后来的导航。归档请求不会停止运行中的工作：已知运行中或等待交互的会话不能参与批量选择，每条请求仍由 Host 检查归档条件。Host 发现后台工作时，会逐条显示拒绝原因并提供重试操作。

批量请求串行执行，单条失败后继续处理后续会话，未完成项可显式重试。关闭设置后批次继续，反馈通过 `shell.overlay` 显示。卸载插件后不再发送后续请求，已发出的 Host 请求仍可能完成。页面不会为筛选打开冷会话日志。

已归档页签支持确认后的单条与批量永久删除。Host 拒绝删除未归档会话、仍有工作运行或被其他写入者占用的会话。删除会清理所选会话记录、投影检查点、搜索条目、工作区关联、固定与收藏状态，保留工作区文件和其他会话。清理未完成时提供显式重试。选中行使用主色浅底，分组复用 `AnimatedCollapse`，遵循主题动画 token 与减少动态效果设置。

删除弹窗在请求执行期间显示已处理数量、总数、进度条和运行指示。会话记录删除成功后，目录行先于后续清理移除；清理失败仍可重试，已删除的行不会因此返回列表。

<a id="understand-the-implementation"></a>
## 理解实现

`src/client/index.ts` 拥有注册与注入命令。`ArchivePage.tsx` 接收标准会话、工作区钩子和窄范围的操作状态源。`operations.ts` 拥有批量进度、逐条失败和临时提示。会话与工作区的权威数据仍由已有 API controller 拥有。控件来自 ui-primitives，CSS 使用共享主题 token。归档装饰插画是项目鲸鱼女仆素材的同风格透明变体。

<a id="model-experience"></a>
## 模型体验

无，因为页面不注册模型工具、提示词、事件或消息，归档、恢复和收藏控件均不发起模型请求。

<a id="kv-cache-effect"></a>
#### KV 缓存影响

无。页面不改变模型输入或已缓存的对话内容。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- 搜索范围为标题；全文检索、归档会话只读预览、闲置整理和跨工作区移动不属于本页面的操作范围。
- 当前对话导航要求先恢复已归档会话才能打开。现有归档模型不记录每条会话的归档时间。
