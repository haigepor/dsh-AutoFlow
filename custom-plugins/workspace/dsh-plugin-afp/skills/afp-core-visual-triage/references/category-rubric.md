# 五类图片视觉判据

## 统一门槛

视觉模型的 `confidence` 表示“目标类别是主要视觉主体”的置信度，不表示“画面中存在相关物体”的置信度。必须同时满足：

1. 目标主体在像素中直接可见，而不是由 caption、title、OCR、品牌或上下文推断。
2. 目标主体占据有意义的画面比例，或构成明确的构图中心。
3. 没有命中该类别的硬排除语境。
4. 主体被遮挡、过小、模糊或类别边界不清时，返回 `none` 或低于 `0.80`。

模型执行顺序固定为：主构图识别 → 目标类别必须条件 → 类别硬排除 → 置信度校准。`confidence` 代表目标类别是主要视觉主体的确定程度，不代表相关物体在画面中出现的概率。

| 类别 | 必须满足 | 排除示例 |
|---|---|---|
| `animals` | 至少一个真实动物清晰可辨，并且是主要主体 | 服装/吉祥物/玩偶/Logo/插画、动物仅在背景或文字中出现、以活动人物为主的现场照 |
| `food` | 可食用食物或饮料是主要主体；加工过程只有在食物本体清晰可辨时保留 | 空餐厅、餐厅外景、菜单/招牌、配送员、包装或车辆为主、无法辨认食物的工厂流水线 |
| `landscape` | 完整自然环境或广阔城市全景构成的横幅壁纸画面；环境覆盖至少 75%、强空间纵深、分层构图、主题清晰、水平结构平衡且审美分为 5 | 花卉/叶片特写、人物特写、单物体、单栋建筑、交通道路、活动人群、灾害报道、源图文字或拼贴、大面积空天空/水面但主题模糊的失衡画面，以及中国/香港/澳门/台湾的明确视觉证据 |
| `movie-poster` | 真实电影宣传海报占据明显画面，并可见电影版式、角色/画面与片名或电影宣传设计 | 政治/纪念/商业海报、登山者海报、演员肖像、红毯、采访、舞台活动、电影剧照、影院建筑 |
| `celestial-body-wallpaper` | 画面本身是完整宇宙壁纸；允许大球形星体、星云/星系/彗星/黑洞等扩展天体，或密集星点构成的宇宙画面 | 小月亮/小行星点缀、空黑夜空、城市夜景、极光或流星单独出现、飞机/活动灯光、望远镜、书本、海报、屏幕、拼贴、源图文字和 Logo |

## 类别专项判断

- `animals`：真实动物可以佩戴普通配饰，但若主要视觉信息是 cosplay、吉祥物、笼舍标牌或活动环境，应拒绝。
- `food`：人物端着食物时，只有食物本身清楚且占据视觉重点才保留；动物吃东西、食品摊位活动和食品包装不能仅凭文字保留。
- `landscape`：只保留 `presentation=wallpaper`、`primaryFocus=natural-landscape|city-panorama`、`sceneType=natural-scenery|open-city-panorama`、环境覆盖至少 75% 且 `spatialDepth=strong` 的画面。还必须为横幅或全景画幅、包含 `layered-depth`、`subjectClarity=clear`、平静感为高或中、`visualBalance=balanced`、人物不主导、审美分为 5；自然风景不能由建筑主导。水平线、岸线、水线或天际线是画面的主要稳定横向结构时，`horizonPlacement=centered` 为默认安全构图；偏离中心只有在主体从缩略图即可清晰读出、画面包含前中后层次并有明确平衡锚点时才标为 `off-center-balanced`，同时返回 `clear-anchor` 和 `balanced-off-center`。无明显水平结构时可标为 `not-visible`，但仍必须返回 `clear-anchor` 和 `visualBalance=balanced`。大面积天空、水面或地面没有清晰主体、使画面明显上重或下重时标为 `off-center-unbalanced` 或 `visualBalance=unbalanced` 并拒绝。`vesselRole` 仅可为 `none|incidental`，`crowdScale` 仅可为 `none|sparse`，`editorialContext` 必须为 `none`；城市全景还必须 `urbanOpenness=open`。`coastalStructureRole` 为 `prominent|dominant` 时拒绝灯塔、防波堤、码头、海堤等设施主导画面；`cityInfrastructureRole` 为 `prominent|dominant` 或 `industrialDocumentary=true` 时拒绝工业/交通纪实；`terrainInfrastructureRole` 为 `prominent|dominant` 时拒绝道路、轨迹、土方、壕沟或公用走廊切割自然地形的画面，仅远处不抢主体的小路可标为 `incidental`。海滩、山、冰川、湖泊和有留白的广阔城市天际线可保留；单朵花、单棵植物、道路纪实、车辆、人群、活动、单栋建筑、灾害新闻、战争/冲突/军事报道、码头/游艇/渡船、日常纪实和高密度城市地标记录均不算风景壁纸。视觉模型只有在画面中存在直接且高度特异的地标/城市景观证据时，才可标记中国、香港、澳门或台湾；模糊亚洲风格、人物外貌、caption 和 OCR 都不能当作地域依据。AFP 水印、版权条、图片 ID 和查看器 UI 是预览叠层，必须忽略。
- `movie-poster`：背景中的海报被人物遮挡、无法辨认版式、只是活动背板、影院路人场景或普通剧照时拒绝；海报应占据明显画面比例。
- `celestial-body-wallpaper`：按三种构图分支判断。人物、手持眼镜/设备、商品包装、动物、城市、山地、树林、岩石或水面一旦成为主构图，不能因为画面里出现太阳、月亮或星空而保留：
  - 所有宇宙类别先判定 `presentation`。仅成品宇宙壁纸可通过；科学观测式、单色平面太阳圆盘属于 `scientific-observation`，即便球体超过 80% 也拒绝。带地平线、树林、山水、城市或流星夜景属于 `terrestrial-landscape`，应留给后续 `AutoFlow_风景` 规则而不是本类别。
  - `spherical-body`：行星、月球、太阳等球体的可见直径或跨度至少达到图片短边 80%；旧参考中的“小月亮 + 大面积黑底”因此拒绝。
  - `extended-formation`：星云、星系、彗星、黑洞等可以不是圆球，但宇宙内容必须覆盖至少 60%，空黑背景不超过 40%。黑洞本体内部的黑色不计为空黑背景。
  - `dense-star-field`：允许散落的星星点点，但必须被判为 `dense`、宇宙纹理覆盖至少 75%、空黑不超过 40%；稀疏天文目录图/深场应标为 `sparse-deep-field` 并拒绝。星点之间的深色空间若仍有明显宇宙纹理，不按“空黑”处理。
  - 空间站或卫星只能是清晰宇宙构图中的次要点缀；设备本身占据主构图、新闻现场、展品、模型或发射场景均拒绝。

模型必须依据预览中底层图片像素而非 AFP title、caption 或实体关键词判断。AFP 水印、版权条、图片 ID、查看器控件和元数据页面 UI 只是预览叠层，必须忽略，既不能作为接受理由，也不能作为拒绝理由；但源图本身的文字、Logo、边框和拼贴仍应拒绝。无法确定时返回 `none` 或低置信度。
