# AFP 专用 Agent

[English](agent.md) | 中文

## 进入方式

新对话的预设菜单中选择 **AFP 策展助手**，或在输入框的 `@` 菜单选中 **AFP 图片策展** 插件。选中插件引用会把当前对话切换到 `afp-curator`，发送前会等待切换完成。已有对话标题旁的预设名称也可点击切换。切换在两轮之间生效，保留当前对话，不改变新任务默认预设。

AFP 组合包必须处于启用状态，原有读取、视觉刷新、写入和 Skill 开关继续生效。专用预设不会重复创建 AFP 服务，也不会擅自打开已关闭的功能。账号和模型配置仍通过 AFP 操作台完成，Agent 不在聊天中索要密码或 Token。

## 功能对照

| 任务 | Agent 工具与行为 |
|---|---|
| 检查配置和账号 | `afp_status`、`afp_account`；存在凭据不等于认证已成功 |
| 搜索与查看 | `afp_search_plan`、`afp_photo_search_start`、`afp_photo_search`、`afp_photo_details`；转换为支持的检索词并沿用真实游标 |
| 浏览收藏夹 | `afp_collection_list`、`afp_collection_items`、`afp_collections`；有名称的共享收藏夹仍可读取 |
| 视觉筛选 | `afp_refresh`、`job_output`、`afp_report`、`afp_run_items`；保存逐图判断、理由及可续跑检查点 |
| 最终选图 | `afp_photo_selection`、`afp_result_page`；使用本轮证据、明确最终图库并分页读取结果 |
| 整类修改 | `afp_plan_change` 后接 `afp_apply`；按准确分类目标追加、替换或清空 |
| 指定图片修改 | `afp_collection_plan` 后接 `afp_operation_apply`；只添加、复制、移动或移除明确指定的图片 ID |
| 分类绑定 | `afp_category_plan` 后接 `afp_operation_apply`；将分类关联到私有可写收藏夹，或解除绑定 |
| 下载 | `afp_download_options`、`afp_download_directory`、`afp_download_plan`、`afp_operation_apply`；选择版本、目录，预览费用后作为当前 Session 作业执行 |
| 历史与恢复 | `afp_history`、`afp_diagnostics`、`afp_run_control`；历史及诊断事件分页、暂停任务、归档非活跃报告 |

专用预设组合原有 14 个 AFP 工具和新增的 11 个预设内操作工具，并使用原生 Skill、只读文件、提问、待办和作业工具组织流程。其他预设继续保留原有能力，新增操作仅在 AFP 预设中提供；AFP 组合会过滤其他全局业务工具。

## 使用顺序

1. 说明题材、数量和用途；新闻图片尽量补充时间范围与地点。Agent 只加载对应 AFP Skill，并先检查能力是否可用。
2. 自由关键词搜索读取元数据；内置视觉筛选支持动物、食物、风景、电影海报和天体壁纸五类。自由搜索的结果不能直接传给 `afp_refresh`，元数据匹配也不能宣称已完成逐图视觉审核。
3. Agent 保留真实作业和报告 ID，跟踪进度，读取结束后的报告，再保存最终选图。视觉选图必须来自本轮已读取报告中保留的图片。`maxSelectionPhotos` 默认 1000，与搜索分页上限独立；收藏夹操作及下载仍以每批最多 120 张执行。
4. 要求收藏指定子集、修改整类内容或下载所选版本。预览列明目标、准确图片 ID 和增删数量，或下载费用及目录名称，再由 DSH 请求确认。最终图库不会自动缩小整类写入计划。
5. Agent 等待真实作业结果，区分完成、部分完成、结果未知和失败。报价变化后重新选择并预览；写入结果未知时先核对状态，再建立新计划。

示例：“找 20 张风景候选，先展示元数据结果。”“视觉筛选 30 张动物图，并说明保留理由。”“只把我选中的图片加入 X 收藏夹。”“将这三张图从 A 移到 B。”“下载前先列出图片版本、尺寸和积分费用。”

## 组成与状态

`cordis.patch.yml` 通过现有预设注册表声明 `afp-curator`。专用 persona 负责工作流选择和关键约束，原有六个 AFP Skill 提供搜索和分类细则；`agent.js` 注册预设内工具并过滤全局业务工具。根级 `AfpService` 继续统一管理认证、分类工作流、报告、下载和收藏夹修改，UI 与 Agent 复用同一实现。

操作预览有有效期、只能使用一次，且归发起 Session 所有。收藏夹批准绑定账号、名称和成员快照，执行时在收藏夹写入锁内再次核对；并发提交不能让同一份批准执行两次。下载确认凭据与签名地址留在 Host 下载器中。AFP 作业保留原会话归属，切换预设不会把作业转移给另一个对话。

新增操作预览只在当前 Host 内存中保留，重启或相关能力变化后需要重新预览。视觉报告和已记录的预设选择会持久保存。视觉调用继续使用 AFP 单独配置的视觉模型，与对话模型独立。

## 验证范围

无密钥夹具使用真实 Loader、预设组合、Session 循环、浏览器入口和 AFP 业务实现，并用确定性的 AFP 响应验证本地集成。真实 AFP 认证、付费视觉筛选质量、在线购买及生产收藏夹修改，需要用户配置的账号和具体操作确认后验收。
