# dsh-plugin-afp

[English](README.md) | 中文

## Summary

这是安装到 DSH profile 的独立 npm 组合包。只读工具、视觉刷新、远端写入、六个 Skill 和三个操作台入口分别开关。默认开启三项 Agent 工具能力组、六个 Skill 和全局面板；设置入口和会话 Tab 默认关闭。远端写入仍须经过写入计划和明确确认。所有入口显示同一 profile 的任务与报告，切换会话或关闭页面不会停止任务。

## 安装与开发

在仓库根目录运行 `pnpm install`：AFP 是 CLI 的 workspace 依赖。新建 Web/Desktop profile 会自动选中它，Headless 与 SDK 不启用。`pnpm run build` 会重建浏览器入口，Desktop 打包会包含 AFP tarball。AFP 保留独立包版本，不声明 DSH 精确 peer 版本。已有 profile 的 bundle 选择保持原样；替换 profile 本地安装的方法见[升级指南](../../../docs/upgrade-guide/v0.2.0-rc.2/afp-builtin/guide.zh.md)。

在根目录运行 `pnpm --filter dsh-plugin-afp test` 与 `pnpm --filter dsh-plugin-afp check`。需要经审核的独立产物时使用 `pnpm --filter dsh-plugin-afp pack`。更新仓库后执行 `pnpm install` 与 `pnpm run build`，即可更新内置包；未启用模块监听时重启 Host。包不声明独立应用 bin。代码来源及发布限制见 [UPSTREAM.md](UPSTREAM.md)。

GitHub 分发使用包自己的 `afp-v<version>` 标签，以及独立 tarball、校验值和版本元数据；见 [AFP 版本发布](release/README.zh.md)。插件详情默认自动检查稳定版本；开启「自动下载安装」后自动安装，或使用「立即更新」。新版重启生效，保留功能选择和配置；运行时更新要求当前应用已包含更新器。

## 目录约定

根目录 `index.js`、`execute.js`、`skill.js` 和生成的 `client.js` 是导出的生命周期入口；`config-schema.js` 校验部署配置。自有 Host 实现放在 `src/host/afp-*.js`；浏览器实现放在 `src/client/afp-*.js`；适配的协议与分类实现放在 `src/vendor/auto-afp-img/`。`skills/` 只存技能说明和参考文档。根目录 `cli/afp-task.js` 导出 DSH 托管的任务适配器，与 UI 调用同一个 Host 服务；`scripts/` 只存本包构建和检查脚本。修改浏览器源码后运行 `npm run build:client`，不直接修改生成的 client.js。

## 图标资源

`assets/icons/` 包含 AFP 主图标和 12 个功能 SVG。清单声明文件路径，由插件管理器在 Web 中提供资源 URL，不使用 Base64 显示。功能图标通过 CSS mask 使用页面的语义颜色 token，适配深色主题；图片加载失败时回退到分类图标。

## 实时配置

下载目录支持 Host 系统选择器和 Web 浏览式选择器。浏览弹窗列出已有 Host 目录，支持绝对路径导航；确认后绑定到有期限的 Host 目录 ID。下载计划不能直接传入路径，系统选择器部署拒绝浏览器提供的路径。选择器不创建目录或 AFP 收藏关系。

配置编辑器在首次读取时按实际表单高度显示骨架字段。视觉刷新在宽窗口中采用账户认证与模型预算的左右布局，760px 以下使用单列。字段直接显示在弹窗上，通过标题和间距分组。内容在编辑器内滚动，高级配置展开后保存按钮仍保持可见；读取失败时保留弹窗尺寸并显示错误。

操作台的“视觉模型”分区在左侧卡片显示模型设置、筛选参数和保存按钮，右侧卡片显示默认展开的高级配置。两张卡片采用 AFP 账户布局的列宽比例并保持等高，容器宽度不足 860px 时上下排列。JSON 编辑区填充右侧卡片，与普通字段共用同一份草稿和保存操作；折叠或切换分区会保留未保存内容。

包内 `config.json` 只提供初始模板。唯一的用户功能配置是 `<profile>/.plugins/dsh-plugin-afp/config.json`，包含 `version: 1` 和完整的布尔值 `features` 表。插件页面保存与手动修改都使用这份文件。有 HMR 时监听文件；没有 HMR 时重启生效。非法文件保留现场并显示错误，失败的 HMR 读取保留此前运行状态；页面保存后启用失败会恢复旧文件及运行选择。首次创建时迁移明确的旧行选择，后续启动和升级保留用户文件。修改功能 ID 或文件版本时须提供显式迁移，不直接覆盖选择。

功能键是 `read`、`refresh`、`write`、`ui-settings`、`ui-panel`、`ui-conversation` 及六个 Skill 目录名。插件详情和操作台区分已选择与实际运行状态。Home 和命令行部署覆盖仍有更高优先级。关闭组合包保留全部选择；托管 Skill 说明仅在已知包版本或与安装摘要一致时升级；自定义说明保持原样。关闭某个 UI 入口只移除入口；关闭刷新或写入能力会取消并等待相关任务释放资源。AFP 不包含提示词注入功能。 根插件通过 Cordis 服务名数组依赖 credentials、jobs、profileContext、pluginManager、configEditor、directoryPicker、sessions 和 sessionQuery；根插件停留在 pending 时，工具与技能行无法激活，仅提及插件不会使 AFP 接口可用。

凭据通过 DSH 凭据服务读取：`AFP_ACCESS_TOKEN`，或 `AFP_USERNAME` + `AFP_PASSWORD`，以及 `VISION_API_KEY`。这里只配置引用名称，不能写入凭据值；token 缓存也保存在凭据服务。配置弹窗只有在 AFP 用户名和密码均已填写时才启用“获取令牌”；它会先保存当前填写值，再复用运行时的登录流程取得或刷新令牌。请求期间按钮显示加载动画，获取操作不会返回令牌或写入插件 JSON；点击小眼睛可按需查看已保存的凭据。Cordis 根行 `afp` 配置 `visionBaseUrl` 和 `visionModel`，示例见 [config.example.patch.yml](config.example.patch.yml)。接口地址、模型、超时、预算和 `pollIntervalMs` 属于部署配置，不进入功能 JSON。旧 `allowWrites` 字段仅为已有运行记录兼容而接受，不再赋予写入权限；写入由 `write` 功能行控制。只提供 token 时，更换 token 会改变账户标识；提供用户名可保持标识稳定。

凭据输入使用视觉遮罩并关闭浏览器自动填充，由 DSH 管理已保存值；小眼睛仍可独立显示或隐藏各字段。工作台账户卡片填满所在网格列，与账户信息卡片保持 16px 间距；容器宽度不足 860px 时上下排列。

## 会话搜索与最终图片

普通找图不枚举固定分类收藏夹，也不启动视觉策展。完整的安全图片元数据保存于 profile 的 conversation-results 目录，绑定 Session、Turn 及成功调用身份；不含凭据值、签名媒体地址或图片字节。原生结果持久化展示元数据，嵌套调用通过 resultRef 和认证的 conversation-result 操作读取完整记录。其他轮次、失败调用及不匹配的调用身份不能提供选图证据，不自动修复已有失败会话。

模型接收由 agentResultMaxBytes 限制的有效 JSON，默认 16384，范围 4096–65536。afp_result_page 仅读取剩余本地元数据，不再次请求 AFP。新搜索、详情、收藏夹成员和最终选择记录不依赖通用输出截断。afp_photo_selection 使用 basis=metadata、runId=null，或 basis=visual 加上本轮成功读取的真实运行报告 ID。afp_report 接收 kind=run|plan 和 id；afp_refresh 新建使用 mode=start、categories、runId=null，续跑使用 mode=resume、categories=[] 及真实 runId。收藏夹写入授权不变。

AFP 不再注册输入框上方的独立进度胶囊。任务计划由原生任务清单展示，实际检索和视觉校验进度保留在聊天行内折叠输出；工作台和下载进度入口保持可用。

过程中保留一份可折叠候选图库，完成后收起。仅成功保存的明确选择生成最终图库及结构化表格，保持选图顺序，显示说明、AFP 图片 ID 和不含登录 token 的同源认证预览链接。元数据结果明确未视觉复核，视觉合格状态来自已保存报告。重开读取持久元数据，不从回答文字推测最终图片。Agent 回答采用“结果与数量、标准与依据、未满足要求或错误”三个简短段落；选图失败不能用手写清单或缩写 ID 代替。界面统一展示图库、结果表和已保存的筛选标准。

## 操作台与工具

会话图片列表的箭头切换使用可反向的缓动；连续点击推进未完成的目标位置，滚轮、指针或键盘输入会取消动画。减少动态效果时直接定位。宿主支持时，总结图库使用共享高度折叠动画。

状态检查完成与实际 AFP 读取成功使用不同说明。进度面板关闭后焦点返回胶囊；分页工具仅由图库注册展示。图库没有水平溢出时隐藏翻页提示；窄屏最终结果表保留列宽并在独立、可键盘聚焦的区域内横向滚动。空白或横线占位标题使用说明或本地化名称兜底，不修改原始元数据。下载弹窗高度随内容收紧，多图列表单独限高滚动。

三处入口分别注册 `settings.section`、`sidebar.panellist` + `main`、`conversation.view`，共同显示五个工作台页签。账户元数据、图片搜索与详情、收藏夹内容、任务和计划历史都经认证的 Host API 读取；图片预览使用同源认证二进制路由，不落盘也不转为 Base64。无法读取的账户资料显示为未知；共享或未分类收藏夹只读；选中的图片可以在明确确认后加入已命名的私有收藏夹。刷新任务可单独设置目标数量和置信度阈值。新计划记录创建时间，旧计划日期显示为未知。图片读取结果新增不透明 resultRef；Agent 报告使用 kind 和 id，最终选图需要 basis 和可空 runId，视觉刷新需要 start/resume 模式及可空 runId。全零 ID 在 AFP 请求前拒绝。任务属于当前 profile，会话 Tab 展示同一组任务，而不是独立 Session 队列。修改客户端源码后运行 `npm run build:client` 生成 `client.js`，不要直接编辑生成文件。移除全局入口时，当前面板返回会话；设置和会话页由现有壳处理导航回退。

搜索框提供本地关键词菜单，词库在构建时从插件搜索配置的正向词生成，并补充常用中文别名和分类筛选。输入时不调用 AFP 或模型；方向键高亮选项，Enter 填入高亮词，没有高亮时 Enter 搜索当前输入。Esc 或点击外部收起菜单，输入法组合期间的 Enter 不发起搜索。搜索操作栏可将最多 120 张已选图片加入已有可写收藏夹。弹窗固定打开时的批次，刷新目标目录并要求明确确认；保留原有收藏关系和实时选图。结果区分新加入、已存在、失败和待核实；旧 Host 在重载前仅显示完成数。不自动重试结果不明的写入。修改关键词配置后须重新构建客户端；插件检查会拒绝过期的生成词库。

搜索和收藏夹翻页保留已有图片，在同一响应式网格末尾追加卡片骨架屏。首次搜索与下一页加载使用独立的按钮状态。下一页失败时保留当前游标或偏移，重试读取该页，不重置列表。成功页按图片 ID 去重；空页、纯重复页或搜索游标循环会暂停翻页。重新搜索会取消未完成的分页读取并重置游标记录，保留已选图片。

既有工具继续可用：`afp_status`、`afp_search_plan`、`afp_collections`、`afp_report`、`afp_plan_change`、`afp_refresh`、`afp_apply`。实际读取先调用 `afp_photo_search_start`（query、language、limit 必填，没有 cursor 字段），hasMore 为 true 时再调用 `afp_photo_search`，使用返回游标并保持查询和语言不变。`afp_photo_details`、`afp_collection_list` 和 `afp_collection_items` 读取元数据。搜索使用说明文字及支持的语言，不执行离线计划筛选或自动翻译。原工具仍支持首屏省略 cursor；已知无效占位值 "0" 和 "?" 在本地拒绝，重复调用也不请求远端。Agent 目录排除空名称条目并返回 meta.excludedUnnamedCount；直接读取此类条目会在获取成员前拒绝，正常命名的共享收藏夹仍可读取。成员分页返回 collectionNextOffset 用于 AFP 翻页，null 表示结束；offset/nextOffset 用于本地结果分页。新读取返回允许的元数据、同源 previewPath 及 meta.durationMs，不含上游签名媒体链接或图片字节；详情不存在时返回 found:false。工具错误保留 DSH 错误状态，提供安全的 code、stage、message、action、retryable 和 durationMs 字段，不返回上游正文。无效游标给出固定参数指导；GraphQL 失败仅返回白名单中的 upstream 协议、HTTP 状态和类别，认证、权限及接口字段错误分别分类。未知 GraphQL 原因保持未确认，不应因此连续更换关键词；未知读取失败不提示部分写入。只有明确可重试的读取才能重试，不重复提交不变的非重试参数。Agent 任务属于调用会话，并走 DSH 确认流程；页面任务属于 profile。页面先预览精确目标及增删数量，再提交一次性、有期限的确认凭据；凭据在任务入队前消费，重启或关闭写入后失效。两种入口都会在写入前复核账户、精确私有目标名、完整收藏夹成员和引用的运行记录，并在第一次修改前消费计划。写入不自动重试或回滚；失败、取消可能已经部分写入，须先检查保留的报告和收藏夹，再生成新计划。

会话搜索标题、状态和查看记录操作使用 DisclosureRow 的次级字号，随内容字号设置同步。失败或空结果用简短状态及同行的查看记录操作呈现；不回显未允许的远端文本。

会话展示遵循[会话搜索与最终图片](#conversation-search-and-final-results)。卡片保持 176px 宽度，支持横向浏览和大图操作；画廊和弹窗省略重复权限提示，实际权限检查继续生效。

候选和最终图片列表可通过标题、Enter 或空格键折叠和展开。最终图库默认展开；折叠关闭大图并在高度退出动画完成后卸载缩略图，重新展开恢复浏览。

会话图片卡片通过 `tool.call.toolview` 按工具名称注册，覆盖实际搜索、搜索续页、详情及收藏夹成员结果，不依赖 `ui-conversation` 工作台页签开关。卡片从会话已记录的元数据重建标题、provider 和图片 ID，默认以单行横向列表显示缩略图；触控滑动、滚动条及左右按钮浏览当前结果，滚动和尺寸变化更新按钮边界。点击图片或标题使用现有 Modal 放大，多图弹窗提供上一张、下一张、位置计数及左右方向键，首尾不循环；编辑控件保留自身方向键。图片 ID 默认折叠，来源、说明和预览操作分区显示；打开预览链接在当前 DSH Web 地址下解析。旧记录缺少 previewPath 时按 ID 重建同一路由。链接需要当前 DSH 登录态、读取能力及有效 AFP 凭据，不能作为公开 AFP 外链或原图下载地址；Agent 应引导用户点击卡片，不能猜测站点 origin。卡片不自动翻页，不调用搜索、刷新、购买、下载或收藏夹变更；栅格请求复用工作台缓存与取消流程，凭据及权限变化时清空。插件停用后插槽随生命周期移除。

工作台占满可用高度，标题和单行滚动标签页保留在内容区上方。宽屏搜索页固定工具栏，结果与详情独立滚动，并区分初始提示、加载、无结果和可重试的读取失败。任务、变更和收藏夹两栏独立滚动，分隔线贯穿可用高度，窄窗口纵向排列。筛选配置集中显示分类；数量或评分不合法时禁用提交并显示字段说明。报告加载与失败留在报告区域，不会被历史列表替代。任务与变更历史共用行骨架屏和项目刷新控件。变更页将配置与预览、历史分开；预览期限、写入提示和明确确认仍是写入前提。账户与设置使用项目分段控件，凭据和模型字段分组显示，用户身份与积分使用紧凑信息区；切换分区保留草稿。筛选参数和部署 JSON 默认折叠。功能按分类网格排列，使用轻量运行状态和可展开说明。输入、菜单、标签、气泡和按钮加载指示沿用项目组件与主题 token；入场和展开动画尊重减少动态效果设置。续跑输入按需展开，图片详情保留完整筛选理由。

账户卡片并排时使用一致的主题背景并保持等高，保存按钮位于凭据卡片内；高级配置从右对齐的入口展开。收藏夹全选会读完全部元数据分页再更新选择，可取消读取；取消全选保留其他收藏夹的选择来源，不会一次加载全部预览或展开画廊分页。读取失败保留原有选择。现有下载协议每批最多接受 120 张图片，超过时下载按钮禁用并显示提示。下载悬浮入口使用主题阴影，在任务进行时显示 SVG 动画，并遵循减少动态效果设置；右键或 Shift+F10 打开项目菜单，其中任务页面入口需启用全局工作台。关闭图标使用项目的 14px 图标和 28px 点击区域。

## 内容归属与恢复

### AFP 认证自动恢复

Hub 可能将刷新拒绝包装为 GraphQL HTTP 200，消息为固定的 `Request failed with status code 401`。Host 仅对 `refreshToken` 将此响应分类为认证失败，允许一次登录回退；包装的 403、服务、协议和未知错误不会触发此回退。配置获取失败返回 `acquired: false` 与固定的安全错误类别；编辑器区分认证、权限及临时服务错误，不返回上游文本，也不显示成功提示。

部署字段 `autoRefreshToken` 默认 `true`，可在高级配置 JSON 中关闭。Host 用 FAR `getPhotos` 的最小元数据查询验证图片读取能力，不再将 SLT 收藏夹接口的 HTTP 200 当作图片认证成功。JWT 在 `tokenRefreshMarginSeconds` 窗口内提前更新；无法解码期限的 opaque token 在每次打开连接时验证。明确的 HTTP 401 或 GraphQL 固定认证类别触发恢复。FAR 也会以 GraphQL FORBIDDEN 拒绝旧 grant：仅缓存 token 的校验阶段对此允许一次更新，新 grant 必须通过 FAR 校验后才能保存。业务权限拒绝、新 grant 被拒绝、HTTP 403、查询、协议、未知错误和限流不会触发恢复循环。只有静态 token 且没有用户名、密码或刷新 grant 的账号无法自动恢复。

登录取得的 access/refresh grant 仅保存在 DSH 凭据服务。Host 先使用官网 Hub `refreshToken` mutation；只有刷新凭据被明确拒绝且已配置用户名、密码时才回退登录。旧缓存只有 access token 时，首次认证拒绝会登录并补齐刷新凭据。认证请求不自动重试，新 token 必须通过 FAR 校验才能保存。每个账户的凭据服务串行更新 grant，并记录 generation；即使刷新返回相同 access token，并发失败也只需一次更新。

读取在打开连接后失去认证时，最多更新一次凭据并重放一次原读取；第二次认证拒绝直接失败。购买、交付下载及收藏夹写入不会因此重放，取消的操作不会提交 grant 或继续读取。工具、会话、运行记录和普通配置读取不返回刷新凭据。Agent 错误区分认证失败、权限拒绝、查询拒绝和 `upstream-error`；未知 GraphQL 错误不再表示查询参数一定错误。`verifiedAt` 表示最近 FAR 校验时间，并非远端声明的到期时间。

账户分区经 Host 读取 Hub `user` 查询，在凭据表单右侧显示姓名、邮箱、用户与客户 ID 和 `credit.amount`。余额为零时显示零；接口未提供余额时显示暂未提供。账户资料的加载和重试不阻塞凭据编辑，不调用管理员、购买或下载历史接口。已保存的密码与密钥继续留在凭据服务。

收藏夹侧栏只列出已命名收藏夹，使用紧凑的项目 Button 单行显示文件夹图标、名称和数量，并复用悬浮及焦点滑动高亮。只读或共享权限使用 Tag，可写的私有收藏夹省略重复权限标签；首次选取跳过未命名项。折叠按钮紧邻搜索框；收起后保留可切换收藏夹的简称入口，悬停与键盘聚焦提示完整名称、权限和数量。宽屏保留56px紧凑栏，窄屏使用横向列表；宽度与文字过渡沿用模型页侧栏，并遵循减少动态效果设置。折叠保留筛选词、当前收藏夹和图片选择。图片选取使用项目 Button 内的紧凑毛玻璃圆角方框、白色 SVG 对钩和按下状态；方框以半透明背景和局部背景模糊显示，不支持滤镜时使用实色，并以同色画框描边标识选中；选中、悬浮或键盘聚焦时显示，选取不会打开详情。图库卡片在加载、成功及失败时使用一致的 4:3 预览画框；缩略图等比裁切铺满画框，详情和大图预览继续保留完整构图。选图清单通过操作栏摘要按钮展开或收起，不重复显示标题栏关闭按钮。宽屏清单占满图库可用高度，标题和清空操作固定，只有图片列表独立滚动；窄屏保留高度受限的纵向布局。行内移除按钮在悬浮或键盘聚焦时显示，触屏设备直接显示；操作气泡使用简短的本地化文案和受限宽度，按钮的无障碍名称保留完整图片标题。收起清单保留所选图片。AFP选择菜单按真实触发按钮定位，并在限高卡片内滚动；收藏夹操作弹窗采用紧凑、清晰的内容布局。选图摘要将最多三张完整缩略图、溢出数量和计数 Tag 合并为一个清单开关，批量操作按钮独立保留。AFP 设置区隐藏外壳底部操作栏，为工作台释放高度。图片列表只排除 `docClass` 明确标识的非图片成员，保留缺少该字段的旧成员；写入校验仍检查完整成员。图库与详情独立滚动，超过半个图库可见高度后显示回到顶部。骨架屏与图片淡入尊重减少动态效果设置；点击详情预览使用项目 Modal 展示，并在关闭后恢复焦点。预览持有共享栅格 Blob URL 租约，最后一个使用者退出时回收 URL。Host 协商 JPEG、PNG、WebP、GIF，按签名接受标为通用二进制的图片，拒绝 HTML 与 SVG。CDN 被阻止时只显示域名；核实域名后再加入部署 `previewCdnHosts`。签名媒体链接与 AFP 凭据不进入浏览器元数据。

选图可以跨收藏夹保留，并记录每张图片的来源。移出操作只解除单张图片关系，不删除图片或收藏夹。复制和转移要求目标可写；转移前先确认图片已加入目标，再从可写来源移除。下载会列出 AFP 提供的画质和费用，默认选择最高的免费画质；任何付费总额都需在重新核对余额和报价后明确确认，付费选项受 `write` 功能开关保护。若 AFP 已接受购买却未返回已确认的下载地址，该图片会标记为待处理，系统不会自动再次购买。文件流式写入用户在 AFP Host 上选择的目录，并限制文件大小、清理原始文件名及为重名文件添加序号。关闭或切换工作台不会停止 profile 下载任务；Host 停止后任务终止。保存的任务记录不包含目录、凭据或签名链接。

下载弹窗占满可用高度，宽屏画质和设置两栏独立滚动，窄屏使用一列滚动，底部费用与操作栏固定。紧凑图片行只显示一处尺寸、大小和费用，逐张画质菜单仍提供完整报价。顶部图标可刷新报价，或批量选择最高免费、最高可用及 AFP 返回的具体画质。批量匹配使用每张图片自己的画质 ID；没有匹配或权限不允许的图片保留原选择，并显示应用数量。批量更改使已有报价确认失效，不会提交购买。报价加载保留同一组带键的行、缩略图和滚动容器；尚未返回的元数据与画质操作从连续扫光骨架交叉淡入。刷新保留已有画质。加载过渡与按钮转圈遵循减少动态效果设置。下载被接收后显示全局通知，可直接打开进度；默认收起的屏幕边缘入口支持查看近期批次和取消任务，切换工作台页面后仍可使用，进度采用 Host 的持久化计数。按 Escape 或点击外部收起卡片。边缘入口的右键菜单可在当前客户端隐藏入口，不取消任务或丢弃历史；进度通知或新下载被接收后恢复显示。文件名前后缀默认折叠。单张读取失败不阻止其他图片；余额无法读取时允许免费画质，阻止付费画质。更改画质、命名前后缀或保存目录会使已有检查结果失效；报价变化须重新检查并确认扣分。报价未知时不显示数字总额。最终文件优先采用交付名称；预览使用完整 GUID/图片 ID 作为回退，标识中的点不会被当作扩展名删除。

六个 DSH Skill 要求 Agent 在执行 AFP 操作前先用原生 todo_write 创建清单，并依据实际工具结果更新。选 10 张图片等普通单轮任务不创建目标；只有资源目标确实很大且需要跨轮持续执行时，才考虑运行时目标工具。保留已有目标和其他未完成任务。这是模型执行说明，不是 Host 自动写入清单。重新加载插件会升级已知的托管说明，自定义说明保持原样。

六个 Skill 分别在 `$DSH_HOME/.plugins/dsh-plugin-afp/skills/` 保存进程/profile 持有者。最后一个持有者停用后，托管目录从 `$DSH_HOME/skills/` 移入私有停用区；对托管内容的编辑会保留并在再次开启时恢复。同名用户目录、归属标记损坏、链接路径和副本冲突会拒绝覆盖。由于扫描目录共享，同 Home 的另一个 profile 仍可能使 Skill 可见。异常退出的持有者在下次管理操作核对恢复；已有会话历史不会删除。

原有 run/plan UUID 及记录位置保持稳定：`$DSH_HOME/.plugins/dsh-plugin-afp/profiles/<profile-hash>/`。视觉任务失败或取消保留 pending 候选和游标，以便续跑。Home 范围的账户/运行锁阻止并发操作；不完整锁或遗留恢复锁会拒绝工作，须停止持有者后检查现场。报告只返回数量和脱敏错误，不返回凭据或预览字节；本地运行记录仍包含候选元数据，应作为私有数据保管。

下载选项和计划绑定 Host 账户标识；准备、确认或执行前更换账户会拒绝旧批次。报价变化使用同一次刷新快照，返回完整画质选项供再次明确确认。收藏夹操作结果显示部分失败和待核实数量；重置账户会丢弃迟到的操作响应。启动失败或 Host 中断会终结每个未完成项，并同步汇总计数。任务失败只输出固定错误码，不暴露原始认证或交付错误。

## 预览缓存

预览在等待、请求及解码期间使用极简骨架：平整底色覆盖图片区域，一条低对比度斜向反光缓慢掠过；标题和操作区保持可见。动画只使用 CSS transform，不使用 Three.js、Canvas、WebGL 或 JavaScript 帧循环。离屏、inert 或页面隐藏时暂停；图片加载事件触发后移除骨架，失败后保留重试操作。减少动态效果时显示静态背景；部署设置 `previewAnimationEnabled`（默认 true）可关闭扫光。本地化加载状态仍可供辅助技术读取，不显示虚假进度或额外转圈文字。组件退出后断开交叉观察器与页面可见性监听。

预览恢复由部署项 `previewRetryCount`（默认2，0关闭，最大3）和 `previewRetryDelayMs`（默认1000毫秒，范围100..30000）控制。临时网络、超时、限流和服务错误仅重新读取当前预览，等待时间指数递增；获取与解码失败共用每个预览的次数预算。画框不可见或页面隐藏时暂停，卸载、图片切换、权限或凭据范围变化时取消。次数耗尽后显示紧凑错误占位与“重新加载”；手动刷新开启新的预算并失效该预览缓存。认证、CDN未放行、不支持的栅格图片及未知代理错误不自动重试。代理只返回安全的retryable标志，不回显提供方诊断。并发使用者继续共享请求和已成功的缓存。旧Host缺少策略时保留手动刷新；安装这些Host修改后需重启应用。预览恢复不重放搜索、购买、下载或收藏夹写入。

插件 store 管理页面内存缓存，图库、详情、清单和下载缩略图共用。同一图片的并发消费者合并为一次请求，成功的栅格 Blob 通过 LRU 保留。部署 JSON 可设置 `previewCacheMaxEntries`（默认 300，设为 0 关闭保留）、`previewCacheMaxBytes`（64 MiB）和 `previewCacheTtlMs`（10 分钟）。访问、释放和检查缓存时清理过期条目；条目与字节上限只约束保留的 Blob，不包含正在显示的图片、DOM 和解码内存。关闭一个消费者只取消自己的订阅，最后一个等待者退出才终止请求；最后一个 URL 租约释放时回收对象 URL。请求失败不缓存，解码失败和主动重试使对应版本失效。凭据、读取权限、连接和 Host 实例变化时清空预览，旧响应不能回填；插件卸载等待所属读取结束。刷新整个浏览器会清空内存；不保存持久文件、签名地址、凭据、付费原图或报价。Host 响应继续使用认证和 `no-store`。

`node scripts/benchmark-preview-cache.mjs` 使用离线 40 ms 传输比较六个无缓存与有缓存消费者，校验请求次数，不代表浏览器绘制速度。

## 验证范围

“视觉校验”行在收起和展开时均保留标题摘要，集中显示分类、判断或预览数量、保留和请求失败；类别目标、保存状态和最终选图含义放在提示中，不再重复堆叠计数和说明段落。展开的实时行将当前阶段与大于零的待判断图片数量合并为一行，复用“思考”的 TextShimmer；只有所属任务正在运行、连接正常且展开时播放，遵循减少动态效果偏好。收起时标题显示流光，展开后标题停止流光，仅正文阶段行播放。“已通过”和“未通过”是两个独立折叠区，默认收起，带图像图标；各横向列表最多显示五张缩略图，窄屏显示更少，横向滚动可查看全部其余图片，不截断结果。展开或收起一个列表不会影响另一个。请求失败在标题中单列，不计入未通过；等待判断数量放在阶段流光行，不在图片列表下重复显示。分类依据原调用认证结果或实时已落盘批次的逐图结论，历史记录缺少结论时明确说明，不显示虚假的零数量，也不用后来变化的报告补齐。固定淘汰原因在对应缩略图的提示中显示。点击图片使用与 AFP 操作台相同的 PreviewModal，保持尺寸、contain 显示、重试、Esc 关闭和焦点恢复一致。窄屏标题使用省略显示，完整摘要保留在提示中。历史认证结果在展开后读取，缩略图仅在所属列表展开时挂载，预览内容仅在可见时加载。仅供界面使用的图片身份与逐图结论保留在原结果缓存及实时进度中，不进入模型工具文本或后台任务输出。

会话反馈沿用“思考”的行内折叠：标题保留检查事实，展开显示分类图片列表，不使用卡片背景或边框。已保存的部分结果与最终选图保持区分。会话与操作台显示连接验证、账户收藏夹去重、预览读取、像素判断及风景二次确认阶段。准备阶段即保存 `running` 和 `stage`，连接与收藏夹读取各以 `requestTimeoutMs` 限制总等待，避免重试延长启动。相同运行仍有活跃任务时不能续跑；等待原任务结束后使用原 `runId` 恢复检查点。启动句柄不表示审核或最终选图完成，类别精筛也不会直接审核前一轮自由检索的候选。报告分别列出完成像素判断、保留、未保留、目标及请求失败，只有固定淘汰类型进入摘要；请求失败不算视觉淘汰。实时预览计数属于当前批次，像素判断计数累计已保存结果和当前批次。同轮相同报告读取合并展示，原始工具记录仍可检查。胶囊悬浮采用不透明主题背景，不使用背景模糊。

视觉去重读取有名称的账户可见收藏夹，包括共享收藏夹。无名称的目录或系统项与收藏夹页面一样被排除，其标识不会传入普通收藏夹详情接口。有名称的收藏夹读取失败仍会在像素审核前中止任务。

视觉 Chat Completions 请求不指定 `temperature`，兼容只接受供应商默认采样值的推理模型。

筛选失败日志只记录本地阶段和代码位置，不含供应商异常正文或凭据。状态轮询发现保存摘要变化时，自动刷新打开的报告，保留分类与结果筛选条件，并使旧写入预览失效。

`npm test` 使用模拟 AFP 接口与隔离的临时 Home，不执行真实 AFP 写入。会话快照测试消费仓库 `pnpm run build:lib` 的产物，独立副本缺少仓库时明确跳过；它记录真实 Agent 循环调用离线搜索及停用后的工具列表。`npm run check` 检查语法、exports、默认功能、发布文档和 UTF-8。仓库聚焦测试覆盖 JSON 选择迁移、单行开关、手动 HMR 修改、启用失败回滚及旧 bundle 兼容。打包安装和浏览器验证使用当前仓库构建。模拟通过不代表线上接口、账户权限或素材使用许可已经验证。

## 功能介绍与配置弹窗

插件详情按类型分组，通过标题展开说明，开关旁显示状态标签；组件列表默认折叠。点击功能名称在浅色说明块中展开简洁的用途、使用条件与相关影响，并提供展开和收起过渡；脚本与工具开关旁的编辑按钮打开共享配置弹窗。弹窗沿用 DSH Modal、Input 和 Button，常用模型与预算字段直接编辑，完整 JSON 收在“高级配置”中。已保存的用户名正常回显；已配置的密码、令牌和视觉模型密钥在输入框内显示固定长度遮罩，并使用成功状态标签。小眼睛可显示本地草稿，或通过绑定当前部署版本的 AFP 私有认证操作读取单个已保存的值，包括有效的缓存令牌。常规配置读取不返回密钥，单纯查看不会写入凭据。隐藏、切换分区或保存时清除已查看的值；编辑或关闭后到达的旧响应会被忽略。查看失败保留遮罩并允许重试。敏感字段写入成功后清空草稿并重新隐藏。弹窗输入框将边框和内边距计入宽度，按容器宽度调整列数，避免裁切和重叠。四个字段写入当前部署引用的 DSH 凭据服务，留空保留已有值；部署 JSON 只存引用名、接口、模型和预算，由 profile 配置编辑器保存并重载。部署保存会取消活动任务，凭据保存不重载。两类保存分别反馈结果；成功的凭据写入不会因后续部署失败撤销。修改引用名后重新打开弹窗再保存凭据。
