# dsh-plugin-afp

[English](README.md) | 中文

## Summary

这是安装到 DSH profile 的独立 npm 组合包。只读工具、视觉刷新、远端写入、六个 Skill 和三个操作台入口分别开关。默认开启三项 Agent 工具、六个 Skill 和全局面板；设置入口和会话 Tab 默认关闭。远端写入仍须经过写入计划和明确确认。所有入口显示同一 profile 的任务与报告，切换会话或关闭页面不会停止任务。

## 安装与开发

在本包目录依次运行 `pnpm install --ignore-workspace --config.auto-install-peers=false`、`npm run build:client`、`npm test`、`npm run check`、`npm pack`。通过 `dsh plugin --profile web add <绝对路径的tarball>` 或“插件 → 添加插件”安装打包产物。开发时也可执行 `dsh plugin --profile web add file:D:/project/deepseek-harness/custom-plugins/workspace/dsh-plugin-afp`。使用当前仓库构建的 DSH；此前发布的运行时尚不支持新的 featureConfig 声明。

用自己的 npm 账号发布经过审核的包后，用户可在同一插件页面输入 `dsh-plugin-afp@<版本>`，或运行 `dsh plugin --profile web add dsh-plugin-afp@<版本>`。未启用模块监听时，更新已安装的包后须重启运行中的 Host；仅替换文件不会重载已导入的操作。无需全局安装。包不声明独立应用 bin。代码来源及发布限制见 [UPSTREAM.md](UPSTREAM.md)。

## 目录约定

根目录 `index.js`、`execute.js`、`skill.js` 和生成的 `client.js` 是导出的生命周期入口；`config-schema.js` 校验部署配置。自有 Host 实现放在 `src/host/afp-*.js`；浏览器实现放在 `src/client/afp-*.js`；适配的协议与分类实现放在 `src/vendor/auto-afp-img/`。`skills/` 只存技能说明和参考文档。根目录 `cli/afp-task.js` 导出 DSH 托管的任务适配器，与 UI 调用同一个 Host 服务；`scripts/` 只存本包构建和检查脚本。修改浏览器源码后运行 `npm run build:client`，不直接修改生成的 client.js。

## 图标资源

`assets/icons/` 包含 AFP 主图标和 12 个功能 SVG。清单声明文件路径，由插件管理器在 Web 中提供资源 URL，不使用 Base64 显示。功能图标通过 CSS mask 使用页面的语义颜色 token，适配深色主题；图片加载失败时回退到分类图标。

## 实时配置

配置编辑器在首次读取时按实际表单高度显示骨架字段。视觉刷新在宽窗口中采用账户认证与模型预算的左右布局，760px 以下使用单列。字段直接显示在弹窗上，通过标题和间距分组。内容在编辑器内滚动，高级配置展开后保存按钮仍保持可见；读取失败时保留弹窗尺寸并显示错误。

操作台的“视觉模型”分区在左侧卡片显示模型设置、筛选参数和保存按钮，右侧卡片显示默认展开的高级配置。两张卡片采用 AFP 账户布局的列宽比例并保持等高，容器宽度不足 860px 时上下排列。JSON 编辑区填充右侧卡片，与普通字段共用同一份草稿和保存操作；折叠或切换分区会保留未保存内容。

包内 `config.json` 只提供初始模板。唯一的用户功能配置是 `<profile>/.plugins/dsh-plugin-afp/config.json`，包含 `version: 1` 和完整的布尔值 `features` 表。插件页面保存与手动修改都使用这份文件。有 HMR 时监听文件；没有 HMR 时重启生效。非法文件保留现场并显示错误，失败的 HMR 读取保留此前运行状态；页面保存后启用失败会恢复旧文件及运行选择。首次创建时迁移明确的旧行选择，后续启动和升级保留用户文件。修改功能 ID 或文件版本时须提供显式迁移，不直接覆盖选择。

功能键是 `read`、`refresh`、`write`、`ui-settings`、`ui-panel`、`ui-conversation` 及六个 Skill 目录名。插件详情和操作台区分已选择与实际运行状态。Home 和命令行部署覆盖仍有更高优先级。关闭组合包保留全部选择；关闭一个页面入口只移除该入口；关闭刷新或写入能力会取消并等待相关任务释放资源。AFP 不包含提示词注入功能。

凭据通过 DSH 凭据服务读取：`AFP_ACCESS_TOKEN`，或 `AFP_USERNAME` + `AFP_PASSWORD`，以及 `VISION_API_KEY`。这里只配置引用名称，不能写入凭据值；token 缓存也保存在凭据服务。配置弹窗只有在 AFP 用户名和密码均已填写时才启用“获取令牌”；它会先保存当前填写值，再复用运行时的登录流程取得或刷新令牌。请求期间按钮显示加载动画，令牌不会回显到页面或写入插件 JSON。Cordis 根行 `afp` 配置 `visionBaseUrl` 和 `visionModel`，示例见 [config.example.patch.yml](config.example.patch.yml)。接口地址、模型、超时、预算和 `pollIntervalMs` 属于部署配置，不进入功能 JSON。旧 `allowWrites` 字段仅为已有运行记录兼容而接受，不再赋予写入权限；写入由 `write` 功能行控制。只提供 token 时，更换 token 会改变账户标识；提供用户名可保持标识稳定。

## 操作台与工具

三处入口分别注册 `settings.section`、`sidebar.panellist` + `main`、`conversation.view`，共同显示五个工作台页签。账户元数据、图片搜索与详情、收藏夹内容、任务和计划历史都经认证的 Host API 读取；图片预览使用同源认证二进制路由，不落盘也不转为 Base64。无法读取的账户资料显示为未知；共享或未分类收藏夹只读；选中的图片可以在明确确认后加入已命名的私有收藏夹。刷新任务可单独设置目标数量和置信度阈值。新计划记录创建时间，旧计划日期显示为未知。Agent 工具名称和输出保持不变。任务属于当前 profile，会话 Tab 展示同一组任务，而不是独立 Session 队列。修改客户端源码后运行 `npm run build:client` 生成 `client.js`，不要直接编辑生成文件。移除全局入口时，当前面板返回会话；设置和会话页由现有壳处理导航回退。

搜索框提供本地关键词菜单，词库在构建时从插件搜索配置的正向词生成，并补充常用中文别名和分类筛选。输入时不调用 AFP 或模型；方向键高亮选项，Enter 填入高亮词，没有高亮时 Enter 搜索当前输入。Esc 或点击外部收起菜单，输入法组合期间的 Enter 不发起搜索。搜索操作栏可将最多 120 张已选图片加入已有可写收藏夹。弹窗固定打开时的批次，刷新目标目录并要求明确确认；保留原有收藏关系和实时选图。结果区分新加入、已存在、失败和待核实；旧 Host 在重载前仅显示完成数。不自动重试结果不明的写入。修改关键词配置后须重新构建客户端；插件检查会拒绝过期的生成词库。

搜索和收藏夹翻页保留已有图片，在同一响应式网格末尾追加卡片骨架屏。首次搜索与下一页加载使用独立的按钮状态。下一页失败时保留当前游标或偏移，重试读取该页，不重置列表。成功页按图片 ID 去重；空页、纯重复页或搜索游标循环会暂停翻页。重新搜索会取消未完成的分页读取并重置游标记录，保留已选图片。

Agent 工具名称保持稳定：`afp_status`、`afp_search_plan`、`afp_collections`、`afp_report`、`afp_plan_change`、`afp_refresh`、`afp_apply`。Agent 任务属于调用会话，并走 DSH 确认流程；页面任务属于 profile。页面先预览精确目标及增删数量，再提交一次性、有期限的确认凭据；凭据在任务入队前消费，重启或关闭写入后失效。两种入口都会在写入前复核账户、精确私有目标名、完整收藏夹成员和引用的运行记录，并在第一次修改前消费计划。写入不自动重试或回滚；失败、取消可能已经部分写入，须先检查保留的报告和收藏夹，再生成新计划。

工作台占满可用高度，标题和单行滚动标签页保留在内容区上方。宽屏搜索页固定工具栏，结果与详情独立滚动，并区分初始提示、加载、无结果和可重试的读取失败。任务、变更和收藏夹两栏独立滚动，分隔线贯穿可用高度，窄窗口纵向排列。筛选配置集中显示分类；数量或评分不合法时禁用提交并显示字段说明。报告加载与失败留在报告区域，不会被历史列表替代。任务与变更历史共用行骨架屏和项目刷新控件。变更页将配置与预览、历史分开；预览期限、写入提示和明确确认仍是写入前提。账户与设置使用项目分段控件，凭据和模型字段分组显示，用户身份与积分使用紧凑信息区；切换分区保留草稿。筛选参数和部署 JSON 默认折叠。功能按分类网格排列，使用轻量运行状态和可展开说明。输入、菜单、标签、气泡和按钮加载指示沿用项目组件与主题 token；入场和展开动画尊重减少动态效果设置。续跑输入按需展开，图片详情保留完整筛选理由。

账户卡片并排时使用一致的主题背景并保持等高，保存按钮位于凭据卡片内；高级配置从右对齐的入口展开。收藏夹全选会读完全部元数据分页再更新选择，可取消读取；取消全选保留其他收藏夹的选择来源，不会一次加载全部预览或展开画廊分页。读取失败保留原有选择。现有下载协议每批最多接受 120 张图片，超过时下载按钮禁用并显示提示。下载悬浮入口使用主题阴影，在任务进行时显示 SVG 动画，并遵循减少动态效果设置；右键或 Shift+F10 打开项目菜单，其中任务页面入口需启用全局工作台。关闭图标使用项目的 14px 图标和 28px 点击区域。

## 内容归属与恢复

账户分区经 Host 读取 Hub `user` 查询，在凭据表单右侧显示姓名、邮箱、用户与客户 ID 和 `credit.amount`。余额为零时显示零；接口未提供余额时显示暂未提供。账户资料的加载和重试不阻塞凭据编辑，不调用管理员、购买或下载历史接口。已保存的密码与密钥继续留在凭据服务。

收藏夹侧栏只列出已命名收藏夹，使用紧凑的项目 Button 单行显示文件夹图标、名称和数量，并复用悬浮及焦点滑动高亮。只读或共享权限使用 Tag，可写的私有收藏夹省略重复权限标签；首次选取跳过未命名项。折叠按钮紧邻搜索框，收起后保留展开入口。图片选取使用项目 Button 内的小圆形 SVG 对钩和按下状态；选中、悬浮或键盘聚焦时显示，选取不会打开详情。图库卡片在加载、成功及失败时使用一致的 4:3 预览画框；图片保持原始比例完整显示，不裁切，并保留必要留白。选图清单通过操作栏摘要按钮展开或收起，不重复显示标题栏关闭按钮。宽屏清单占满图库可用高度，标题和清空操作固定，只有图片列表独立滚动；窄屏保留高度受限的纵向布局。行内移除按钮在悬浮或键盘聚焦时显示，触屏设备直接显示；操作气泡使用简短的本地化文案和受限宽度，按钮的无障碍名称保留完整图片标题。收起清单保留所选图片。选图摘要将最多三张完整缩略图、溢出数量和计数 Tag 合并为一个清单开关，批量操作按钮独立保留。AFP 设置区隐藏外壳底部操作栏，为工作台释放高度。图片列表只排除 `docClass` 明确标识的非图片成员，保留缺少该字段的旧成员；写入校验仍检查完整成员。图库与详情独立滚动，超过半个图库可见高度后显示回到顶部。骨架屏与图片淡入尊重减少动态效果设置；点击详情预览使用项目 Modal 展示，并在关闭后恢复焦点。预览持有共享栅格 Blob URL 租约，最后一个使用者退出时回收 URL。Host 协商 JPEG、PNG、WebP、GIF，按签名接受标为通用二进制的图片，拒绝 HTML 与 SVG。CDN 被阻止时只显示域名；核实域名后再加入部署 `previewCdnHosts`。签名媒体链接与 AFP 凭据不进入浏览器元数据。

选图可以跨收藏夹保留，并记录每张图片的来源。移出操作只解除单张图片关系，不删除图片或收藏夹。复制和转移要求目标可写；转移前先确认图片已加入目标，再从可写来源移除。下载会列出 AFP 提供的画质和费用，默认选择最高的免费画质；任何付费总额都需在重新核对余额和报价后明确确认，付费选项受 `write` 功能开关保护。若 AFP 已接受购买却未返回已确认的下载地址，该图片会标记为待处理，系统不会自动再次购买。文件流式写入用户在 AFP Host 上选择的目录，并限制文件大小、清理原始文件名及为重名文件添加序号。关闭或切换工作台不会停止 profile 下载任务；Host 停止后任务终止。保存的任务记录不包含目录、凭据或签名链接。

下载弹窗占满可用高度，宽屏画质和设置两栏独立滚动，窄屏使用一列滚动，底部费用与操作栏固定。紧凑图片行只显示一处尺寸、大小和费用，逐张画质菜单仍提供完整报价。顶部图标可刷新报价，或批量选择最高免费、最高可用及 AFP 返回的具体画质。批量匹配使用每张图片自己的画质 ID；没有匹配或权限不允许的图片保留原选择，并显示应用数量。批量更改使已有报价确认失效，不会提交购买。缩略图、逐张画质、可重试的错误、行骨架屏和按钮转圈区分加载阶段，并遵循减少动态效果设置。下载被接收后显示全局通知，可直接打开进度；默认收起的屏幕边缘入口支持查看近期批次和取消任务，切换工作台页面后仍可使用，进度采用 Host 的持久化计数。按 Escape 或点击外部收起卡片。文件名前后缀默认折叠。单张读取失败不阻止其他图片；余额无法读取时允许免费画质，阻止付费画质。更改画质、命名前后缀或保存目录会使已有检查结果失效；报价变化须重新检查并确认扣分。报价未知时不显示数字总额。最终文件优先采用交付名称；预览使用完整 GUID/图片 ID 作为回退，标识中的点不会被当作扩展名删除。

六个 Skill 分别在 `$DSH_HOME/.plugins/dsh-plugin-afp/skills/` 保存进程/profile 持有者。最后一个持有者停用后，托管目录从 `$DSH_HOME/skills/` 移入私有停用区；对托管内容的编辑会保留并在再次开启时恢复。同名用户目录、归属标记损坏、链接路径和副本冲突会拒绝覆盖。由于扫描目录共享，同 Home 的另一个 profile 仍可能使 Skill 可见。异常退出的持有者在下次管理操作核对恢复；已有会话历史不会删除。

原有 run/plan UUID 及记录位置保持稳定：`$DSH_HOME/.plugins/dsh-plugin-afp/profiles/<profile-hash>/`。视觉任务失败或取消保留 pending 候选和游标，以便续跑。Home 范围的账户/运行锁阻止并发操作；不完整锁或遗留恢复锁会拒绝工作，须停止持有者后检查现场。报告只返回数量和脱敏错误，不返回凭据或预览字节；本地运行记录仍包含候选元数据，应作为私有数据保管。

下载选项和计划绑定 Host 账户标识；准备、确认或执行前更换账户会拒绝旧批次。报价变化使用同一次刷新快照，返回完整画质选项供再次明确确认。收藏夹操作结果显示部分失败和待核实数量；重置账户会丢弃迟到的操作响应。启动失败或 Host 中断会终结每个未完成项，并同步汇总计数。任务失败只输出固定错误码，不暴露原始认证或交付错误。

## 预览缓存

插件 store 管理页面内存缓存，图库、详情、清单和下载缩略图共用。同一图片的并发消费者合并为一次请求，成功的栅格 Blob 通过 LRU 保留。部署 JSON 可设置 `previewCacheMaxEntries`（默认 300，设为 0 关闭保留）、`previewCacheMaxBytes`（64 MiB）和 `previewCacheTtlMs`（10 分钟）。访问、释放和检查缓存时清理过期条目；条目与字节上限只约束保留的 Blob，不包含正在显示的图片、DOM 和解码内存。关闭一个消费者只取消自己的订阅，最后一个等待者退出才终止请求；最后一个 URL 租约释放时回收对象 URL。请求失败不缓存，解码失败和主动重试使对应版本失效。凭据、读取权限、连接和 Host 实例变化时清空预览，旧响应不能回填；插件卸载等待所属读取结束。刷新整个浏览器会清空内存；不保存持久文件、签名地址、凭据、付费原图或报价。Host 响应继续使用认证和 `no-store`。

`node scripts/benchmark-preview-cache.mjs` 使用离线 40 ms 传输比较六个无缓存与有缓存消费者，校验请求次数，不代表浏览器绘制速度。

## 验证范围

## 功能介绍与配置弹窗

插件详情按类型分组，通过标题展开说明，开关旁显示状态标签；组件列表默认折叠。点击功能名称在浅色说明块中展开简洁的用途、使用条件与相关影响，并提供展开和收起过渡；脚本与工具开关旁的编辑按钮打开共享配置弹窗。弹窗沿用 DSH Modal、Input 和 Button，常用模型与预算字段直接编辑，完整 JSON 收在“高级配置”中。已保存的用户名正常回显；密码、令牌和视觉模型密钥默认隐藏，各自通过小眼睛显示或隐藏当前输入草稿，不回读已保存的密钥。敏感字段写入成功后清空草稿并重新隐藏。四个字段写入当前部署引用的 DSH 凭据服务，留空保留已有值；部署 JSON 只存引用名、接口、模型和预算，由 profile 配置编辑器保存并重载。部署保存会取消活动任务，凭据保存不重载。两类保存分别反馈结果；成功的凭据写入不会因后续部署失败撤销。修改引用名后重新打开弹窗再保存凭据。
