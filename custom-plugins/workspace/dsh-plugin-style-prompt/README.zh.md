# 风格提示词

[English](README.md) | 中文

## Summary

风格提示词提供 React Flow 画布，组织参考图片、风格分析、规则选择、新画面、双语提示词和图片生成。模型与附件复用当前 profile 的服务。生图需要明确注册的图片提供方；支持图片输入不代表能输出图片。画布和 Codex Subscription 集成使用配套的 AutoFlow Host 构建。

<a id="use-this-package"></a>
## 使用本包

### 安装到 profile

风格提示词随 CLI 和 Desktop 运行时提供。在**插件 → 已安装插件**中启用后，从侧栏打开**风格提示词**。已有 profile 保留之前的功能选择。使用 `pnpm --filter dsh-plugin-style-prompt run build` 构建；无法热加载 JavaScript 的 profile 在替换构建后需要重启。独立发布方法见[发布指南](release/README.zh.md)。

### 分析和创建提示词

1. 使用已连接的初始流程，或通过**添加节点**、画布右键菜单、从连接端口拉线到空白处创建节点。连线匹配端口类型，拒绝循环，图片输入支持多个来源。
2. 将 PNG、JPEG、WebP 或 GIF 导入参考图片节点。导入后保存到当前 profile；运行节点时才会发送给外部模型。在分析节点选择视觉模型与分析维度。
3. 运行分析后，选择可以迁移的风格规则。未知规则和仅限原场景的观察不能作为风格要求。在画面节点填写新内容和希望改变的部分。
4. 选择文本模型生成三个双语提示词变体，或在快速组合模式中填写两种语言。分析和文本生成继承所选原生模型的输出限制与推理设置，在应用模型页统一配置。生成使用已选规则，不会重复识图。
5. 需要生图时，选择明确公布的生图模型。内置 Codex Subscription 集成通过 `llm` 暴露已配置的图片模型，不需要独立 ComfyUI 服务。可以连接提示词或直接填写；连入的提示词优先，手动输入框会禁用。需要图片参考时显式连接图片输入。
6. 运行选中节点或整个工作流。按 Shift 选中画面、提示词、生图和输出节点后**复制分支**，即可复用分析并填写另一个画面。未变化的上游会复用；显式运行的生成节点会创建新请求。
7. 在节点预览结果，在检查面板查看完整提示词与规则依据，也可复制双语内容、导出提示词 JSON/Markdown、下载图片原图或导出画布 JSON。

空格拖动平移，滚轮缩放，Shift 多选。方向键移动选中节点，Delete 移除选中节点与连线。鼠标与键盘编辑都会自动保存，并支持撤销和重做。运行输入与草稿分别保存，编辑不会改变迟到结果的归属。校验会定位缺少内容的字段，并按需展开英文输入。模型按提供方分组，列表较长时支持搜索；失效的选择保留原模型标识，并提供应用设置入口。失败分支阻止自己的下游，独立分支继续运行。停止会排空本地工作；已派发请求仍可能在远端完成，系统不会自动重发。

画布内容、节点尺寸和视口通过版本检查自动保存。保存失败会保留草稿并提供重试；保存冲突可选择**另存为新画布**或**重新载入已保存版本**。短暂操作结果使用应用 Toast；保存失败、模型目录加载失败和缺少输入的状态保留在所属画布或节点旁。删除画布或保留记录前，通过确认弹窗说明删除范围。

### 历史与部署限制

通过顶部**更多操作 → 运行记录与历史**查看只读运行快照，底部不常驻历史栏。返回当前草稿后编辑，或将快照另存为新画布；快照中的运行按钮明确运行当前草稿内的对应节点。其他画布的任务继续在后台运行，可通过后台任务菜单和完成提示回到所属画布。原有分析与提示词历史继续保存在原存储域中。**创建画布**为成功历史新增关联图，不重写或删除旧记录。现有提示词 JSON 和 Markdown 保持原格式。画布或保留的运行记录引用任务时，任务不能删除。

[Config](src/host/config.ts) 限制图片、请求与响应字节、任务并发、截止时间、任务历史、画布、素材和运行记录数量。旧插件配置键 `maxOutputTokens` 和 `temperature` 仍可读取，但不再生效；这些参数由原生模型设置统一管理。默认每批最多四张图片，每张 8 MiB、上传合计 32 MiB，文本任务 180 秒、生图任务 600 秒。画布 JSON 导入与导出共用默认 16 MiB 的文件限制，并受请求字节上限约束。**更多操作 → 参考素材**显示占用数量，并允许显式清理未引用条目。已保存画布、保留的运行快照和最近 15 分钟导入的素材受到保护；清理前请保存其他窗口的草稿。清理释放插件素材名额，不删除应用附件。画布导出包含图片哈希清单，不内嵌像素或凭据。先在目标 profile 导入对应图片，再导入画布；导入会重新匹配图片引用，并清除来源 profile 的任务标识。画布 JSON 是本插件的文档格式，不是 ComfyUI 可执行工作流。

## 理解实现

<details>
<summary>实现细节</summary>

[画布文档](src/shared/canvas.ts) 将编辑参数、布局和不可变运行快照分开。[验证](src/shared/canvas-validation.ts) 由 Client 运行前检查与 Host 执行共同使用。[CanvasService](src/host/canvas-service.ts) 负责依赖顺序、分支隔离、按输入复用、取消与重启恢复；文本分析和提示词继续调用原[任务服务](src/host/service.ts)，生图调用公共 LLM 图片提供方。原图与规范化预览分别保存为附件。

新增画布存储域复用现有 profile 写入租约。旧任务记录及格式版本保持原状。重启后的活跃运行会标记为中断，不重新派发。画布结果保存实际提交的生图提示词和参考图元数据。Client 卸载停止订阅；Host 卸载先排空图执行，再关闭原任务存储。

Client 私有打包 React Flow，从 Host 模块表取得 React、ReactDOM、JSX runtime 和 UI 基础组件。控件复用项目 Menu、Input、Button、TextArea、Checkbox、Tooltip、ZoomControls、StateDot、AnimatedCollapse 和 Toast。CSS 继承应用字体、圆角、背景和语义状态颜色。组合包附带第三方许可说明。

</details>

<a id="model-experience"></a>
## 模型体验

节点显式发起辅助 LLM 调用，插件不安装全局指令、Skill 或 Agent 工具。分析发送原生图片附件和有界结构化输出指令。提示词生成发送已选规则、原内容排除项与新画面文本。快速组合、画布编辑和导出不调用模型。生图通过已配置提供方发送冻结后的提示词与显式连接的参考附件。主对话与 Session 格式保持原状。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延后工作

风格提取和提示词校验不能保证语义准确或成图质量。生图提供方需要实现公共 LLM 图片 API；普通对话模型不会自动成为生图模型。本包不在本地执行扩散，也不导入原生 ComfyUI 工作流 JSON。付费提供方的成图质量需要独立真实服务评估；确定性测试图片仅为夹具。跨 profile 转移画布需要恢复引用的图片附件。暂不混合多份分析的风格：每个提示词消费一份分析和其中选定的规则。
