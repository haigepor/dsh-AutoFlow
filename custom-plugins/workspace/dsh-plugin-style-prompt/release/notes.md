## Style Prompt 0.1.3

Supports DSH 0.2.2-alpha.2 and 0.2.2-rc.1 through an explicit compatibility range. Saved analyses, prompts and activation choices remain in the profile. Older desktop builds require a manual restart after installation; the matching new desktop waits for current work before restarting automatically. Automatic installation remains opt-in.

## 风格提示词 0.1.3

通过明确的兼容范围支持 DSH 0.2.2-alpha.2 和 0.2.2-rc.1。已保存的分析、提示词及启用选择继续保存在 profile 中。旧桌面版安装后需手动重启；配套新桌面版会等待当前工作结束后自动重启生效。自动安装仍需明确开启。
