# 文章生图第一期改动与验证索引

整理日期：2026-10-18。本文覆盖本次提交前累计的文章生图插件、独立 MCP 工具包、应用集成、测试和文档改动。各历史报告只描述其测量时的版本；当前接口和配置以[插件说明](../../README.zh.md)及[工具包说明](../README.zh.md)为准。

## 功能改动

| 范围 | 实现及影响 |
|---|---|
| 来源获取 | 工作台与 MCP 共用富文本捕获内核，保存正文块、嵌套列表、表格、图注、原图及来源哈希；支持公开 Web Story、视频封面和公开字幕。访问受限、短公告与获取不完整保留不同状态。 |
| 分析与审核 | 导入 Google Sheets 后，按来源版本与规则版本生成文章理解稿、配图规划和提示词；提供证据定位、分页读取、编辑、版本失效及人工审核。真实模型语义验收 AC-25 仍由用户执行。 |
| 生命周期与诊断 | 取消后等待在途操作和资源清理；批量进度合并写入；状态事务串行并保留跨进程文件锁；失败结果保留根因和脱敏诊断；网络重放追加记录后同步更新端点计数和查询字段。 |
| 传输与原图 | 接入显式代理与 DoH，保持公网地址校验和 DNS 固定；共用匿名 Cookie 会话；原图候选有界回退、解码验证、字节去重并保留所在位置。 |
| 性能 | 仅对显式站点模板启用静态完整性校验；不能确认时回退浏览器。浏览器可按模板延后视觉资源，连接池按操作拥有并等待关闭。图片说明只从匹配当前文章和原图身份的发布者元数据补充。 |
| 集成与分发 | 工具包进入 workspace；桌面打包剔除嵌套 node_modules；插件图标降到 256 KiB 限制内；保留构建后的 client.js，验证实际生产 tarball。 |

第一期止于人工审核，未接真实生图、上传发布或表格回写。没有整体引入 Scrapling、Crawlee 或额外 Python 运行时。

## 当前回归证据

[最终 3080 性能报告](speed-implementation-2026-10-18/report.zh.md)记录一组新对照与最终批次：耗时 21 分 26.758 秒降至 12 分 11.679 秒，减少 43.14%。最终批次含一次额外重试，共 29 次尝试，不能解释为相同 28 次尝试的严格对照或所有站点的普遍提速。

最终获得 21 篇新快照；另有 6 篇访问受限、1 篇短公告。正文与列表保留，98 份就绪原图的完整文件 SHA256 一致，R7 的 131 条字幕逐条时间和文本哈希一致。原始来源哈希 20/21 一致；R7 的差异为一个经页面核对的播放器浮层，剔除该已识别控件后其余 142 块及语义哈希一致。Metrópoles 与 R7 仍标记 partial，不能把未获取的视频动态画面或嵌入内容宣称完整。
