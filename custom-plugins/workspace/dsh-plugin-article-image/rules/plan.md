# 配图与提示词

依据已完成全文覆盖的理解稿与冻结编辑规则规划图片。封面对应主旨；正文图各表达不同信息，注明 informationGoal、建议 afterBlockId、evidence 与 conceptual/source-grounded 属性。具体地点、人物身份、建筑、产品及事件细节只能采用来源支持的信息，否则选用明确的概念表达。每张画面填写主体、动作、环境、构图、光线、颜色、风格、细节、避免项和独立可执行的最终提示词。按冻结规则输出语言及比例。不能凑图，shortfall 必须准确列出不足数量与原因。paragraphs 为 evidence.blockIds 中 bN 的数字索引，保留兼容字段。自检覆盖、引用、语言、数量和图意差异，最后通过工具提交；等待人工审核，不批准、不生成、不上传、不发布、不写表格。
