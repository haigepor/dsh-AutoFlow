# dsh-plugin-better-sidebar-updater

[English](README.md) | 中文

## Summary

本独立包检查官方增强侧栏 GitHub 发布，下载精确匹配的 npm 包。它复用应用插件管理器的压缩包检查、安装锁、失败恢复和重启能力。检查不会自动安装更新。侧栏关闭后，更新器仍可使用。

## Use this package

运行 `pnpm --filter dsh-plugin-better-sidebar-updater build`。新建 Web 和 Desktop profile 默认启用随应用交付的更新器；已有 profile 保留开关选择，可在插件页面启用。打开侧栏或更新器详情页，先点击**检查更新**，再点击**安装更新**。点击**重启生效**前保存工作；不支持重启的载体需要关闭并重新打开应用。

更新器不使用凭据。上游来源为 omdsh-dev/DSH-better-sidebar；npm 安装包只来自 registry.npmjs.org/dsh-better-sidebar。GitHub 发布版本必须与 registry 包及预期下载 URL 匹配。完整字节按 npm SHA-512 integrity 校验；这验证 registry 产物完整性，不证明其与某个 Git 提交等价。npm 尚未发布、DSH 或 Node 版本不兼容时拒绝安装。

## Configuration

| Field | Default | Meaning |
| --- | --- | --- |
| checkIntervalMs | 3600000 | 后台检查间隔；零表示关闭后台检查。 |
| pollIntervalMs | 1000 | 可见操作进行时的状态轮询间隔。 |
| timeoutMs | 30000 | 单次上游响应超时。 |
| jsonBytes | 1048576 | 元数据响应最大字节数。 |
| archiveBytes | 67108864 | 压缩安装包最大字节数。 |

在更新器行配置这些字段。共享插件管理器继续限制解压内容大小。安装仅替换当前 profile 的侧栏依赖，保留组合包选择与设置；源码、更新器代码、应用主题与布局不被覆盖。

安装前，更新器将侧栏的原始配置（包括 customCss）显式保存到 profile 覆盖层，即使它与继承的默认值相同。组件停用时仅原样保留配置，不绕过 schema 编辑；整个组合包未启用时离线组合并保存，不启动侧栏。配置所有者缺失或不唯一会中止安装。官方包替换本地组合包默认值后，设置与定制样式仍保留。

插件列表将 Better Sidebar 与更新器合并为一个 Better Sidebar 入口。紧凑详情页默认显示更新操作，提供两个模块各自的启停开关，并折叠技术包信息。更新区复用 AFP 的圆角卡片、内边距和分隔线规则，下半区显示手动安装说明与更新说明入口。没有自动安装开关，不依赖 AFP 是否启用。官方侧栏 npm 更新不会替换独立更新器和合并页样式；两者关联读取安装包的声明。共享管理器保留重启前的正在使用与已安装版本，更新器停用后再次启用也能读取待重启状态。

检查和安装使用 AFP 的共享加载圆环与不定进度条。收起时只显示圆环，操作结束后移除加载反馈。减少动态效果偏好会停止动画，不推算总完成百分比。

当侧栏 customCss 启用该效果时，其 Client 还提供文件变动控件的滑动指示层。测量沿用现有按钮，不更改点击与键盘处理。观察器跟随选中态、容器和按钮尺寸变化；停用后移除测量数据并恢复普通选中样式。这些本地文件位于官方侧栏 npm 替换范围之外。

伴随包 Client 通过现有 settings.section 优先级机制提供本地侧栏设置页，沿用官方入口注入的状态与动态描述符注册表；停用伴随包会恢复官方页面。内容与预览行使用共享 Switch/Button，区分隐藏的差异预览，功能停用后仍可进入设置。加载设置修订号后才能打开功能选项。CSS 修改须显式应用；草稿在本次 Client 生命周期内跨设置页导航保留，完整刷新后不保留。保存按已确认的修订号依次提交，失败保留 CSS 草稿，并先刷新设置再处理后续写入。页面及编译后的辅助代码位于伴随包产物，不受官方侧栏 npm 替换；上游设置注入与描述符接口变化仍需适配。

九个内置设置图标使用 `assets/icons` 中可编辑的 SVG 文件，采用明亮强调色与统一灰色底座，代码 SVG 本身不含彩色填充，并用于 JSONL；外部扩展保留自己的图标。原生侧栏标题通过标题槽位选择器将图标与文字垂直居中。自定义 CSS 使用 CodeMirror，提供 CSS 高亮、行号、撤销重做以及随明暗主题切换的语法配色；修改仍须点击应用。这些外观改动由伴随包提供，不写入官方侧栏包。

功能设置与扩展目录使用本地弹窗外观，固定标题和底部操作栏，仅内容区滚动。设置项使用分隔线；目录标题左侧带圆角强调色竖线，说明与可换行的安装命令块对齐标题文字。共享 Modal 保留焦点与 Escape 处理，伴随包表单保留搜索、复制和设置行为，HTML 沙箱风险说明完整展示。输入框、开关、按钮和下拉菜单使用项目共享组件与语义字号、颜色、圆角 token；挂到页面根节点的菜单使用独立作用域，说明可换行，图标使用标准槽位。内置编辑器适配保留 openWith 数据格式，外部自定义渲染器仍由扩展负责。CSS Modules 保留文件名前缀，避免与独立构建的其他插件发生短类名冲突。

## Model Experience

不贡献提示词、工具声明或模型可见输入。后台检查产生网络请求，不调用模型。

## Known Limitations and Deferred Work

官方安装包替换侧栏实现修改，不合并修改。伴随包内嵌导入版本的偏好解析器和目录数据；这些接口变化时需要一起构建对应的伴随包。本包不提供自动安装或降级。包操作失败时，共享管理器恢复 profile 配置；此前允许的依赖脚本副作用不属于恢复范围。重启支持取决于应用载体。
