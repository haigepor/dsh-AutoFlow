# 视觉策展版本发布

[English](README.md) | 中文

## Summary

本包随 AutoFlow 分发，在已安装插件中展示，保留已有启用选择。[release.config.json](../release.config.json) 负责稳定的 `visual-curator-v<version>` 标签族和 `visual-curator-update.json` 元数据，与 AFP、应用分别发版。

## 准备与发布

阅读[发布 Skill](../../../../.agents/skills/dsh-custom-plugin-release/SKILL.md)和[发布规范](../../../release-governance/README.zh.md)。审核并提交源码后准备资产：

```sh
pnpm --filter dsh-plugin-visual-curator run release:prepare --out .artifacts/visual-curator-release
```

准备流程运行本包测试和 prepack，验证 Host、Client、tools、Skill 和 page 入口、patch、图标、语言文件与许可说明，生成 tarball、`SHA256SUMS` 和更新元数据。元数据固定源码提交、版本、字节数和摘要。`--allow-dirty` 只用于本地演练。[自定义插件工作流](../../../../.github/workflows/release-custom-plugins.yml) 在四个原生平台检查，再从已验证草稿发布，并设置 `latest=false`；公开资产与标签保持冻结。

## 运行时更新

插件详情页复用已有的检查、更新和自动更新控件。自动安装需明确开启，不会自动重启应用。重启后同时加载配套的 Host、Client 与 profile patch。已保存的风格、引用、任务、反馈、模型设置、凭据、启用及功能选择保留在各自的 profile 存储中。

tarball 需要 peerDependencies 声明的原生 LLM、附件、作业、存储和 Client 能力；应用拥有的组件需要配套 AutoFlow 构建。无密钥发布测试不代表真实图片来源登录、付费视觉调用或来源权限已经验收。按要求另行执行下载、安装和旧版本更新验收。

## Visual Curator 0.2.8

找图新增 50/100 个唯一候选池和真实缩略图批量初筛，随后只对保留及不确定图片完整复核。初筛不能直接入选，原图在初筛后才下载；故障有界重试后转逐图复核，不把技术故障计为风格拒绝。暂停、重启及检查点提交间隙复用已保存结果，继续遵守同一任务预算。模型设置可调整候选池、每批图片数量和初筛分辨率，任务卡显示分阶段真实数量。

修复仅由反例支持的规则被禁用、required 排除被其他偏好抵消，以及源审拒绝图在新会话重复复核的问题。相同素材集按稳定照片身份排除已知图片，不因改写任务或换模型重置；技术失败和不确定图片仍可重试。关键词指引依据真实 Unsplash 接口测试调整，保留当前启用的主体及环境约束；多关键词并非严格 AND，最终结果仍看实际像素。

当前任务结束后更新插件并重启 AutoFlow，无需重新安装桌面包。旧任务继续原流程，旧数据集内容保持固定；需要补回旧版遗漏的反例规则时，选择“全部角色 → 复用并整理”，使用新生成的完整数据集。兼容观察无需重新逐图分析；仅导出旧画像不能补回规则。

## Visual Curator 0.2.7

已保存的参考观察、自动风格画像和参考数据集可供其他已配置的视觉模型使用。切换模型会保留已分析状态、原始模型及请求记录和已有数据集文件。新找图和裁剪任务固定所选模型，暂停任务重启后仍沿用原模型。增量分析可跨模型复用已提交观察，全部重新分析仍须明确确认；图片、规则、判断或处理方式改变时，受影响的观察仍需重新分析。

分析支持全部参考、仅正例或仅反例，并可分别选择复用或重新分析。正例批次提取需要保留的可迁移特征，反例批次记录有依据的不匹配原因及不确定性，不将反例纳入目标风格。其他角色保留有效观察。完整依据由模型统一整理匹配提示词并自动保存带校验和的数据集；尚有参考图未分析时保留部分结果，待其余分析齐全再整理。封装提交失败可继续任务重试，不再调用模型。最新完整包固定在列表首位，新分析进行或暂停时也可选择历史完整版本找图。

参考图标记在依据变化时显示“需重新分析”。在当前任务结束后更新插件并重启，无需迁移数据或重装桌面安装包。人工发布版本和受控对比保留评估模型资格检查。无密钥检查不代表付费模型输出已经验收。

## Visual Curator 0.2.6

主动停止会话会同步取消其已受理的视觉任务和正在受理的工作。关闭弹窗或一轮对话自然结束时后台任务继续运行，其他会话和工作台独立任务保持运行，已保存结果保留。阻止取消通知自动唤醒空闲会话还需要配套 AutoFlow 宿主更新。在当前任务结束后更新并重启；已有 profile 数据无需迁移。
