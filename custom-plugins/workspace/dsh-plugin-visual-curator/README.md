# dsh-plugin-visual-curator

English | [中文](README.zh.md)

## Summary

Build a visual style from selected reference dimensions, publish immutable versions, and use one fixed standard for image search and actual-image crop review. Human corrections remain auditable and affect future standards only after explicit publication. DSH carries this independent bundle with its installation and enables its nine Agent tools in newly initialized Web and Desktop profiles. Existing profiles retain their choices. Local records remain available without search or vision configuration, while operations that need those services fail visibly until configured.

## Use this package

Search preparation reserves a Session identity before native creation finishes; the canvas and launch controls offer conversation navigation only after creation is confirmed. New workbench searches submit the frozen requirements and dataset through the native conversation, whose Agent tools start the background Run. The selected model applies to this conversation and its visual reviews without changing the profile default. Historical workflow launches retain their original execution path and synchronize display-only task checkpoints without resubmitting prompts. Showing those conversations in the sidebar requires the matching Host change to Session-list metadata, so a plugin-only import into an older desktop does not include that fix. Stop first saves a durable intent and cancels known source and wallpaper tasks, then joins preparation and rechecks late admissions. Launch writes are serialized and retain the stop intent. Batch removal keeps cards until tasks are terminal and its visibility marker is committed; closing its progress dialog leaves removal running. Read failures preserve the current view and expose a diagnostic code.

### Enable the profile layer

Workflow conversations display confirmed requirements, frozen model and dataset, real execution stages, counts, bounded request summaries and failures, and acknowledged result directories in the body. Task details open in place. Continue and stop use the original task controls; retrying display synchronization never creates a task or provider request. Saved checkpoints are synchronized after restart, including ended tasks with empty conversations. Copied conversation records are read-only and retain their original owner. This requires the matching Host task-journal API: importing only a plugin package into an older Desktop cannot supply it. New workflow admission reports that mismatch before executing. Use the updated local Desktop preview alongside the local plugin package; existing task records remain intact.

In Plugin Manager, enable **Visual Curator** to use the installation-owned copy in an existing profile; no profile-local package installation is required. Restart an already running Host after updating the application's installation dependencies. An installation that does not carry this bundle can install a reviewed package artifact into the intended profile instead. Its [patch](cordis.patch.yml) mounts the business provider, six Skills, three Agent tool groups and three page entries, each with an independent switch. Skills register through the native catalog without writing Home files. The Host must provide profile context, storage domains, credentials, jobs, Plugin Manager, configuration editing, the skill catalog and Session storage. The Web client uses the standard Plugin Manager detail page. The package provides no application executable; launch applications through a supported `dsh` profile.

This bundle does not add itself to other profiles or change AFP. Turning it off removes its registrations, stops new work, cancels and drains active work, and retains saved data. A second Host writer for the same profile is refused; stop the first Host before reopening the writer.

Release artifacts include the native image/reference picker, its command runner and Windows worker.cjs; an older folder-only picker dependency cannot prevent plugin loading. koffi remains a declared dependency. The worker starts only for a native chooser and belongs to that request's cancellation lifecycle. The package supports AutoFlow hosts based on DSH `0.2.2-alpha.2` and `0.2.2-rc.1`, using AutoFlow's plugin actions; older desktop builds apply the fix after a manual restart, while updated desktop builds wait for current work before restarting automatically.

### Wallpaper workflow

Wallpaper production checks original availability before layout. Searches configured for automatic wallpaper output exclude originals marked restricted by the provider. If an existing batch contains restricted sources, a bounded replacement search reuses its frozen queries, references and full visual acceptance rules; only accessible original pixels that pass review replace the failed slots. The saved replacement identity records its unavailable predecessor. Full reviews use saved, bounded model views while measured checks and rendering retain original geometry and pixels; page-provided original URLs avoid redundant detail requests. Continuation keeps completed originals and artifacts and does not retry permanently unavailable sources. The download card reports saved, restricted, failed and pending originals separately. The image navigator uses local small previews or the saved remote thumbnail descriptor, including historical originals without a local preview.

Canvas headers and batch filters use a fixed task identifier rather than the current row number. Loading, filtering and automatic arrangement do not rename a batch. New batches use unoccupied space. Automatic batch groups avoid occupied space while manually positioned groups stay fixed. Positions migrated from older layouts are treated as manual. New nodes and explicitly arranged nodes use automatic positions until dragged. Resizing moves only automatic siblings in the same batch; manual cards and other batches limit the available size. Explicit automatic arrangement releases the displayed nodes for automatic positioning again. Dragging defers group correction until the interaction ends. Geometry stays device-local and does not change task records. The dataset node is visible while references are imported or analyzed, and waits for saved observations. Active upstream work can animate a connection to this waiting node without marking it as running or completed. New cards enter once per canvas session; viewport virtualization does not replay their entry. Native SVG motion follows the stable curve, with a destination arrow and theme-based timing; reduced-motion preferences and hidden-page state stop the particles.

File checksums are SHA-256 over exact UTF-8 content; business-record digests use separately versioned canonical JSON. References-only is the default. Image bytes require recorded permission and a successful integrity check; missing, corrupt or unauthorized bytes fail the export instead of producing a supposedly complete package.

Client `reference-analyze` accepts optional `buildDataset: true` for cross-image induction; omission retains legacy per-batch analysis. `export-start` accepts `analysisRunId` with `kind: "style"` and `purpose: "reference"`, requiring a completed analysis whose images, dimension intent and human judgments match the selected release. Existing record enums and schemaVersion remain unchanged. The versioned profile lives in the existing Run JSON checkpoint; original style exports and human-supervision formats remain readable. Machine observations never enter classification/preference/crop human-supervision rows.

Training exports include learning families only and retain the eligible human feedback IDs frozen at request time. Later corrections do not rewrite an existing snapshot. Preference ties and neither choices remain explicit. Generated Skills identify the release and required resources, require a missing-resource report when pixels are unavailable, and only produce downloadable artifacts. They do not modify Home instructions, activate in a Session, train a model or contain model weights.

Technical failures and uncertain outcomes are not permanently excluded, and other collections remain independent.
