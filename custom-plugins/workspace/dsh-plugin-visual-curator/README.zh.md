# dsh-plugin-visual-curator

[English](README.md) | 中文

## 摘要

从选定参考维度建立视觉风格，发布不可变版本，并用同一固定标准搜图和复核真实裁后图片。人工纠正可追溯，只有显式发布才改变未来标准。DSH 随应用提供这个独立 bundle，新建 Web 和 Desktop profile 默认启用其九个 Agent 工具，已有 profile 保留原选择。未配置搜索或视觉接口时仍可读取本地记录，需要这些接口的操作会明确失败，直到配置完整。

## 使用本包

找图准备会先预留会话标识，画布与启动菜单在确认原生会话创建后才提供打开入口。工作台新找图任务通过原生会话提交固定需求与数据集，由 Agent 工具启动后台 Run；所选模型用于本会话和视觉复核，不修改全局默认模型。历史 workflow 任务保留原执行路径，只同步展示检查点，不重新提交提示；侧栏显示这类会话需要配套的宿主会话列表元数据修改，仅向旧桌面导入插件包不会包含此修复。停止时先持久保存停止意图并取消已知的找图与壁纸任务，再等待准备流程收尾、补查期间刚受理的任务；启动记录串行保存，保留停止意图。删除批次会等待任务进入终态并提交隐藏标记后才移除卡片，关闭进度窗口不取消后台删除。读取失败保留当前视图，并显示诊断代码。

### 启用 profile 层

工作流会话在正文显示已确认需求、固定模型和数据集、真实执行阶段、计数、有界的请求摘要和失败，以及已确认的结果目录；任务详情就地打开。继续和停止沿用原任务控制，重试展示同步不创建任务或请求供应商。重启后会从已保存检查点同步正文，包括正文为空的已结束任务。复制会话中的任务记录只读，并保留原所有者。此能力需要配套 Host 任务记录 API，仅向旧桌面导入插件包无法提供；新工作流会在执行前报告不匹配。验收时配套使用更新后的本地桌面预览和插件本地包，保留现有任务记录。

已有 profile 在插件管理器启用“视觉策展”，即可使用随应用提供的版本，无需在 profile 内另装一份。更新应用安装依赖后，已运行的 Host 需要重启。未随应用携带本 bundle 的安装环境，也可把审核过的包产物安装到目标 profile。[补丁](cordis.patch.yml) 挂载业务 Provider、六项技能、三组 Agent 工具与三个页面入口，每项均可独立开关。技能通过原生技能目录注册，不向 Home 写入文件。Host 需要 profile 上下文、存储域、凭据、jobs、插件管理、配置编辑、技能目录及 Session 存储。Web Client 使用标准插件管理详情页。本包不提供应用可执行文件；应用通过受支持的 `dsh` profile 启动。

本 bundle 不会把自己加入其他 profile，也不修改 AFP。关闭后会释放注册、停止接收新工作、取消并排空活动任务，同时保留数据。同一 profile 的第二个 Host writer 会被拒绝；先停止原 Host，再重新获取写入能力。

发行产物包含原生图片与参考图选择器、命令执行辅助代码及 Windows worker.cjs；旧版仅支持文件夹的选择器依赖不会阻止插件加载。koffi 仍声明为依赖。工作进程仅在打开原生选择器时启动，其取消与清理由该请求持有。插件支持基于 DSH `0.2.2-alpha.2` 和 `0.2.2-rc.1` 的 AutoFlow 宿主，使用 AutoFlow 的插件动作接口；旧桌面版需手动重启应用加载修复，新桌面版等待当前工作完成后自动重启生效。

### 配置外部服务

本地图片、图库收藏及已有找图结果的普通导入只保存参考图，由用户点击“分析参考图”并确认范围后启动；明确命名的“加入并分析”仍为主动选择。每次新的参考分析都会复用兼容观察，让模型整理正反例依据，并在任务完成前自动保存数据集。尚未分析齐全、缺少正例或有效匹配规则时先保存观察包，依据齐全后生成完整风格包。数据集工作区也提供“模型整理生成”，可重新整理。列表按档案版本归组，将相同内容的导出合并展示，每个历史导出 ID 保持可读。同一档案、范围和生成格式的重复或并发请求复用同一份包。风格归纳读取全部已保存的逐图观察；附带的视觉比对图片是代表子集，受固定图片数量及源图字节预算限制，正例、反例及待判断角色交替选取，角色内部按位置分散抽样。输入卡片分别显示观察覆盖数和实际附图数，四张附图不表示只分析了四张。计数与样本筛选采用包中冻结的有效角色，并保留原始导入角色。匹配规则数量不包含参考说明；版本对比分别呈现参考图、匹配规则和仅说明调整。

数据集列表和已打开的找图表单随已保存的工作区数据变化自动刷新，包括从未在数据集页面手动提交的自动导出。保留当前筛选、数据包选择和已有内容。自动选择会展示实际选用的包、版本及角色数量，全部有效反例单独统计。

原生启动在预览、原图和用途尺寸输出中均保留本次明确检索计划。新 v3 任务固定 `fixed.cropReviewPolicy: candidate-focus-v1` 和 `fixed.cropModelViews: bounded-v1`：源图和终图审核分别只接收本次规则，裁剪终审在实际派生图上重新检查主体与用途硬要求；没有该策略的历史任务保留原审核请求。已保存的风格覆盖率区分达到匹配阈值与满足全部偏好。缩略图准备在整个 Run 内共享配置的请求并发上限，保留图片顺序，失败或取消时等待已接纳的工作结束。终审未知保留为待处理，明确拒绝和技术失败仍显示失败。

未选中素材集时，工作区只显示创建素材集的入口，不显示批次筛选、任务历史或找图裁剪空状态。

找图与裁剪使用无限画布。普通预览找图保留前三个节点；选择壁纸输出后启动七步[壁纸工作流](#wallpaper-workflow)。默认聚焦当前任务；全部批次总览按独立行展示，每行保留各自的冻结输入和进度。准备任务时立即创建找图卡片，正式 Run 启动后复用卡片及位置。曲线连接跟随固定步骤和实际返工记录。拖标题排列节点，拖背景或按空格平移，滚轮缩放，双击节点聚焦本批；按钮和图片预览不会拖动节点。按住 Ctrl（macOS 使用 Command）拖背景可框选相交卡片；按修饰键点击可增减选择，拖动选中卡片的标题可整体移动。右键卡片或选区可使用原生菜单进行聚焦、折叠、展开、尺寸重置及当前可用的任务操作。支持节点折叠、适应全部和聚焦当前批次。选中卡片后可拖动边缘或角点调整宽高，也可通过标题栏重置尺寸。布局版本 7 保留迁移后的位置、尺寸、手动位置归属及每个启动任务对应的主要 Run 标识；旧版布局记录不覆盖。图片继续分页，查看画布不会派发模型任务。

导入参考图、分析、数据集及任务详情通过画布上的弹窗操作，不切换当前 Session。风格侧栏通过不可变风格版本保存已采纳规则的描述；本机风格补充加入新任务需求，已启动任务仍使用原要求。AI 生成封面仅用于界面引导，不加入参考图、数据集或经验。构图经验分别显示当前版本、已确认的基准案例家族、版本评测和案例详情，完整 Skill 指令默认折叠，使用原生折叠组件和主题动效 token 过渡。规则复选框保持横向排列，经验整理门槛读取 Host 设置。

数据集以表格分列展示名称与版本、正反例和规则数量、生成时间、状态及操作，每行提供详情、下载与删除。确认删除后，该数据集及相同内容导出记录会退出列表和新找图选择；原始图片、档案、分析记录及已受理任务保留，之后可以重新生成。正在生成的数据集需先停止任务再删除。

训练集和已完成的参考数据集归应用 profile 所有，可跨会话选择，并使用其他已配置的模型执行。旧版带会话标记的数据集也可直接复用，无需改写文件或重新分析。选择数据集后固定其中的参考图、规则和匹配提示词；其他 profile、会话私有图片和任务记录继续遵守原有权限检查。

已保存的观察、自动风格画像和参考数据集独立于执行模型。切换模型会保留已分析状态、原始模型及请求记录和已导出的文件。增量分析可复用其他模型已经提交的观察，但图片输入、规则、判断和处理方式仍须一致；全部重新分析须针对所选模型明确确认。新的画像找图和裁剪任务会在执行 recipe 中固定所选模型及参考图额度，继续或恢复已受理任务仍使用原有配置和预算。人工发布版本和受控对比保留评估模型资格检查。

已安装插件详情页通过与 AFP 相同的更新器提供独立 GitHub 检查、更新和显式自动安装选择。重启后同时加载配套的 Host、Client 与 patch，保留已保存的数据、凭据和功能选择。版本族、精确源码资产与验证范围见[发布指南](release/README.zh.md)。

视觉模型页面从“设置 → 模型”的原生注册目录中选择支持图片输入的模型，供应商地址、凭据和推理默认值统一在项目设置管理。模型或凭据更新会使共享目录失效并重新读取；单个供应商故障保留重试状态，不隐藏其他可用模型。保存新的原生选择时，再次确认该供应商仍声明图片输入能力。既有 HTTP 部署与冻结任务保持可读；选择并保存已配置模型后，新任务使用原生调用，不迁移已有任务。

在所属 profile 的 Cordis overlay 中配置 Provider 条目。`source` 选择 Unsplash 或通用 HTTP JSON 图片来源，包括端点、方法、query/cursor/page-size 字段、响应 JSON Pointer 及允许的媒体 origin。新任务默认使用 `vision.backend: native`：填写项目模型设置中已注册的 `vision.provider` 和支持图片的 `vision.model`。凭据、模型能力检查、图片处理和流式输出复用原生 LLM 与附件服务。`limits` 控制文件、解码、存储限制，以及请求和候选预算、重试、并发及截止时间。[配置解析器](src/host/config.ts) 是字段与默认值的唯一详细定义；创建任务快照前先解析配置。

原生模型任务的时序统一交给所选 LLM 适配器，覆盖参考图分析、找图复核、裁剪提案、评估和上下文压缩。插件不再为这些路径施加单次模型请求或任务总时长限制，继续已保存任务时也采用这一策略。原生连接与空闲处理、主动取消、Host 关闭，以及调用次数、搜索页数和字节预算继续有效。图库检索和图片下载保留网络超时；明确选择的兼容 HTTP 任务保留原有请求与任务时限。继续任务时仍固定原有模型、参考图和已保存观察。

风格归纳 v4 使用短图片代号，并在实际请求中记录真实 ID 字典；通过校验后，将证据、风格组、不适用引用和模型建议的拒收原因还原为真实 ID 再保存。每张反例都有按维度归纳的原因，缺少人工理由时保留不确定性，模型建议不会创建人工反馈。新模型提出的硬性要求在人工确认前按偏好处理。旧 v1/v2/v3 归纳仍可读取。流式 JSON 达到文本保留上限、开头被移除时，原文保持稳定的代码块展示；最后已收到的可读前缀会保留，直到完整保存结果替换。部分或失败输出不会被算作已完成观察。

显式设置 `vision.backend: compatible` 可使用已保存 endpoint 和凭据引用的备用 HTTP 接口。模型失败不会悄悄切换接口或额外发起付费调用。未记录 backend 的历史冻结任务保持 HTTP 行为。切换调用方式后，已有观察仍可读取；新原生任务使用新的 reviewer 标识。参见[升级指引](../../../docs/upgrade-guide/v0.2.1-rc.3/visual-curator-native-llm/guide.zh.md)。

原生请求把授权远程图片的真实字节交给附件服务接纳，不改变来源引用和导出权限。下载预算、下载请求时限、重试额度和取消仍由策展任务负责。整批远程图片共享一次持久化预留，全部读取成功后结算实际字节；未知传输保留预留额度。发送前保存实际附件引用和已解析的调用参数；成功或失败响应都保留已返回的 token 用量、时间和结束状态。只有收到原生终止块的完整响应才能提交，完整 JSON 不能替代流结束确认。原生适配器未返回的缓存字段显示为不可用。分析侧栏把未缓存输入、缓存读取和缓存写入作为互不重叠的输入量相加，不推断网关整体命中率，也不伪造聊天 Session。

分析信息默认收起，通过批次导航旁的图标展开或折叠。模型归纳格式错误可从已提交观察继续，包含旧版标记为不可重试的同类失败。继续执行保留任务模型与预算，只重做未完成部分，整理成功后保存数据集；无法继续时显示具体原因。

分析弹窗的上下文圆环使用同一次分析或归纳请求保存的模型容量，以及服务返回的输入与输出 token 总量；缓存桶互不重叠，思考 token 不重复计入。新请求尚未报告用量时保留上次已报告的读数并标明来源，辅助压缩调用计入累计用量但不替换圆环读数。若所有请求都未报告用量或容量，对应字段保持不可用，不借当前模型设置补齐。窄屏弹窗也保留相同读数。

最近查看的分析及已读取输入在 Client 内存中保留 `limits.analysisCacheTtlMs`（默认 60,000，设为零可关闭复用）。短时重开已完成任务不重复读取详情；运行中的任务继续同步。手动刷新、写入操作和授权变化会使缓存失效；任务信息更新或刷新失败时保留已有画面并重新验证，失败和已取消的读取不会延长缓存期限。加载骨架沿用设置页的低对比底色和扫光，并支持减少动态效果；右侧为批次导航预留更多高度，空间有限时模型信息独立滚动。

背景分辨率依据服务原件测量，与请求尺寸和预览分别记录。订阅通道可能在请求 1872×3328 后仍返回 941×1672，客户端参数不能证明原生尺寸。新任务固定 `wallpaper.backgroundResolution` 独立限额：启用时，对当前蒙版生成的低分辨率背景运行 CPU ESPCN 3 倍亮度重建，再一次缩至 1845×3280。它属于学习式重建，不代表原生高清生图或真实细节恢复。服务原始文件、摘要、尺寸、模型摘要、处理耗时和独立产物均保留；最后贴回原图全部保护像素。原有验收项全部适用，分块接缝、光晕、颜色变化、虚构结构与不自然的地面、天空或地平线衔接均不能通过。输入、中间及输出像素、取消和超时分别受限。旧任务不补策略；`wallpaper-continue` 的 `recompose:{imageVersionId,revision,mode:"protected-context-v2",backgroundResolution:"current"}` 明确创建恢复任务，复用当前蒙版的已有生图回执进行超分和独立复审，不新增生图或重置编辑次数。界面为已保存的尺寸不足结果提供此入口。

Unsplash 图片优先使用系统 DNS，连接失败时执行有界的加密 DNS 切换。`source.unsplash.mediaDnsResolvers` 配置备用服务，默认采用 Google 和 Cloudflare 的 JSON DNS 端点，空数组可关闭备用解析。查询仅包含域名，不包含照片路径或账号 Cookie。`mediaConnectTimeoutMs`、`mediaConnectAttempts`、`mediaDnsCacheTtlMs`、`mediaDnsFailureTtlMs` 和 `mediaDnsCacheEntries` 限制连接竞速、重试和缓存；DNS 查询也受请求总期限限制。所有解析地址必须公开，HTTP 和 TLS 校验仍使用原始域名。权限错误、证书失败和已开始读取的响应不会触发 DNS 重试。`previewTransport: host` 默认让已保存引用、收藏夹封面、图库缩略图和大图预览都走同一读取路径；显式选择 `redirect` 可恢复浏览器直连 CDN。图库投影新增可选的 Host 展示路径，原始来源 URL 仍用于引用与导出。预览路由仅接受既有规则允许的 Unsplash 无签名公开图片地址，不转发账号 Cookie，也不创建图片记录。原生调用在同一任务内重试时复用已接纳并核验的附件，不再次下载同一图片。

图库元数据请求将全部已检查地址交给 curl 的原生连接回退，并沿用现有连接超时与读取重试额度。Cookie 仍留在私有请求文件中，TLS 继续校验 unsplash.com。浏览器第二版元数据缓存会丢弃旧的直连图片投影并重新读取，不影响来源收藏夹、选择或已保存引用。

`source.endpoint`、可选的 `source.lookupEndpoint` 和 `vision.endpoint` 拒绝内嵌凭据、查询参数及 fragment。视觉服务基础地址没有路径时补全为 `/v1/chat/completions`，以 `/v1` 结尾时追加 `/chat/completions`；其他请求路径保持原样。`source.allowedMediaOrigins` 和 `vision.localOrigin` 必须填写精确 origin，不含路径或末尾斜杠。可选 lookup 端点仅通过来源稳定 ID 刷新媒体定位，不会从第一页重启已过期搜索。

模型设置只读显示注册模型的上下文容量与输出默认值。新原生任务使用 `vision.useModelDefaults: true`，通过原生 `prepareCall` 继承输出、推理和采样参数；`limits.maxVisionOutputTokens` 继续用于备用 HTTP 和历史冻结任务。上下文容量不等于输出上限。重试次数仍由任务管理；原生参考分析采用上文所述的 LLM 请求时序。达到输出上限的响应不提交，远端结果未知的请求仍可能计费。

原生风格归纳前，观察文本按注册模型容量和原生压力策略进入 profile 的 Compaction 服务；人工判断、完整图片身份和输出 Schema 不进入摘要。压缩调用消耗相同任务的视觉调用预算并采用原生分析时序，保留输入、输出和返回用量，并复用匹配的已提交回执。压缩失败会停止最终归纳，已保存观察保留；不会伪造 Session。Web 将聊天压缩隔离在 Agent preset 内时，工作台在自身可卸载作用域挂载相同的原生 Basic 后端，并关闭自动 Session 监听；可选的 profile 级 `compaction` 字段接受原生 Basic 策略覆盖，不修改聊天实例。没有继承标记的历史快照保持原参数；模型目录更新影响新准备的原生调用，其实际参数在发送前记录。

`vision.vendorVersion` 记录供应商声明的模型版本；未声明时，已保存请求保留重放限制。模型采样、`limits.maxVisionOutputTokens`、`limits.maxReferenceImages` 或 `limits.maxReferenceBytes` 变化会形成新的审核器标识。正式搜图与裁图使用变更后的审核方法前，需要创建新 candidate 并发布对应 release。已有 release 保留原审核方法。

密钥值保存在 DSH 凭据中。本插件只保存凭据引用，初始名称为 `VISUAL_CURATOR_SOURCE_KEY` 和 `VISUAL_CURATOR_VISION_KEY`；修改 JSON 字段并不会保存密钥。来源和媒体使用有界的公网 HTTPS 请求，并检查重定向与 DNS。显式配置的本地视觉 origin 是本地模型的受支持例外。不提供任意请求脚本、模型指定端点或远端收藏夹写入。

预算限制实际尝试次数、字节和耗时。重试消耗同一任务预算；外部请求中断后保留已预留配额，因为供应商可能已经计费。实现报告费用未知，不强制执行货币额度，也不预测最终账单。

“模型&图库设置”将视觉表单与多账号 Unsplash 浏览分开。“添加账号”在本机独立 Chrome 或 Edge 窗口打开 `https://unsplash.com/login`。在官网完成验证与登录后，Host 仅读取影响 Unsplash API URL 的 Cookie，核验当前用户，再交由 DSH 凭据服务保存。密码留在官网，不读取个人浏览器配置。登录窗口与图库请求使用相同的 User-Agent，导航提交后即开始检测；访客 Cookie 不触发账号校验，官网访问校验未通过时会持续显示原因。点击遮罩保留登录弹窗，取消、关闭按钮或 Escape 请求结束连接。每次登录使用临时配置目录，捕获完成、取消或总登录超时后关闭窗口。`source.unsplash.login` 下的 `validationTimeoutMs` 默认 20 秒，`maxValidationAttempts` 默认 3 次，`retryDelayMs` 默认 1 秒并线性退避；临时网络、DNS、响应不完整及单次校验超时会在同一窗口重试。次数用完后暂停自动重试，“重新校验”复用当前窗口并重置尝试次数，仍受原总登录期限约束。证书错误和账号不匹配不自动重试。状态仅保留尝试次数、耗时与 curl 退出码，不包含会话内容。“更新会话”核对已保存用户 ID；再次添加已连接的官网身份会更新原有会话，保留账号 ID、凭据引用、备注、列表位置与默认选择，不增加重复卡片。更新会话时若登录了其他身份，会单独提示账号不匹配。配置只保存账号 ID、备注、用户 ID、用户名和凭据引用。`source.provider` 设为 `unsplash`，`source.unsplash.accounts` 保存这些账号描述，`source.unsplash.defaultAccountId` 选择一个搜索账号或以 `null` 使用公开搜索。账号连接与默认选择即时保存。“高级设置”通过弹窗打开原 HTTP JSON 来源，使用 `source.provider: generic`。

图片工作区的“引用图库收藏夹”打开按账号隔离的弹窗，账号栏保持固定高度，内容区域独立滚动；窄屏使用高度受限的横向账号栏。弹窗首个入口为“收藏图片”，与普通收藏夹分别读取，共用分页、明确勾选及正例或反例引用流程。打开收藏夹时读取一页，滚动时追加分页，上限为 `limits.maxGalleryReferenceFiles`（默认 10,000）。单页读取成功后，提前将下一页元数据读入现有账号缓存，滚动读取复用该请求；预取不改变显示列表与勾选，关闭弹窗时取消。默认不勾选，可逐张选择已加载的图片；“全选”继续读取全部分页，并保留逐张取消的选择。加载过程中也可添加当前已选图片；点击添加时固定所选 ID 并停止当前弹窗的待完成读取，迟到响应不会扩大已受理任务。列表遇到临时网络故障时，在限定次数内重试同一游标；取消读取会立即中断重试等待。次数耗尽后保留已有图片、勾选和失败游标，手动重试从该页继续；认证失败和游标校验失败不自动重试。搜索框明确限定已加载图片。紧凑工具栏左侧集中显示选择、数量和清空操作，右侧显示加载进度，窄屏将进度换到下一行；信息按钮支持悬停、键盘聚焦和点击查看 Unsplash+ 可用性说明。“取消读取”保留预览，重试可从保留的游标继续读取。引用沿用当前素材集及正例或反例角色，每批遵守 `maxImportFiles` 且读取最新版本。

确认加入后由 Host 持有引用任务，关闭弹窗、切换素材集或刷新页面不停止后续批次。素材集菜单和工作区显示同一任务的已确认数量及阶段；工作区使用约 58px 的紧凑进度卡片，保留插画动画、已确认进度和停止操作，并遵循减少动态效果偏好。“停止引用”保留成功结果，未知回执停止后续写入。每个素材集同时仅一个引用任务，执行期间不能分析或归档该素材集。Host 重启将未结束任务标记中断，不自动重放。中断或部分失败的引入在毛玻璃弹窗中展示已保存数量和进度条，并提供“取消引入”和“继续引入”，侧栏不再显示故障提示。继续或取消请求失败时标明对应操作，显示本地化恢复提示及服务返回的错误代码；未确认的响应不视为操作成功。页面已更新而后台仍拒绝新操作时，应重启应用后继续；仅刷新页面不会替换正在运行的后台。关闭按钮或 Escape 立即收起弹窗，不取消任务；素材集页面通过任务标签卡片显示已引入和剩余数量，并保留继续引入入口。继续前会核对原选择与已保存引用，在原任务中仅重试尚未引入的图片；取消保留已确认图片并结束剩余任务。连接故障在现有传输重试用尽后停止后续图片请求。普通引用不会启动模型。图片列表按当前素材集触底加载，角色总数、已加载数量和本次引入进度分别统计；追加引用不使既有分页失效，失败保留图片并提供重试。进度读取不重复构建完整工作区快照；工作区分页在图片卡片投影前校验并截取，任务摘要不构建尚未请求的结果卡片。

每张引用成功关联素材集后才公布进度，因此后续图片仍在登记时，已成功的卡片即可显示。工作区、素材集菜单和重新打开的弹窗使用同一份实时计数，包含当前批次已提交的图片。进度条按该数量填充，并随成功引用进度混合已有强调色与成功色 token，同时保留动效。首张成功前显示列表骨架屏，不显示添加图片的空状态。

工作区入口共享一个内存 store。素材集修订号及成功引用数量不变时复用已读分页；新增引用使用经过校验的尾游标读取，保留已有卡片和未读旧页。集合前缀变化时重新读取一次首屏。手动刷新、写入和连接或授权重置会使相应状态失效。任务轮询结果未变化时不重复发布图库渲染。创建素材集只读取新集合的当前状态及图片页，不等待整个工作台快照或旧任务详情，并显示原生加载指示。Tab 切换替换任务折叠实例，防止退出动画将上一页内容带入当前页面。空素材集使用紧凑的响应式布局和内置透明插画。

持久化写入通过项目存储服务，使用已有只读基线和具有权威数据的按记录增量单元。新依赖先持久化，随后由提交清单公布；失败提交不可见，并保留原操作 ID 供重试。读取验证两部分组合的数据，初始化时拒绝基线变更。增量记录使用 Host 的手动载入表：启动时载入当前清单依赖，清单成功替换后释放被替代的缓存项，保留全部持久记录。复用旧内容键时，先校验其保存值再公布。操作恢复仅读取匹配回执，工作区修订号不复制历史模型内容。备份需同时保留两个存储单元，参见[升级指引](../../../docs/upgrade-guide/v0.2.1-rc.3/visual-curator-incremental-storage/guide.zh.md)。

图库登记保存远程引用，不下载或转码图片字节。记录保留经过白名单验证的公开预览 URL、账号与来源标识，以及提供方报告的尺寸。原生分析把下载的像素接纳为原生附件；HTTP 备用接口以 `image_url` 发送链接，需要模型服务能够访问来源。`remote-url-v1` 仍标识来源描述，原生请求收据另行保留经过校验的像素身份。预览读取和原生附件接纳都不会把来源尺寸变成已测量事实，也不会授予字节导出权限。参考数据包包含来源链接及重放限制；裁图和字节导出需要已验证的字节来源图片。已有本地路径和字节导入仍可读取。显式 `gallery-import` API 继续默认使用原字节模式，图库 UI 会提交 `mode: remote-reference`。UI 写入前确认 Host 支持远程登记。

登记过程显示账号核验、逐项引用和保存阶段及处理数量。“取消引用”中止尚未完成的详情请求，并停止后续图片和批次；已开始的原子提交完成后，成功前缀仍保留在素材集中。回执无法确认时停止后续批次，不自动重试。取消、进度和元数据按所属账号及 Session 隔离。

每个账号分别提供收藏夹 Collections 和收藏图片 Bookmarks 视图。私有读取以会话核对保存的用户 ID，成功核验按 `source.unsplash.identityCacheTtlMs` 复用（默认 180000；设为零禁用成功缓存）。只有 API 实例、账号 ID 和预期用户 ID 都相同才能复用，凭据或传输配置变化会更换实例；过期、显式刷新和认证拒绝会让复用失效。字节导入与显式账号校验仍进行新鲜核验，单个等待者取消不会中止其他等待者共享的核验。进入收藏夹后，搜索按图片标题和摄影师覆盖全部元数据分页，清空搜索恢复收藏夹；“全站搜索”仍搜索 Unsplash 全站。适配器兼容数组与 results 对象，continuation 保留页内偏移和 ID 摘要，避免截断额外图片；半页内容变化时必须显式刷新。

图库元数据按账号身份、收藏夹或搜索范围、分页及配置版本缓存，同一浏览器标签页刷新后也可复用。`source.unsplash.cache` 配置 `ttlMs`（默认 300000）、`maxPages`（120）和 `maxBytes`（2097152）。“刷新当前列表”先让该列表分页失效再重新读取。过期分页和旧连接配置不会命中；缓存达到上限时淘汰较早的分页。不缓存图片字节、Cookie 或授权参数；浏览器禁用会话存储时，内存缓存仍遵守相同的分页与字节上限。导入和登录操作始终请求 Host。

上方设置概览可以向上滚走；图库使用完整滚动视口高度，到达顶部留白后保持位置，结果列表独立滚动。紧凑工具栏与左侧全站搜图行对齐，不重复显示账号名称；图库 Tab 使用小图标、浅色选中背景和共享滑动下划线，收藏夹路径与批量选择共用一条紧凑工具栏。加载时使用收藏夹或图片骨架屏，面板高度保持一致。收藏夹和图片列表接近底部时自动追加下一批，保留已有卡片与选择，不显示分页按钮；屏幕外卡片延后绘制。收藏夹引用预览也随滚动读取后续元数据分页。右键图片或按 Shift+F10 直接打开大图，不显示中间菜单或覆盖图标；共享大图预览使用内置透明图片叠层素材显示加载动画，成功后淡入，失败时可重试，支持 Escape 关闭并返回焦点。“全选已加载”覆盖当前已加载且符合筛选的图片，取消时保留范围外选择。图库导入按 `maxImportFiles` 分批提交并读取新修订号，结果不明时停止后续批次。底部操作栏集中显示目标素材集和引用操作，在窄窗口分成两行。收藏夹引用弹窗复用同一缓存、骨架屏与预览组件。

选择图片及目标素材集，再使用“加入素材集”或“加入并分析”。登记固定来源与账号身份，保留逐图收据并添加正例远程引用，不复制像素；本地路径引用保留原图位置。图库登记使用 references-only，不授权导出图片字节。Unsplash+ 照片可以手动或全选勾选，以公开预览链接登记并参与视觉分析；来源描述保留 Unsplash+ 标记。分析与参考数据包复用自动模型档案流程。来源标识 `unsplash` 通过固定风格搜图使用选定账号；没有显式检索词时，档案搜索提示成为召回关键词。初筛、裁图规划和终审均接收固定的匹配提示词与可替代规则分组。搜索裁图沿用已提交源审，终审仍检查实际裁后像素。结果按保存的最终偏好分和稳定图片 ID 排序；读取投影不改写不可变选择，也不调用模型。

Unsplash Web 适配器依据所提供接口包的读取行为与真实响应实现。它需要系统 curl，可通过 `source.unsplash.curlBinary` 配置程序，通过 `source.unsplash.userAgent` 配置请求标识。官网登录使用 `playwright-core` 和已安装浏览器，不下载浏览器。`source.unsplash.login.browser` 可为 `auto`、`msedge` 或 `chrome`；`executablePath` 可指定部署方管理的程序，`timeoutMs`、`launchTimeoutMs` 和 `pollIntervalMs` 限制登录等待、启动与轮询。Host 需要本机图形会话显示该窗口。没有 Python 依赖。每次 API 请求使用独立的临时 Cookie 文件、公网 DNS 检查、HTTPS、响应限制及同源重定向；会话值不进入进程参数或任务 JSON。JSON 响应协商压缩。`source.unsplash.connectTimeoutMs` 限制每次连接与 TLS 握手，默认 5 秒；临时 curl 故障在同一请求期限内按 `source.unsplash.readRetryAttempts` 重试，默认 1 次，并依次使用已验证的 DNS 地址。后续请求优先使用已成功的地址，但该地址必须仍在本次校验通过的公共 DNS 结果中。收藏夹枚举沿用配置的重试次数，失败页面之间按 `source.unsplash.readRetryDelayMs` 等待（默认 1 秒），等待可以取消。证书错误不重试。访问校验与请求共享截止时间。网页接口可以独立于官方 API 变化；会话过期、访问校验及限流会明确报告。连接多个账号不会自动合并配额或轮换身份。

<a id="wallpaper-workflow"></a>
### 壁纸工作流

壁纸制作在布局前检查原图可用性；启用自动壁纸的找图任务会排除图库明确限制的原图。已有批次包含受限来源时，在任务预算内复用冻结的关键词、参考图和完整视觉验收规则补找，只有可获取原图且复核通过的候选才能替换失败位置，并记录被替换的来源。完整复核使用有保存记录且受模型输入限额约束的缩小视图，尺寸检查与渲染继续使用原始尺寸和像素；复用图库页面已返回的原图地址，避免重复查询详情。继续任务保留已保存原图和处理产物，不反复重试永久不可用的来源。下载节点分别展示已保存、来源受限、下载异常与等待下载数量；图片导航使用本地小预览或已保存的远程缩略图描述，覆盖缺少本地预览的历史原图。

画布标题与批次筛选使用固定的任务标识，不再使用当前行号。加载、筛选和自动排列不会更改批次标识；新批次放入未占用区域。自动布局的批次避开已占用区域，含手动位置的批次保持原位。旧版迁移坐标均视为手动位置；新节点和显式自动排列后的节点使用自动位置，拖动后转为手动。调整尺寸只推动同批的自动节点，手动卡片及其他批次限制本次可用尺寸；显式自动排列可让当前显示的节点重新参与自动布局。拖动过程中推迟批次校正，交互结束后处理。布局仍仅保存在本机，不修改任务记录。导入或分析参考图时即显示数据集节点，等待观察保存；上游运行时可向等待节点显示传输动画，但不据此把下游标为运行或完成。新卡片在本次画布中只播放一次入场动画，视口虚拟化不重复播放。连线使用原生 SVG 沿固定曲线运动，保留终点箭头并读取主题动效时长；减少动态效果设置及页面隐藏时停止粒子。

参考图缩略图支持触控板、滚动条、左右按钮及聚焦后的方向键横向查看；“查看全部”直接打开参考图卡片弹窗，上方固定导入与搜索工具，中间网格独立滚动，底部保留加载与手动分析操作。名称和角色筛选作用于已加载图片，不改变参考工作区的筛选；大图预览沿用弹窗当前的筛选顺序。卡片完整容纳图片，显示两行名称、保存的尺寸和角色，标题提示与预览操作可查看完整名称；窄窗口采用双列卡片并允许工具换行。预览继续使用按所有者隔离、有容量限制的 Blob 缓存和合并中的请求，任务轮询不重载成功图片；单图预览地址相同时复用已加载的 Blob。画布中已有弹窗的功能保留在画布打开，没有弹窗的设置才跳转页面。

画布中的数据集列表与包详情互斥显示，查看指定包时直接打开详情；“返回数据集列表”保留筛选、历史展开状态及表格滚动位置，“关闭”则回到原入口。列表明确分配各列宽度，将规则比例成组显示，表头与加载操作保持可见，长表在内部滚动；窄窗口保留表格并允许横向查看。名称和操作样式由数据集工作区持有，因此在独立弹窗和数据集页面中均生效。

已受理但没有找图 Run 的启动记录显示为等待，卡片及右键菜单均提供打开所属会话和停止任务的操作。受理成功不代表已经开始检索；旧等待记录保留可查、可停止，画布不会自动重新提交其会话提示。

点击卡片或框选后，可按 Delete 或 Backspace、使用右键菜单或工具栏删除。确认弹窗将同一启动任务的卡片合并为一个任务批次；先停止来源任务及关联壁纸任务，再统一隐藏任务历史和准备记录。原始任务记录、参考图片、数据集、风格和输出文件继续保留。弹窗显示进度及尚未确认的删除结果，重试沿用同一操作 ID 核对已保存结果。编辑字段或操作弹窗、菜单时不触发键盘删除。准备卡片保持身份和位置，直到实际批次加载完成；筛选不会把该身份转给另一个 Run。

找图弹窗展示视觉模型目录及当前配置路由。显式选择会冻结到本批任务，用于检索规划、筛选及自动壁纸处理，不修改全局配置；历史会话路由继续可读。必填项通过表单提交校验，包括菜单式选择、纯空白需求与整数数量上下限；数据集自动选择仍为可选方式。

在找图弹窗将输出目标设为“壁纸工作流”，或对已完成批次选择“生成本批壁纸”。主要找图入口默认选择壁纸目标，仍可明确选择仅预览、原图或指定用途。壁纸任务处理本批全部已保存的合格结果，包括来源受限或搜索预算耗尽后的部分合格结果；队列按图片版本去重，保留受理时的风格、数据集、模型路由与模板，下游任务另行冻结 Skill 和提示词版本。零结果及已取消的搜索不启动后续处理。历史预览任务保留原目标，需要明确启动壁纸处理。准备失败及下游衔接错误留在对应任务中；顶部进度跟随实际壁纸处理，不在找图结束时宣称整条流程完成。关闭页面保留后台任务，停止本次任务也停止已受理的下游壁纸处理。

`wallpaper` 配置固定输出 1845×3280，安全区为 `(258,1032,1329,1686)`。新任务可调整默认 32px 上方缓冲、每侧 66px 容差及下方 84px 容差。主体重要上沿避开 `y<1032` 时间区，关键部位保留在安全区，左右下非关键轮廓允许在容差内延伸。风景和抽象图保护局部焦点、透视和结构，不把整个场景压进安全框。视觉模型分析实际原图，涵盖任意对象、共同主角及自然特写；名称和检索词只作背景。模型区域是推断依据，不是实测分割。

处理顺序为优先裁剪、调整等比位置、必要时仅扩背景。原主体不放大、不拉伸。Sharp 执行确定性布局，主体、关键部位和焦点保护框内恢复原图像素；未保护的原图背景边缘可与生成背景平滑过渡。`wallpaper.backgroundTransitionPixels` 默认 192，设为 0 恢复硬边合成；原图文件及旧成品不改写。编辑蒙版保护原图内部和全部标注框，开放外围及背景衔接带。返回图片长宽比只允许一个像素的舍入差，不通过裁切掩盖比例错误；保存实际生成尺寸供复审核对。`wallpaper-continue` 可显式指定 `recompose:{imageVersionId,revision}`，复用该轮生成回执重新合成和复审，禁止新生图或自动生成返工。干净壁纸、构图标注图与锁屏模拟图分别保存。纯裁剪记录为 `crop`；生成背景的派生图记录为 `composition`，保存来源、规划及生成回执。只有独立校验通过的干净图片计入成品并提供最终下载。复审检查实际像素、原内容保护、时间避让及可读性、构图、接缝和固定风格，同时核对真实尺寸及透明缺口。

“原图下载与保存”节点校验对应图片后保存原始字节、方向校正后的完整尺寸图片、下载次数及保存回执。直接裁剪使用有上限的单图并发队列，取得原图后即可观察，不等待其他图片下载完成；默认并发两张，同时受 `limits.maxConcurrentRequests` 限制。新任务的 `limits.originalDownloadTimeoutMs` 为总传输上限，默认 300000 毫秒；`limits.originalDownloadIdleTimeoutMs` 为无数据时限，默认 60000 毫秒，与普通接口请求分开。旧冻结任务继续使用其原有时限；显式重试原图会创建采用当前传输策略的续接，连接、取消和字节限制仍然有效。Unsplash+ 下载使用授权接口返回且与当前图片路径匹配的 `delivery.unsplash.com` 签名原图，图库预览继续遵守原有来源限制。续跑复用已保存文件；临时网络错误及 HTTP 408/425/429/5xx 按冻结的请求与字节预算自动重试。受限或缺失的原图明确显示，只阻塞对应图片的后续步骤。模型分析使用按 `limits.previewMaxDimension` 及视觉字节限额约束的无损 WebP，保存请求中的原图与分析图尺寸、摘要及文件引用；实际裁剪仍使用完整尺寸原图。受限原图不会被图库预览图替代。任务栏与失败详情共用当前图片的恢复判断，历史版本不能发起重试。图片编辑先查询旧回执，有结果或结果未知时复用原操作；只有确认失败且原有编辑和返工次数允许时，才会创建新版本。处理阶段默认同时执行两张，每图最多返工两轮、调用 Codex 编辑两次，设置只能降低上限。原图取得失败或单图失败不会丢弃其余队列。继续遵守已有请求、下载、存储和时间限制。预算耗尽时保留未完成图片；“继续未完成图片”显式创建新任务预算，保留编辑计数和回执。“暂停处理”保存进度，“继续处理”恢复已受理工作。取消先停止后续处理，再尝试取消远端生图；远端未确认取消或结果未知时明确提示，不自动重复付费派发。稳定操作身份使重复受理和回执恢复保持幂等。

批次总览展示原图下载、图片处理及复审成品的汇总阶段。图片导航逐步保留所有已到达节点，同时显示当前步骤与紧邻的下一个接收步骤，从批次内七个稳定步骤中选择：原图与保存、主体与安全区规划、裁剪与尺寸规划、裁剪与必要扩图、清晰度与超分、质量复审、成品与导出。下一步只说明需要的输入，不表示已经执行。返工期间保留制作与上次失败的复审节点、原因和回线；已到达步骤继续显示在画布上，步骤菜单定位其保存结果。主体观察保持原图，尺寸规划保持编辑前的布局，后续复审或超分不会替换前序预览。自动坐标按步骤顺序上下错落展开，并按卡片宽度保留横向间距；“整理布局”可恢复不重叠的排列。切换图片更新内容和状态，保留节点位置、宽高、折叠和视角；已有单图布局仍单独保留。图片侧栏可拖拽调整宽度并记住设置，每组最多十二张缩略图，最后一张可完整滚入视野；窄窗口改用横向导航。图片选择菜单使用独立背景、清晰行高，并限制在视口内。接口仅读取所选图片的完整规划，目录只附带状态和已保存预览链接，不回退到大尺寸原图。已取消请求或与请求不符的图片窗口不能显示另一张图的编辑器或结果。内容淡入不移动节点，并遵循减少动态效果设置。详细依据和历史版本按需打开，只有最新结果通过全部检查才提供成品导出。正向连线保留已到达的处理顺序，只有实际返工时增加回线。步骤定位可聚焦单个结果，“适应全部”可查看已到达的完整流程。

素材库中每张图片都可通过“调整参考”选择正例、反例或未定角色、整体或指定维度，并选填原因。保存只替换当前关联，保留原参考、反馈、观察和数据集。新逐图观察使用 `visual-curator-reference-v4`（保留 V3 读取），区分主次对象、相对大小、画框截断、遮挡和不可辨细节；新归纳使用 `visual-curator-summary-v5`，不把无原因的拒绝推测写成检索禁忌，导出的匹配提示词由当前启用规则及替代分组编译，不直接执行推测性总结。

工作台有导入或分析任务时按既有间隔更新；空闲发现外部任务使用 `limits.idlePollIntervalMs`，新配置默认 30 秒。页面隐藏或最后一个工作台关闭时停止轮询，返回时立即读取。参考观察的每个维度只能出现一次，局部事实与不确定项合并在同一条观察中。

“清晰度与超分”单独记录实际检查，历史没有证据时保持未执行。新 `wallpaper-review-v4` 增加必需的清晰度检查，附带从原图和成品提取、保存坐标映射的主体细节图。原图主体截断时直接拒绝，不消耗重规划次数或补画缺失结构；细节未知时仍需复核。只有清晰度不通过且原有验收项全部通过时，才允许一次有界的 CPU ESPCN 亮度超分。原版继续保留，全部关键区域保持增强前的精确像素；内部 3 倍重建后在固定输出尺寸回采样并保守混合，不新增生图调用或重置编辑次数。新版本还必须完整复审结构、颜色、标识、接缝和清晰度，没有像素变化不能算作已修复。`wallpaper.clarity` 限额随新任务固定，旧提示词和已有结果不改写。

Unsplash 原图优先下载已授权的 `raw` 地址，其次为 `full`；`regular`、`small` 仍是预览，不能冒充原图。原图缺失、受限或超出大小时，继续遵守既有来源及字节限制。

新任务固定 `wallpaper-plan-v6` 与 `wallpaper-outpaint-v4`。模型观察完整主体、可见次要人物、保护范围和不确定项，Host 按相同的固定安全区计算整数缩放后的等比位置；优先直接裁剪，不放大原图。普通环境不作为必须保留的锚点，已有 V1–V4 任务继续使用原规划协议。规划存在未决证据或截断记录时，每版规划最多进行一次原图局部复核：保存真实局部裁片并结合全图，逐项解决原疑点后才自动继续；保留原有全部保护范围，重新检查几何，成品仍需独立复审。缺失、遮挡或仍无法辨识的部位继续拦截，视觉和生图限额不变。自动返工保留累计保护范围；不通过项的图片证据未改变时停止重复复审，不能靠更换主体送审区域绕过未修复的时间、日期或背景问题。显式复审请求仍保留。显式 `wallpaper-continue` 携带 `reinspect:{imageVersionId}` 为已保存的规划待确认图片创建独立恢复任务，保留旧任务与原图像素。结构化响应被拒绝时保留失败请求；原限额允许的重试会接收具体解析错误，并须重新输出完整且通过独立校验的响应，不重置重试预算，也不由 Host 删除多余字段。当前 V4 扩图让编辑蒙版与保护区域合成器开放相同背景，并恢复全部标注区域的原图像素；较早固定的任务仍沿用原图边缘合成。显式恢复模式 `protected-context-v2` 让编辑蒙版与合成器开放相同的未保护背景，实际衔接仍须由独立复审验收。旧提示词版本及合成模式继续对应其已保存回执。显式 `wallpaper-plan-update` 请求可携带 `backgroundPolicy:"current"`，为新版本选择当前背景提示词和蒙版，其他固定设置及累计编辑次数保持不变。已有生成回执不能改称使用了不同的蒙版。自动返工停止后仍可提交有效的手动修订，但不重置生图或视觉请求限制；接缝、重复主体及不确定结果仍由独立复审拦截。

执行工作区通过“批次画布”“任务列表”“单图流程”三个标签和素材集、来源批次、已保存任务及当前图片的面包屑衔接。任务列表沿用画布工具栏的颜色，以紧凑工具栏排列筛选、状态、目标进度和操作，完整需求可从任务详情查看。执行视图贴齐工作区边缘，不显示“返回素材库”按钮。有文字的返工连线按实际文字宽度和端口留白平滑拉开节点，并遵循减少动态效果偏好；单任务省去重复切换控件，刷新元数据时保留已确认的流程身份。结果卡片和画布任务详情可直接进入对应视图。导航使用源图目录身份，不把成品的直接父图误当作目录条目。`wallpaper-read` 可显式携带 `runId`，读取同一 `sourceRunId` 下有权访问的历史子任务；任务不匹配时拒绝请求，不回退到最新任务。视图切换保留会话上下文及已有画布布局；归档素材集仍可查看历史工作流，不会恢复素材集或开启新检索。

四个单图步骤的详情显示逐图版本、主体依据、标注、工具回执、实际产物和独立复审。修改布局前先暂停任务并打开“修改规划”。图形编辑器显示固定安全框、时间区、上方缓冲及水平和竖直中心参考线，可拖动、缩放原图，通过图形或数值编辑归一化保护框；坐标使用完整原图尺寸，编辑器加载已保存的小预览。高级字段继续提供 JSON。Host 检查上方缓冲，将源图透明空洞计入缺少背景。新版本保留旧产物，只使该图的执行与复审失效，不重跑导入、数据集和找图。版本选择器可查看已保存轮次。画布轮询读取持久任务状态，不重新调用模型。画布使用共享的逐图进度统计显示运行高亮、步骤失败及前置阻塞。只有真实运行步骤的入线显示方向箭头和移动标记，长曲线保持静态；平移、拖动和缩放期间暂停移动。缩放控制独立订阅视口，减少任务节点重渲染；减少动态效果偏好会关闭移动标记。

对已有生成背景与原图景物不对齐的成品，`wallpaper-continue` 支持 `recompose:{imageVersionId,revision,mode:"protected-context-v1",reviewPolicy:"current"}`。显式模式保留全部标注区域及相邻背景，再羽化衔接同一张生成全景。`wallpaper.backgroundContextPixels` 默认 128，控制保留的背景上下文；`backgroundTransitionPixels` 单独控制羽化宽度。省略 mode 仍使用 `source-edge-v1`。只重新合成和复审选中图片，其余未完成项保持原状态，也不显示为当前活动步骤。不派发新生图，原生成画布及蒙版保留供审计，独立复审未通过不能计入成品。操作身份包含 mode 与 reviewPolicy；已接纳的相同请求继续返回原回执。

新壁纸任务使用 `wallpaper-review-v4`，保留 V3 完整主体要求。复审分别判断原图与实际干净成品中的主体是否完整，将依据绑定到不同的图片 ID，并单独核对固定任务要求。任一图片的主体被截断，即使模型七项标签全通过也会被否决；完整性、遮挡或任务依据不明则保留复核。几何校验及保护区域像素保真不能证明主体标注完整，正常透视与自身遮挡也不等于截断。已有壁纸详情中的“按当前规则复审”通过 `wallpaper-continue` 的 `review:{outputId}` 建立独立子任务，复用原图、干净成品和已保存模拟图，使用当前选定的视觉模型；不派发生图，也不重置累计编辑次数。显式复审已有成品时，经过严格校验并绑定本次原图/成品的截断证据可独立否决，即使响应的其它字段存在格式错误；此类记录带有 `subjectRejectionOnly`，其余检查标为未知，原始请求错误保留，不能通过此路径计入合格成品。历史任务、产物及 V1/V2 决定保持原样。V3/V4 扩展插件自有检查点数据，旧插件版本不能读取这些新记录。

`wallpaper-review-v2` 与 V3 共用的风格计算保留已冻结画像风格门槛：模型对每条请求的视觉规则报告一次成品像素依据，Host 通过既有规则覆盖策略计算固定权重、硬性要求及替代组。单项软性色板偏好不能要求重绘受保护的原车。其余六项视觉检查继续独立验收；证据未知和仅来源主体风格不符均保留复核。V2 保存模型原始风格意见、逐规则依据和计算结果。`reviewPolicy:"current"` 只为新恢复任务选择 V2，要求该任务具有适用的固定策略；旧标准继续使用 V1。已有 V1 提示词、输出 schema 及请求描述保持不变。可选的合成模式与 V2 复审字段扩展插件自有检查点数据；旧记录直接读取且不重写，旧插件版本不能读取新 V2 记录。符合 schema 但完全不与画布相交的模型规划按失败轮次保留，继续任务仍遵守原返工上限；旧任务已提交的此类规划可先复放，再请求下一轮。存储额度耗尽时保留已提交产物和具体的安全诊断。

原生 Skill `visual-wallpaper-composition` 的经验由当前 Profile 私有持有。完成案例关联原图、规划、工具参数、产物、程序检查、模型复审及单独署名的人工反馈；同源图片及派生图归为一个家族。累计 20 个新的有效家族后，整理有长度限制的候选经验，保存父版本及差异。单纯技术故障不作为训练证据，基准家族不进入经验整理。主体规划、背景扩图、成品复审及经验整理分别保存提示词标识、内容和摘要。

在“构图经验”中查看原图并明确确认基准期望。自动启用至少需要 12 个独立、已确认的家族，单主体、多主体、场景和抽象各至少三例。评测冻结标签，使用真实原图与已有产物比较当前版本和候选，每个候选最多 48 次视觉调用，不额外调用生图。需要新生成结果、比较未完成或基准不足时均不启用。晋升要求无错误放行、正确数不下降，并且正确数增加或复审轮数减少。可在同一弹窗暂停自动启用或恢复已验证的历史版本；已受理任务继续使用冻结的 Skill。不修改全局指令、Codex 设置、Memories 或模型权重。

本地验证可恢复蒙版编辑时，需要配套的源码桌面。在仓库根目录运行 `pnpm run dev:desktop`，配置原生视觉路由和 Codex 生图模型，再从壁纸入口操作。仅打包 Visual Curator 时运行 `pnpm run dsh-plugin-visual-curator:local`；打包及手动替换步骤由[本地开发规范](../../release-governance/local-development/README.zh.md)统一维护。单独导入 Visual Curator 包不会为旧桌面增加原生 LLM 新接口，也不会替换旧 Codex 适配器；旧环境仍可纯裁剪，需要扩背景时报告能力缺失。测试新 `composition` 数据前备份 Profile，[数据兼容说明](../../../docs/upgrade-guide/v0.2.2-rc.1/visual-curator-wallpaper-data/guide.zh.md)定义降级限制。

### 建立固定风格

分析范围可选择全部参考、仅正例或仅反例，并分别选择复用观察或确认重新分析。正例批次描述希望保留的可迁移特征，反例批次描述可见的不匹配依据及不确定性；仅凭反例角色不能判定究竟哪个特征导致拒绝，角色冲突会明确保留。其他角色继续使用图片输入、规则、判断及处理方式仍匹配的已提交观察。缺失观察保持待处理，按角色分析的进度只统计所选图片。

参考图分析齐全后，模型将已保存的观察统一整理为规则、可替代分组和候选图匹配提示词，再自动保存带校验和的完整参考包。仅有反例的素材集保留观察及按角色导出入口，不自动形成目标风格。封装提交失败可从已保存归纳继续，不再请求模型。最新完整包固定在数据集列表首位；当前依据变化时标记为“上次完整数据集”。分析进行或暂停时，也可选择有权使用的历史完整版本找图，任务固定该版本的规则与参考图，不受当前草稿变动影响。

素材集菜单可重命名当前训练集，保留原有身份、引用及已发布版本，校验当前修订号，并等待正在写入引用的任务结束后操作。

规则复选框立即反馈，保存按已确认的不可变档案身份串行执行；保存期间的多次调整合并进下一次请求。回执仅更新选项元数据，复用逐图观察及已加载的引用分页。生成、找图及正常关闭会先完成待保存调整；未知回执沿原操作身份重试，暂时关闭不承诺回滚，重新打开会核对当前已保存选项。

数据集逐图观察接近底部时自动读取下一页，失败保留已有内容并暂停自动读取，点击重试后继续；末页不再发起读取。

找图批次仅授权并投影所请求的图片窗口。相同轮询结果复用页面身份；已结束历史按缓存周期刷新，活跃或失败视图使用正常轮询间隔，预览授权过期时刷新对应分页。后台重启后可依据持久会话元数据读取历史预览，不恢复 Agent；不存在的会话仍不可读，控制与写入仍须原会话处于运行态。

找图弹窗沿用既有材质，并使用已配置的视觉模型路由。新的工作流任务根据所选数据集、启用规则、可替代风格组、需求及预算，保存一次结构化检索规划；查询词使用该规划，断点继续时复用已保存结果。后台直接执行找图，不再要求另一个会话 Agent 重复准备和启动同一任务。所属 Session 继续承担授权及请求检查。历史会话任务保留已记录的模型选择与提示提交身份。

分析范围弹窗通过卡片展示待处理分析和全部重新分析，并分别显示当前范围内的图片总数、正例及反例数量；按图片去重统计，待定或混合角色单独显示。打开时复用当前素材集修订、分析进度、配置和工作区修订对应的已确认方案，或共享页面正在进行的读取；关闭只取消弹窗的等待。修订变化或显式重试会重新读取，任务受理时始终再次校验方案摘要。点击卡片启动对应范围；待处理分析复用已有有效观察，最终风格整理仍可能调用模型。

插件详情页使用与 AFP 相同的原生布局：图标、示例、说明、分组可选功能及开关，共十二项。技能包括参考图与风格、风格分析与校准、按风格找图、智能裁图与构图、人工反馈整理、数据集与 Skill 导出。工具分为只读工具、找图与裁图、反馈建议与导出，合计仍为九个 Agent 工具，关闭某组仅撤销该组注册。

集合、批次、图片、筛选和右键菜单统一使用 13px 字体、34px 行高；宽度按内容在 232px 至 400px 内适配，并受可用视口限制。宽下拉框不再强制撑大弹出菜单，新画布布局让相邻节点轻微错位，连线根据节点位置自动选择侧边或上下端口。运行中的蚂蚁线在拖动、缩放、刷新和切图时持续播放，箭头按连线长度调整间距且最多显示五枚，前进速度保持一致。会话准备与实际检索、初筛和完整复审分开显示；任务详情按需求、核心指标和诊断分组；壁纸设置按输出规格、安全区参数、返工限制与模型分组。会话卡片可收为悬浮胶囊，仅在对话页且宽度足够时显示。完成的连线保持绿色；已有位置、视角和单图步骤的折叠状态保持不变。进度与任务详情浮层仍为结构化内容保留必要空间。工作流工具栏左侧集中展示批次导航、标题与状态，右侧放批次选择和操作；画布较窄时按组换行。

设置侧栏、全局面板、会话 Tab 三个页面入口默认关闭，在原生插件详情页启用入口后即可打开工作台。素材集使用原图路径引用，以网格或列表浏览完整画面，按文件名和参考类型筛选；筛选不改变分析输入。顶部采用两层布局：56px 应用栏左侧紧凑排列带边框的素材集切换框与一级 Tab，右侧保留模型状态和刷新；44px 内容栏将工作区 Tab、画像入口、添加引用和找图操作排在同一行，横跨整个工作区。两个一级 Tab 共用原生选中背景、文字、焦点和键盘交互，并沿用现有主题 token。两层沿用现有主题 token 与键盘交互，根据工作区容器宽度换行，素材集长名称在切换框内省略，菜单中可查看完整名称。图片工具栏提供参考类型筛选、文件名搜索和视图切换；“添加引用”菜单内选择正例或反例。网格使用等宽卡片，桌面每行 5–7 列，窄屏每行两列；3:2 预览区域按原比例完整展示图片，下方保留两行标题、尺寸和参考类型。远程卡片读取已保存的缩略图，打开预览时保留完整图片地址。图片列表首屏读取和预览等待使用同尺寸骨架屏；追加读取保留已有卡片，不在底部添加占位卡片；失败预览显示内置插画，不放置单卡重试按钮，顶部“刷新”统一重新加载失败预览并保留已成功的图片。素材集菜单提供“删除当前素材集”和“全部删除训练集”及确认弹窗；批量删除固定确认名单、显示已确认进度，并在首个失败项停止。此前提交的移除仍然保留，重试复用各项操作 ID，确认后新增的训练集不会被删除。删除流程复用既有归档操作并检查显示的修订号，保留原始图片、任务历史和导出资料。删除后选择剩余可用素材集，删除最后一项后显示空工作区；图库导入目标排除已移除的素材集。300px 画像栏从内容导航下方开始，集中展示摘要、采用规则、风格变体和分析操作，独立滚动；收起时保留图片筛选并将焦点返回开关。工作区宽度不足 1100px 时改用共享 Modal 查看画像，支持 Escape 关闭与焦点返回；完整档案入口沿用既有编辑弹窗。模型&图库设置占满可用内容宽度，左右保留 24px，窄容器收紧至 16px，并沿用共享 Tab、响应式表单和固定保存行。图库账号导航使用紧凑双行布局和小尺寸默认标签。高级图库与登录表单使用 13px 字段文字和 14px 标题；高级表单限制内容滚动区域并保留操作按钮。弹窗打开时暂停背后的档案边框装饰动画，关闭后恢复。找图与裁剪使用带透明找图裁剪插画的单一紧凑空状态，按画像是否可用引导准备参考或填写任务要求；有任务时保留列表与详情分栏，桌面收紧列表宽度，窄容器上下排列。页面使用 DSH 组件、语义主题色和共享折叠动画；关闭入口不会删除数据或停止任务。

本地窗口、路径、图库引用弹窗和已完成找图结果的引用，在导入结束后只登记一次整理意图；高级图库保留显式的“只导入”选项。多次导入复用未结束的分析，并为最新素材集修订排队，取消则停止待处理整理。模型或配置失败保留导入记录；已配置的视觉路由负责观察与风格归纳，人工选择和原始参考角色分别保留。

本地流程为“引用图片 → 视觉 API 分析 → 自动整理并采用规则 → 保存参考数据集 → 按需调整”。每张参考图在配置的图片与字节限制内分析，跨图归纳接收全部观察和固定判断，代表像素交替覆盖正反例。第二版归纳输出可替代的风格组及默认规则选择。模型档案保留图片依据、选择理由与模型来源，不创建人工确认标签，也不覆盖人工草稿规则。题材信息、缺少依据和冲突的参考项默认停用。用户选择和描述调整保存为不可变版本，重新分析时保留；依据消失时停用对应规则。重新分析失败时保留此前可用档案。

所有新建参考分析先逐批保存图片观察，不生成规则建议，再统一归纳当前可用的观察，生成规则、风格变体和搜索提示。仅分析部分角色时先保存临时观察包，等待其余参考图分析齐全。新请求中的旧 buildDataset 开关不再关闭整理与数据集保存。观察模式随任务冻结，并与模型可见的输出 Schema 一同记录；历史任务未记录该模式时，恢复仍使用原响应格式。观察阶段的检查点结果保留空 `suggestedRules` 列表；仅历史冻结任务保留直接返回逐批建议的方式。最终归纳失败时，已经完成的观察检查点仍保留。

新分析检查点从已提交的原始请求回执计算 observationPromptVersion：单一已知版本记录 visual-curator-v1 或 visual-curator-reference-v2，两者共存记录 mixed，缺少或不支持的回执记录 unknown。旧检查点保留原 v1 值，不执行迁移；每个样本通过 inferred.requestId 追溯原请求。

完整分析自动保存模型档案。风格档案弹窗左侧显示整理并选中的规则，右侧联动对应参考图和模型观察；可选调整自动保存，无需逐条人工审核。两栏独立滚动，窄窗口在规则与依据之间切换；底部固定显示保存、导出状态与生成数据集操作。第二版数据包将 style-profile.json、samples.jsonl、references.json、SKILL.md 和带校验和的清单封装为一个 JSON 文件，使用原路径资源引用，不包含图片副本或训练后权重。这类仅引用的参考数据包无需人工发布或数据划分；原有第一版人工监督导出继续使用已发布版本、人工标签和已确认划分。Agent 找图和裁图可在 releaseId 参数中传入有效 modelProfile.id，固定该版本并检查实际候选像素；模型档案仅接受 purpose 为 reference、kind 为 style 或 skill 的导出，训练数据与图片字节权限保持独立。

新数据包使用 generatorVersion 4：当前 activeRules 与已启用的 ruleSelections（包括用户调整的描述）优先于历史模型归纳及匹配提示词；停用规则只保留为参考。已有导出保持原内容并可继续读取。

生成数据集可选择完整参考包、仅正例观察或仅反例观察。按角色导出的观察包保留所选图片引用及逐图观察，不包含启用规则、风格组或匹配提示词，无需采用风格规则，不能作为按风格找图的主数据集。右侧图片区随所选角色切换并展示已保存的逐图观察，完整模式恢复所选规则的图片依据；预览复用档案中的观察，滚动时分批追加。所选范围随后台任务固定，回执未知时重试沿用该范围的操作 ID。自动保存的混合或待定观察包使用 sampleScope observations；未标记 sampleScope 的已有格式二记录仍表示完整参考包。列表分开展示数据包类型、图片总数和生成时固定的正例、反例及待定数量；即使已有当前版本的观察包，仍会提示尚缺已完成的完整包。逐图观察按角色筛选后分页，重试保留同一筛选。档案读取期间明确显示正在核对，暂不可生成；关闭弹窗不会停止已提交的生成任务。

生成数据集时，内容区域显示半透明遮罩，复用引用任务插画，并按实际完成的图片校验、逐图整理、文件封装和持久保存显示进度。回执返回前也可关闭弹窗；工作台保留原操作 ID 并跟踪 Host 任务，回执未知时由用户显式核对原请求。关闭或切换页面不会停止已受理的生成任务。参考页显示共享后台进度卡片；“数据集”页按当前素材集列出任务和数据包，支持状态筛选、搜索、分页和授权下载。只读详情从已保存的导出文件展示概览、启用或候选规则、分组依据、逐图观察分页和有界文件预览；后续修改档案不会改变历史内容。文件校验不代表远程图片像素已校验，也不将模型建议变为人工确认。

数据集读取直接定位所选任务或数据包。Host 按当前清单摘要复用已校验的不可变文件投影，每页图片仍重新检查访问权限。已完成的详情分页可在同一所有者范围内跨角色切换和关闭重开复用；手动刷新、数据包元数据变化、过期或范围切换会失效。`limits.datasetCacheTtlMs` 默认 60000，`datasetCacheMaxViews` 默认 8，`datasetCacheMaxBytes` 默认 16777216，任一设为 0 可关闭复用。Host 按保留的解析内容和有界预览计费，Client 按保留分页的 JSON 大小计费，复用不延长首页原有的资源授权期限。逐图观察和已保存找图批次的图片网格只挂载可见区域，保留全部已加载数据、角色筛选、大图导航和触底分页。数据集 HEAD 请求完成授权后直接返回，不组装响应正文。 图库列表的可丢弃元数据缓存使用小索引和独立分页，只写入新增页，不重复改写历史页；中断或配额不足不会暴露未提交分页。旧版派生缓存会重新读取，图库原数据不受影响。

引用任务在单次、受修订检查的批次内复用已授权的不可变素材库前缀，每张图片仍独立原子提交到草稿。并发修改草稿、归档或前缀记录消失会停止追加；私有前缀和反馈会再次检查。关闭、中断、取消与重试保留已提交前缀及操作回执。已完成找图任务的选择器只投影图片身份、分类、尺寸和授权预览，保留准确的筛选总数、稳定排序和绑定范围的游标。

“数据包内容”使用紧凑文件列表和独立滚动的原生 CodeBlock 预览，窄弹窗改用已有文件选择器。JSON、JSONL 和 Markdown 按文件名复用项目代码高亮、源行号、换行切换和“复制预览”控件。预览原文保持不变，截断内容继续标明，完整数据包仍可下载。文件大小与校验状态常显，校验值按需展开；详情底部只保留下载和关闭操作。

分析状态统一在画像侧栏显示，使用原生标签、已确认图片数量和进度条。第二版素材固定同一张生成的照片卡片，连续扫描并依次显示色板；透明 WebP 每 2.4 秒循环，减少动态效果、暂停及停止过程中使用静态封面。编码脚本为 `scripts/build-analysis-animation.mjs`。侧栏收起和窄屏入口保留简短状态标签；启动分析后留在工作区，完整过程可按需打开。

分析弹窗分为模型对话、批次导航和最右侧分析信息三栏，每个保留的批次尝试分别显示状态及图片数量。点击批次定位对应尝试，不启动模型请求。变高虚拟列表仅挂载阅读区附近内容，同时保留批次跳转、历史阅读位置及最新输出跟随。检查点即使在上次读取收尾时到达，也会补读已保存的请求用量；当前请求未报告时继续标明上次已报告来源。窄屏保留紧凑批次菜单和上下文摘要。

分析任务摘要只缓存少量解析后的字段，受 `limits.analysisTaskCacheMaxEntries`（默认 128）和 `analysisTaskCacheMaxBytes`（默认 1048576）限制，任一为 0 可关闭缓存。每次读取仍检查当前记录校验和、所有者、素材集名称和实时阶段，并重新判断截止时间。检查点读取使用绑定所有者、任务及固定引用的观察游标，只追加新的不可变观察并保留静态图片名称；前缀变化会替换已保留的内容。请求元数据始终刷新，包括同一请求 ID 后续保存的用量和上下文。

Host 合并同一公开预览地址的进行中请求，并按 `source.unsplash.previewConcurrency` 对不同地址实行先进先出的并发限制，覆盖图库原生图片和大图预览。各读者保留独立授权和取消；最后一位读者取消后中止来源请求，来源实际结束后才释放运行槽位。Host 响应仍由浏览器缓存；客户端缩略图缓存见结果评审部分。找图任务的网络预算独立计算。

人工任务控制使用已鉴权的数据路由。`run-control` 传入 `waitForCompletion: false` 时，先返回已持久化的暂停中或取消中状态；省略参数仍等待清理完成。取消可覆盖尚未完成的暂停，迟到的暂停不能撤销取消。排队分析可在派发前暂停，再显式继续。客户端按任务和命令区分请求，保留已加载图片与结果，并忽略旧回执和旧轮询；控制期间其他页面操作仍可用。

### 复核结果和纠正

搜索结果分别保留原图与成图审核。偏好分不能抵消 required 失败；unknown 和技术失败不会成为审美拒绝标签。只有不重复的最终合格图片计入目标，不足结果保留真实停止原因。缺少足够原图像素的预览不能满足成图像素要求。

人工裁图有两次确认：先完成调整，保存并复核真实派生图；再明确允许作为学习样例。关闭预览、下载、接受一批结果或取消拖动都不会产生理想裁图标签。人工保留的合法但带视觉警告图片，与自动合格结果分开标识。系统不通过放大、拉伸或扩图满足不可能的裁剪要求。

反馈默认只作用于当前任务。明确选择纳入当前风格 candidate 后，纠正才可能用于下一草稿；题材不符、本次不需要和 unknown 与风格拒绝分别记录。改判追加新反馈并移动唯一有效头。旧 release 和导出保留原记录。Agent 建议不会变成人工身份确认。

复核队列字段标记不确定判断、技术失败、人工与模型分歧，以及等待人工判读的新来源组。`limits.reviewSampleRate` 还会根据图片摘要可重复地抽取普通通过或拒绝图片；每个任务在启动时固定抽检比例。队列归属不修改反馈或 release，新来源组也不代表已识别出新的语义类别。

新搜索排除同一素材集可读取历史中的已返回原图；只有任务要求、固定风格和实际复核配方一致时，才复用已确认的最终不匹配结果。更改规则、任务或复核配置后仍可重新检查，技术失败和不确定结果不会成为历史不匹配排除项。Unsplash 对相同关键词可能返回相同的相关度排序；本地按稳定照片 ID 在下载和复核前过滤，并沿保存的分页继续取新候选。

预览找图按 `limits.maxConcurrentRequests` 和剩余目标数量受控并行复核，逐图保存结果，按来源顺序选图；已接纳批次全部结束后才推进分页检查点，暂停保留已完成复核。原生请求先复用参考附件的准备，再并行等待模型输出，避免冷参考图重复下载；模型选择及推理默认值保持原样。复核字段、覆盖范围或返回证据身份不符时拒绝采纳，保存私有字段诊断，只在持久化的 `maxRetryAttempts`、调用次数及字节预算内重试。既有失败记录不会自动重新提交。

找图反馈区分原图不可用、下载或导入失败、视觉检查技术失败、不确定判断及视觉不通过。已导入图片在复核期间即可显示，只有保存的选择计入最终入选，筛选保留全任务计数。会话的“对话”标签页显示一张任务卡，位于工具过程折叠区之外；其他会话视图隐藏卡片，同时保留筛选与已加载分页。卡片不再显示次要阶段、数据实时性及候选列表说明。卡片与原生任务胶囊在同一容器内纵向排列：会话区域达到 920px 时位于正文右侧，较窄时隐藏且不预留空间；恢复宽度后重新显示，并保留筛选、已加载分页及展开状态。任务栏默认宽度为 300px，可在空间允许时调整至 280–640px；并排显示时为正文保留 520px 及其内边距。多任务在卡片内切换且不合并数量。Session 授权读取已有找图与裁图，不依赖工具组件是否挂载；仅所选 Run 读取预览。关闭会话停止观察，终态 Run 停止轮询；查看期间的轻量目录读取可发现新任务或外部恢复。重连保留已确认数量并忽略过期响应。输出目录只来自已提交的交付回执，零张合格结果不创建目录。 后台任务输出行展示生产者提供的阶段及数量；进度只在检查点成功保存后发布，原始输出与调用检查继续保留。

任务卡通过原生 Session 插槽判断外层会话当前是否为“对话”视图；嵌入的对话预览不会改变外层显示状态，图片检索 Run 创建前也采用同一判断。

列表缩略图在接近可视区域时进入共享、可取消的客户端队列。`source.unsplash.previewConcurrency` 默认 2，可设为 1 到 4 的整数，独立于任务预算。已显示图片离屏后保留预览；组件卸载时释放其请求和 Blob URL。共享内存 Blob 缓存复用授权缩略图，并合并相同的在途请求。`source.unsplash.previewCache` 配置 `ttlMs`（300000）、`maxEntries`（96）和 `maxBytes`（67108864），按最近使用情况淘汰。缓存键保留完整授权地址；用户作用域变化或插件卸载时清理，不把图片存入浏览器持久存储。画布只渲染可见节点，显式刷新仅重试失败图片，保留成功预览。Unsplash 小图链接与常规评审、完整预览链接分别保存；旧描述符读取缩略图时限制尺寸，不修改已保存的身份信息。每次授权通过后，相同公开媒体 URL 的 Host 在途请求也可合并。

工作台导航只读取风格摘要，不携带逐图观察；打开风格档案时再读取当前素材集的完整依据，包括反例参考。后续摘要刷新仅在分析身份和进度不变时保留已加载的依据。风格列表先校验游标，再构建当前页的素材集详情；画像有效性检查只读取已授权的当前反馈，不再重建其他工作台数据。对话任务卡片的“加载更多”只追加下一页，常规刷新仍重新核对已加载窗口；Session 授权变化或游标失效时执行有次数限制的重读。

工作台入口注册后不会预读数据，最后一个工作台关闭时停止其元数据轮询，重新打开时核对当前状态。可见找图目录继续观察未完成或回执不确定的任务，并响应工作区修订变化；空目录和全部结束的目录不持续轮询。有效批次缓存等待剩余刷新间隔，运行中进度、手动刷新和失败读取仍及时核对，不延长图片授权。参考图筛选使用成员索引，非活跃参考面板释放图片卡片，关闭的风格档案保留保存队列而不遍历图片依据。已加载参考图复用现有虚拟列表库，仅渲染视口附近的行，列数和卡片高度取自实际 CSS 布局；总数、灯箱导航和分页触发位置仍对应完整图片序列，切换标签保留搜索、布局和有效滚动位置。不同预览组件共享所属滚动容器的持续可见性观察器，最后一张图片卸载时释放。

任务详情内部的工具栏分为标题与生命周期操作、主要统计及次要信息、结果筛选三层。最终入选保留目标数量；零值技术统计位于“更多统计”，非零异常继续显示。交付路径和诊断按需展开，全部结果、最终入选、待复核及当前分类始终可用，其余空分类不增加按钮。图片结果在常规宽度下面向单张及多张统一使用 200–224px 小卡片，16:10 预览框完整容纳原图，状态、尺寸和匹配情况分组，评审摘要保留两行，查看详情及裁剪操作继续可用，完整说明仍在原生详情弹窗中查看。结果预览在加载期间保留固定图片区，完整预览失败时使用已授权的缩略图，并明确标注与提供完整预览重试；两种图片均失败时显示错误并允许重新请求。结果弹窗使用接近不透明的底色与轻微背景模糊。

任务卡分为标题与状态、单次需求说明、可点击统计及图片结果。四个统计筛选使用两列等大卡片，数字在上、标签在下。仅当前筛选使用主题色边框和底色，生成的照片叠片插画限定在右下角；长标题省略并可悬停查看全文。“添加引用”还可选择当前素材集已完成的找图任务，弹窗使用大尺寸毛玻璃工作区，桌面端在图片网格旁显示任务导航，窄屏改用任务选择器；全屏和还原保留已加载分页与勾选，图片区独立滚动，筛选栏和底部操作保持可见。原图按实际比例完整容纳在 4:3 预览框中，不再按原图像素尺寸裁切显示；仅看已选、清空选择和重试失败图片均不重新读取任务元数据。候选分页包含未通过图片，并按明确选择的正例或反例角色添加。Host 校验原会话访问权与任务图片归属，保留来源及导出权限后加入素材库，并逐张保存回执供幂等重试；远程引用复用描述符，不下载像素，也不修改原找图任务。已有参考会跳过，若角色相反则需在参考列表中调整。

引用弹窗支持跨已完成任务选择，“仅看已选”集中显示所有勾选，每个任务显示自己的已选数量。左键点击图片切换勾选，右键或 Shift+F10 查看大图；全选会跨页读取当前筛选列表，达到总数量上限后停止，并保留其他任务的勾选。底部分别显示已选图片、总上限、任务数量及清空操作。切换任务或分类时，在 `limits.batchCacheTtlMs` 内复用已加载分页并恢复滚动位置，缓存数量受 `limits.batchCacheMaxViews` 限制，且不超过原资源授权的有效期。缓存与勾选仅保存在内存中，关闭弹窗、切换素材集或会话后结束。图片列表接近底部时自动加载下一页，同一游标在请求期间只读取一次；分页失败保留现有图片，等待手动重试。跨任务添加固定本次选择，核对所有来源后持久化受理到现有后台引用队列；受理成功即关闭弹窗，在素材集页面显示逐张已提交进度、停止操作及最终结果，关闭或刷新浏览器不取消已受理任务。中断后保留已保存数量，仅按原角色补充缺失参考；取消会结束任务并保留已提交图片。受理结果未知时沿用原操作编号重试，不重复创建任务。

点击匹配或待复核可查看对应分类；检索候选和去重数量均打开已保存的去重候选，统计值继续保留各自的检索含义。列表首屏读取四张，可按需加载后续图片，不再限制只显示四张；切换分类取消旧请求，刷新保留已请求的完整窗口，单个接口分页不超过 100 张。状态和图片判断使用原生 Tag 色板。拖动左边缘或使用键盘调整宽度时与正文协调分配空间，双击恢复 300px；响应式重排保留当前宽度、键盘焦点、分类及已加载图片。展开结果填满任务清单下方的剩余高度，结果区内部滚动，操作保持可见；高度变化使用主题动画 token，减少动态效果时取消过渡。

“找图与裁剪”默认展示当前分组的全部预览匹配结果，按原始找图或裁剪 Run 分批排列。每批保留时间、状态、批次标识和匹配数量，可筛选单个批次；批次及批内图片分别分页。已认证所有者可通过独立只读入口汇总同一分组的不同会话结果，图片仍使用原 Session 授权；其他分组和 Agent 工具不能借此跨越授权范围。会话暂不可读时保留批次并明确提示，不伪装成零结果。“任务详情”先切换到明确的目标页面，再异步读取原 Run 的控制与诊断；返回时恢复原素材集、批次筛选和已缓存结果。分类按钮立即响应，按会话、任务和分类分别复用缓存并取消旧请求；重新打开同一会话复用当前授权，不再等待额外全量快照。切换分组会取消旧读取，迟到响应不能覆盖当前结果。读取不启动任务，也不调用图库或视觉模型。

批次列表首次读取使用现有低对比卡片骨架屏，未知数量显示占位。重新打开分组或切换批次筛选时，从仅驻留内存的 LRU 缓存恢复已加载分页，并立即后台刷新；刷新失败保留已有卡片。`limits.batchCacheTtlMs` 默认 60000，`limits.batchCacheMaxViews` 默认 8，任一设为 0 可关闭复用。缓存不超过原 Session 资源授权的有效期。手动刷新和删除批次会清理当前分组的全部筛选缓存；所有者范围变化、连接重置与插件卸载清空全部缓存。取消和失败读取不延长缓存期限。

批次和详情只构建当前页已授权图片的元数据与预览链接，完整计数和排序保持不变。远程卡片复用现有缩略图入口并延迟加载、异步解码；较大预览按点击打开。读取元数据不会请求图片字节或下载原图。同次投影复用 assessment、selection、crop 与 feedback 索引，避免逐图重复扫描。分析详情、原始输入和订阅初始化共享单次同步验证快照，不跨请求或 SSE 生命周期。流式文本展示复用执行者最后一次提交成功的任务副本，不逐 token 读取存储；公开读取和持久更新仍执行原有校验。进入和退出会话详情时保留所有者视图缓存，授权范围重置时清理；分析进度变化时保留已有详情并后台验证，读取失败不延长缓存期限。

续接检查仅在需要核对请求结果时读取所属 Run 保存的请求 ID，运行中和已完成列表不复制模型请求正文。启动记录与交付列表在投影前按清单前缀筛选。原生壁纸回执明确区分继承资格和当前修改，并有界返回需处理图片；尚无成品的失败规划也保留来源与失败检查。

新找图任务固定精确参考图身份和同素材集此前已入选的图片。Unsplash 使用跨账号、跨尺寸链接不变的照片 ID；保存本地像素的图片还比较原图和规范化图片摘要。已知参考图和已入选图片在视觉评审前跳过，分别记录排除数量；已经发生的检索和下载仍消耗原预算。人工启动可包含可读历史会话，自由 Agent 任务仅使用其有权读取的历史。每个新 Run 在受理时重新读取历史，包含会话或任务准备后保存的已确认不匹配；检查过的任务内容未变化时无需重新准备。暂停和续传沿用原排除清单，未保存策略的旧任务保留原行为，不改写历史匹配结果。数据集提供参考观察和规则，不是训练后的模型权重；外观相似的不同图片仍需视觉复核。

### 限定范围和恢复任务

`storage-commit-failed` 诊断保留依赖记录写入或清单发布的失败阶段、安全错误码及尝试次数。临时文件替换错误使用配置的有限重试策略；清单未确认时不发布依赖结果。在失败的找图节点或任务记录点击“继续”，沿用同一 Run 的候选、分页位置、预算及请求回执；使用相同操作 ID 再次启动只返回原回执。存储状态未知时需先重新打开 Host，模型结果未知的请求仍须检查。下游交接失败只重试交接，不重跑已完成的找图。

并发找图保存会先冻结每次检查点，再连同其依赖记录排队提交。任一次保存失败后，该轮后续保存停止发布，避免写入无效图片引用。续跑读取最后确认的检查点；图片或素材记录未提交的引用重新进入待处理队列，已有文件和已提交记录保持不变。

图库与找图结果的引用任务，在自动分析受理记录保存成功前保持“保存中”的运行状态。所选图片全部导入后，点击“继续”只补跑这次交接，不重复导入图片。分析复用已提交观察，并由既有执行器生成数据集；仅导入的任务保留原有行为。

分析预检只读取相关来源 Run 检查点登记的请求，仍要求请求已经提交且归属于该 Run。逐图输入比较只建立一次参考与反馈索引，复用校验也只解析一次同一来源 Run。仓库同步读取作用域按记录类型索引 ID，并对每个依赖校验一次；退出后即丢弃索引和信任结果。任务轮询复用本次读取中已校验的固定输入和数据，每次仍读取实时过程状态并检查原截止时间。

Client 创建的 profile 任务和 Agent 创建的 Session 任务分别拥有归属。授权的 owner 操作需显式打开所属 Session 通道，才能读取其任务、图片或导出。将 Session 结果保存到 profile 样例库会创建独立关联，原 Session 归属保持不变。

离开页面后任务继续执行。主动取消保留已保存结果，不会自动恢复。系统中断的分析保留原 runId、配置、额度和检查点，已提交响应直接重放，不重复请求模型。分析续跑保留已有的未知请求策略，包括预留额度及可能再次计费的限制。新建的后台找图任务在中断后沿用冻结查询词、候选及分页检查点；历史会话任务通过明确的“继续”恢复，不重新提交已受理提示。找图遇到结果未知的模型请求时停止并提示检查，不自动重复派发。显式暂停在重启后保留，继续执行既有任务及供应商校验。

上下文面板在新分析请求尚未报告用量时保留上次请求的读数并标明来源，用量和容量始终来自同一次请求。首次分析预检立即显示不透明的原生弹窗与骨架反馈，提交前可取消；服务接受启动后不再等待后台列表轮询。暂停分析会等待当前已受理请求完成并提交检查点，然后停止后续请求；继续分析沿用同一 Run 和已提交检查点，不重复已完成批次，取消仍可中断在途调用。显式暂停在重启后保留，暂停和继续均不重置原截止时间与额度；进程丢失前尚无已提交回执的外部请求，其计费结果仍属未知。

分析弹窗分别提供模型对话、运行日志、请求记录和失败诊断。请求记录展示保存结果、模型身份和安全错误字段；后续尝试成功后，早先失败仍保留并标为历史记录。旧记录没有保存的原因显示为不可用。“继续分析”也支持明确可重试的失败任务，但原截止时间与模型调用额度必须仍有效；同一 Run 只重试未完成步骤，保留已保存观察和全部请求回执，受理后清除当前失败状态。显式继续失败任务会为待处理步骤开启有界重试窗口，重启或自动恢复不会补充该窗口。原任务总额度和截止时间不重置，已完成或已取消任务不能原地续跑。

分析弹窗的标题与素材集名称同排显示。已结束的图片引用状态移到画像侧栏的分析操作上方，正在引用的进度仍保留在图片列表旁。画像就绪后保留“重新分析”，点击后进入现有范围确认，默认选中完整重分析，确认前不提交任务。“继续分析”优先续接可恢复的 Run；上次任务已结束时，为当前已引入图片准备增量分析，可复用已保存观察，不会重新启动已取消的引用任务。

分析期间在素材集选择器旁显示当前阶段和已保存图片数量，点击可打开现有分析过程弹窗，同时隐藏侧栏里已结束的引用提示。原生图片附件失败保留具体错误码；附件写入失败只有在模型流启动前才可使用原任务额度重试。旧的通用流程失败明确提示未保存原始原因，不因此改成可重试。保留的上下文用量不再暗示失败请求仍在运行。

可恢复的网络与输出格式错误只重试当前未完成请求，次数由 `limits.maxRetryAttempts` 限制，设为 0 可关闭。`limits.retryDelayMs` 默认 1000，按次数线性延长等待，并响应暂停、取消与卸载。已保存的失败回执保证服务重启不会重置重试余量，运行日志显示重试阶段。观察缺失不确定性字段时保留为待确认；错误类型、未知图片证据及不完整的图片覆盖仍被拒绝，并保存字段诊断。再次发起分析时，若参考图、反馈、草稿规则与模型参数一致，会自动复用失败或超时任务中进度最多的部分检查点；取消的任务不参与复用。兼容 HTTP 任务的总时限覆盖全部批次；原生模型任务使用服务配置章节说明的计时策略。分析缩略图使用授权的小图地址，原生灯箱保留原预览地址；加载失败显示固定占位，避免破图文字撑开布局。

参考图提示版本 `visual-curator-reference-v2` 只发送当前批次相关的人工判断，字段投影为反馈身份、主体、判断与作用范围。最终风格归纳仍接收全部反馈，冻结任务保留完整原始记录。输出 Schema 排在动态输入前，请求身份放在最后，在保留图片证据的同时提高公共前缀的可复用性。中断或格式错误的流帧保留诊断并使用同一有限重试策略；明确的鉴权失败和无效 UTF-8 仍不重试。

### 划分、对比和导出

确认 family 成员后，再分配 learning、development 或 holdout。原图、精确重复及其派生图共享 family。尚未确认的近似分组不能证明数据独立；已参与分析或校准的 family 不能成为独立 holdout。holdout 不进入归纳和训练导出；查看其错误并据此修改规则时，需要新建 manifest，将相关 family 移出 holdout。

选择相关来源组并明确确认合并后，重新打开划分表单。合并保存不可变 family 别名和成员确认，原 asset 记录保持不变。旧划分若因合并出现跨集合冲突便不能继续使用，需要创建新划分并将合并组保留在同一集合。

对比保存固定 release/candidate、图片、用途、反馈头、原始计数及分母。召回分母保留全部人工正例，包括待复核、技术失败和未处理状态；精确率统计有人工标签的合格结果。分母为零时显示 unavailable。预算耗尽后仍保存含全部固定输入及明确停止结果的部分报告。仅做图片对比不会生成裁图，也不能证明裁图破坏指标；缺少相应独立裁图监督时，这些指标保持 unavailable。对比不会改变默认 release。

导出支持风格包、classification/preference/crop JSONL 和 Skill Markdown。下载是版本化 JSON 封装：`files` 保存文本内容及 checksum；只有经授权的 with-bytes 导出才在 `resources` 中保存 Base64 媒体字节。文件 checksum 是精确 UTF-8 内容的 SHA-256；业务记录摘要另用带版本的规范 JSON。默认仅导出引用。附带图片字节必须有已记录授权并通过完整性检查；缺失、损坏或未授权字节会使导出失败，不生成被标成完整的缺损包。

Client 的 `reference-analyze` 可选 `buildDataset: true` 启用跨图归纳；省略时保留原逐批分析行为。`export-start` 的 `kind: "style"`、`purpose: "reference"` 可选 `analysisRunId`，要求该任务完整完成，并且分析时的图片、维度意图和人工判断与所选 release 一致。原记录枚举与 schemaVersion 保持不变；版本化档案保存在已有 Run 的 JSON checkpoint 中，原风格导出和人工监督数据格式保持可读。机器观察不会混入 classification/preference/crop 人工监督行。

training 导出只含 learning family，并保留请求时固定的合格人工反馈 ID。后续改判不会重写已有快照。偏好平局和两者均不合适保留原值。生成的 Skill 指明 release 与所需资源；图片不可用时要求报告缺失，且只产生可下载产物。它不修改 Home 指令、不在 Session 中启用、不训练模型，也不包含模型权重。

<a id="model-experience"></a>
## 模型体验

### 准备和复核任务

“按此画像找图”默认使用“仅预览链接”，自动复用当前素材集、当前模型画像对应的完整数据集。缺少完整包时，点击开始会先在原生工作区创建会话，再后台生成可复用的完整包并继续找图。同一训练集已保存的完整版本可跨会话自由选择，并在创建会话前核验；选择历史数据集后固定其中的参考图、规则和提示词，不受当前草稿编辑影响。仅观察包仍不能作为找图标准。弹窗会解释缺少完整包的原因，并显示原生工作区、预填需求和数量；保留原图和指定尺寸仍可显式选择。开始时固定画像、启用规则、备选风格组、来源和预算。准备阶段不调用付费模型，也不改变全局会话模型选择。

新任务默认附带当前全部反例参考，以及同素材集中跨会话可复用的已完成反例包来源。按不可变图片版本去重，排除已移除、已改为正例的历史参考。任务受理时固定当前保存的观察与判断，后续导出或编辑不改变重试内容。会话附件保留主数据包文件和校验和，另附 negativeReferences；Agent 按需读取，将其作为补充依据，不作为正例检索目标或人工确认的训练标签。已有受理任务沿用原始输入和附件。自动生成可复用完整包须由已受理的人工启动任务授权；重试复用同一会话、消息和数据包标识。

预览找图目前要求 Unsplash 来源。Agent 按当前启用规则和备选组生成简短的英文主体优先检索词，按需读取数据集证据；首轮查询为高产方向预留部分页数。检索根据已保存的评审和入选反馈选择候选，弱主体结果及全重复页面不能冒充高产，未探索方向可优先于低产页面。稳定来源身份和逐查询游标支持续传；原图检查点将非活动查询的续页位置单独保存，活动查询继续由原字段拥有。旧检查点缺少这些续页位置时，仍表示前面的查询已完成。搜索页和来源详情调用继续消耗同一份持久化预算，暂停或重启不会重置。复核使用经校验的常规公开预览 URL，包含来源和终审规则，不生成原图或裁剪文件；预览匹配不代表原图像素核验或像素相似度去重。原图和指定尺寸输出保留既有最终像素检查及工作区交付回执。

新模型画像找图及裁剪任务固定使用 visual-curator-rules-v3 评审配方。V3 为每条请求的主体规则返回一项 subjectFocus，并引用候选图自身作为证据；明确要求主角时，结构化证据若表明车辆是陪衬或缺失，即使其他维度满足加权比例也不能通过，不确定则保留待复核。只要求出现或排除某内容的规则不会被额外强加主角要求；明确以主体细节为焦点的特写仍可通过，不擅自添加面积比例或完整车身要求。同一备选组必须同时满足主体与风格检查。原始模型回答保留，评审记录会修正矛盾判定；缺少证据或只引用其他图片属于无效输出。规则强弱等级及已保存画像保持不变；冻结的 v1/v2 任务继续使用原提示词协议和参考采样。

V3 参考采样优先覆盖必需及共享视觉规则的证据和启用的备选组，去除重复图片身份与摘要，在冻结图片数及字节上限内为相关反例预留位置。停用组独占的证据不会挤占当前规则；有效人工判断决定模型看到的正例、反例或未定角色，原导入角色另行保留。采样顺序可复现，不新增模型调用，读取后仍检查实际字节上限。

新找图任务默认在同一 Run 中跨页积累 50 个唯一候选，再将真实缩略图分成小批初筛。`searchScreening.candidatePoolSize` 可选 50 或 100，`batchSize` 默认 6（1–16），`maxScreeningImageEdge` 默认 384（128–1024）；原生请求同时遵守模型图片数量上限。模型设置中的分析参数可保存这些值。来源、页数、字节、视觉调用和并发继续共享原预算，达到来源或预算上限时使用实际取得的候选。首轮筛掉每个启用备选组都明显不符的图片，不确定结果进入完整复核；只有完整复核才能入选。初筛故障经有限重试后转逐图复核，不能计为风格拒绝。原图在初筛后下载，暂停或重启复用已提交的批次及复核结果；旧任务没有此策略时继续原流程。任务卡分别显示初筛、初筛排除和完整复核数量。接口测量与限制见[搜图性能研究](docs/search-performance-20261104.md)（[中文](docs/search-performance-20261104.zh.md)）。

同素材集的新任务在下载前排除当前参考图、此前入选图、源审或终审明确拒绝的原图及已初筛排除的来源身份；修改任务措辞或切换模型不重置这种已知图片去重。Unsplash 按照片 ID 跨账号识别，其他来源保持账号范围；只有已验证像素使用字节摘要，远程描述摘要不代表图片内容相同。历史读取仍须授权，技术失败和不确定结果不会永久排除，其他素材集不受影响。

需要停用初筛时，在分析参数中关闭批量初筛，或将 `searchScreening.enabled` 设为 `false`，新任务恢复逐图完整复核；已受理任务始终沿用其固定策略和检查点。候选大多已匹配或数量很少时，初筛不保证更快。

仅有有效反例证据的规则可以保存和启用；明确的 required 排除在共享或所属备选组中必须满足，不能用其他偏好抵消，preferred 仍是偏好。反例角色不使图片中的所有特征自动成为禁项。已生成的数据集保持固定内容；旧版本遗漏反例规则时，选择“全部角色 → 复用并整理”生成新画像和完整数据集，再用新版本找图。兼容观察直接复用，实际待处理量在启动前显示；只重新导出旧画像不会补回规则，用户明确关闭的规则不会自动开启。

关闭弹窗或一轮对话自然结束时，已受理的后台 Run 继续运行。用户主动停止会话会取消该会话的视觉 Run、正在受理的任务及尚未完成的原生找图启动，不影响其他会话和工作台独立启动的任务。取消后的结果和通知保留，但不会自动唤醒空闲会话。会话卡片的“停止任务”会停止所属启动及关联视觉 Run；没有启动记录时取消选中的 Run。状态按已保存的修订号更新，旧的运行中响应不能覆盖已确认终态。保留此前已确认结果，会话受理与检索、匹配数量分开显示。过期私有参考在创建会话前失败；文件缺失、目录变化和未知回执保留明确恢复状态。

工作台启动摘要位于顶部素材集选择器旁，不单独占用内容行。紧凑入口显示任务状态和真实数量，原生菜单展开完整状态、交付目录和现有操作。尚未创建 Run 时显示请求的目标数量，不展示合格计数。已停止任务使用中性状态，结果不足和失败分别标记。

启动弹窗上方集中选择数据集和工作区，下方填写找图要求；底部操作固定，表单内部滚动。生成日期只在数据集选择器中显示一次。启动状态只保留一处提示，不重复显示失败卡片；错误详情保留安全错误说明、失败步骤与建议操作。提交前检查 Host 是否支持数据集选择、自动准备完整包及反例参考。旧版 Host 会阻止提交并提示重启应用服务、刷新页面，同时保留所选数据集和回执未知任务的操作标识。

原生会话创建确认后，启动弹窗立即关闭并跳转到该会话，不等待附件和模型请求准备完成。任务卡展示已保存的找图要求与目标数量，说明及刷新收进“任务详情”，保留停止入口；准备画像附件和提交会话任务分别显示提示。启动受理后显示“检索准备中”，并明确说明会话已启动、图片检索尚未开始；实际图片检索 Run 创建后，同一卡片原位切换为真实进度，再展示完成或失败状态。准备阶段不虚构图片进度，也不占据输入框区域。重试未知回执时也会识别正在运行的回合已领取的请求，避免准备期间重复入队。

“最终入选”只包含已保存的 selection，预览任务改称“预览匹配”。任务顶部在分类筛选上方集中显示标题、状态、目标进度和操作。完整需求、次要数量、结束原因、交付及诊断归入原生“任务详情”菜单；重复结构化候选 ID 和错误码的旧警告会归并，其他警告保留。“待复核”和“全部候选”分别保留不确定图片、通过源审的原图、淘汰裁剪及技术失败。预览卡片可打开公开预览，不提供裁剪操作。会话卡片的“打开任务”取得原 Session 授权；令牌仅存于内存，“返回素材库”清除当前范围。

新模型画像任务从当前启用规则编译执行说明，调整后的画像不自动沿用旧检索词。终审使用固定的 rule-coverage-v2 recipe。共享偏好及任一适用风格组须达到 limits.minStyleMatchRatio（默认 0.75）。即使所有未知规则满足仍无法达标时，该组判为不匹配；否则未解决证据保留待复核。该值是规则满足比例，不是经校准的模型置信度。历史任务与人工发布版本沿用原 recipe。Agent 准备读取可发现用途、来源和预算，不能创建人工拥有的用途。

找图技能和原生启动消息明确由 Visual Curator 负责流程，使用 visual_task_prepare 检查准备条件；AFP 工具属于独立图片服务。已固定的启动任务直接使用给定画像、启用规则和附件，不再遍历全部风格或替换固定版本；消息提供素材集 ID，便于按需定向读取依据。

可选工具条目提供有界风格读取、搜图/裁图启动、任务读取、Agent 建议及导出启动/读取，不暴露人工确认、发布、默认切换或分组确认命令。长操作返回任务句柄；启动确认不代表图片合格。工具结果包含安全 ID 和经授权资源引用；辅助视觉请求在插件所属的任务请求日志中保存实际图片顺序、摘要、提示词、模型/版本声明及校验后输出。Session 工具结果关联该任务；派发前仍核对 Session 归属，不写入实验性 Session 记录。

启用工具时，声明会增加模型工具 schema 上下文。本 bundle 不向每次请求注入风格，也不修改 Home 指令。每次视觉调用消耗自身文本和图片预算。原生收据保留供应商返回的 token 用量，缺失的缓存字段继续保持不可用；精确账单和网关整体缓存统计仍由供应商负责。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

仅支持已配置的图片来源、支持图片的原生 LLM 路由和兼容 HTTP 备用接口。背景扩图使用已配置的原生 Codex 生图路由，不能获取付费原图或补造缺失的主体结构。不提供任意站点爬取、精确分割、Embedding/向量检索、模型权重训练或远端收藏写入。系统只审核已召回候选，不能声明完整图库召回。原图质量、许可、导出授权和审美适用性需要用户自行核验。

keyless fixture 验证流程控制和精确图片几何，不验证真实来源/模型部署、供应商账单、广泛视觉质量或用户参考图适用性。只有提供真实端点、响应映射、凭据引用、模型能力和授权样例后，才能验证相应属性。仅做图片评估时，尚无支持的裁图指标保持 unavailable。profile 锁只协调同一台机器的进程，不支持独立主机共享存储的锁协调。

## 直接处理原图

**直接裁剪**页面接受本地原图与已登录收藏夹图片，无需训练集，沿用固定安全区模板，独立复审原图外观一致性，保留版本并导出合格干净 PNG。“服务器图片”入口通过提供的 OperateImage 接口导入待处理原图，仅回传独立复审通过的干净成品；连接、图片绑定及上传结果待核对的处理见[对接规范](docs/direct-crop-server-api.md)。批次以表格呈现，支持勾选、删除所选及包含未加载分页的全部删除；确认时固定范围，未停止任务保留，部分完成会明确报告。原图、成品、规划版本与不可变任务记录仍可读取。新列表行由 Host 提供 `removable`，统一根据当前快照及执行中任务计算是否可移除；已被替代的历史暂停快照不会阻止移除已停止批次，也不会为通过删除校验而改写历史记录。

原图节点与图片缩略图共用 Host 返回的真实下载计数；响应提供有效总大小时显示百分比，否则仅显示已接收容量。接收完成后仍须校验并保存原图。实时计数只保留在任务运行期，沿用画布读取，不为每张缩略图增加轮询，也不随每个分块写入任务检查点。重试与重启保留已保存原图，获取失败后流程节点仍可见。紧凑图片选择栏提供上一张、下一张与原图下载概览；显式重试或重查授权建立仅处理该图片的续接任务，保留其他已保存原图和前序记录。Unsplash+ 标记表示内容类别，实际访问权由带当前登录身份的下载端点确认，不执行购买或订阅设置变更。

新壁纸任务冻结可选的 `wallpaper.decision` 策略，默认 `enabled: true`、每图 `maxRoundsPerImage: 2` 和额外局部 `maxDetailRequests: 1`。原图证据或可恢复步骤仍有未决事项时，“处理决策”节点使用已配置的视觉模型选择可执行动作，Host 在执行前核对原图、疑点覆盖、几何、剩余限额和已保存回执。决策不能直接判定成品合格或降低独立复审要求；未解决的图片保留可见异常，其他图片继续。规划决策需要局部证据时，流程在剩余局部复核预算内自动检查已保存的原图。手动和自动复核都在“局部放大复核”节点显示进度和结果。可选的 `reasoningEffort` 只作用于该次请求，必须受所选路由支持。旧任务保留冻结策略，主动点击“处理决策”才创建单图续接任务。已保存原图、成品、回执及跨版本决策历史均保留，相同证据和动作不能循环创建生图请求。任务暂停或不完整结束后，中断的决策显示“继续决策”，沿用原轮次与输入并优先复用完整响应。单图续接时，其他图片的待执行状态仅作为保留进度，继承的运行标记不会显示为活跃请求。后台已结束但仍有未完成图片的批次支持显式取消；Host 保存取消状态并关闭自动恢复，保留全部检查点、图片回执及合格结果。已全部合格或已有更新续接的任务会拒绝取消。取消或移除后，已保存图片仍可查看及导出，未完成节点显示已取消并关闭执行入口；历史旧快照不会通过手动恢复或重启再次运行。
