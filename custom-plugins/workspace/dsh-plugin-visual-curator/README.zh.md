# dsh-plugin-visual-curator

[English](README.md) | 中文

## 摘要

从选定参考维度建立视觉风格，发布不可变版本，并用同一固定标准搜图和复核真实裁后图片。人工纠正可追溯，只有显式发布才改变未来标准。DSH 随应用提供这个独立 bundle，新建 Web 和 Desktop profile 默认启用其八个 Agent 工具，已有 profile 保留原选择。未配置搜索或视觉接口时仍可读取本地记录，需要这些接口的操作会明确失败，直到配置完整。

## 使用本包

### 启用 profile 层

已有 profile 在插件管理器启用“视觉策展”，即可使用随应用提供的版本，无需在 profile 内另装一份。更新应用安装依赖后，已运行的 Host 需要重启。未随应用携带本 bundle 的安装环境，也可把审核过的包产物安装到目标 profile。[补丁](cordis.patch.yml) 挂载业务 Provider、六项技能、三组 Agent 工具与三个页面入口，每项均可独立开关。技能通过原生技能目录注册，不向 Home 写入文件。Host 需要 profile 上下文、存储域、凭据、jobs、插件管理、配置编辑、技能目录及 Session 存储。Web Client 使用标准插件管理详情页。本包不提供应用可执行文件；应用通过受支持的 `dsh` profile 启动。

本 bundle 不会把自己加入其他 profile，也不修改 AFP。关闭后会释放注册、停止接收新工作、取消并排空活动任务，同时保留数据。同一 profile 的第二个 Host writer 会被拒绝；先停止原 Host，再重新获取写入能力。

### 配置外部服务

在所属 profile 的 Cordis overlay 中配置 Provider 条目。`source` 选择 Unsplash 或通用 HTTP JSON 图片来源，包括端点、方法、query/cursor/page-size 字段、响应 JSON Pointer 及允许的媒体 origin。`vision` 指定兼容多图 JSON 的模型和端点。`limits` 控制文件、解码、存储限制，以及请求和候选预算、重试、并发及截止时间。[配置解析器](src/host/config.ts) 是字段与默认值的唯一详细定义；创建任务快照前先解析配置。

`source.endpoint`、可选的 `source.lookupEndpoint` 和 `vision.endpoint` 拒绝内嵌凭据、查询参数及 fragment。视觉服务基础地址没有路径时补全为 `/v1/chat/completions`，以 `/v1` 结尾时追加 `/chat/completions`；其他请求路径保持原样。`source.allowedMediaOrigins` 和 `vision.localOrigin` 必须填写精确 origin，不含路径或末尾斜杠。可选 lookup 端点仅通过来源稳定 ID 刷新媒体定位，不会从第一页重启已过期搜索。

模型设置的连接选项支持以秒调整 `limits.requestTimeoutMs`，并配置 `limits.maxRetryAttempts` 和 `limits.maxVisionOutputTokens`，仅对新任务快照生效。推理模型返回完整 JSON 可能需要更长等待及更大的输出预算。响应以 `finish_reason: length` 结束时会报告 `vision-output-truncated`，包括推理耗尽预算而未返回正文的情况；不会把它作为完整观察保存。超时请求的远端结果未知，仍可能计费，测试接口时可将自动重试设为零。

新任务的 `vision.reasoningEffort` 默认 high，显式级别会保存在请求描述和审核器标识中；“服务默认”保存 `null` 并省略请求参数。旧任务快照中省略的参数保持原义。视觉设置通过 Cordis volatile 引用更新，已受理的任务保持原模型、推理强度和预算。保存显示独立加载状态，返回轻量配置结果；配置未改变时不写入 profile。

`vision.vendorVersion` 记录供应商声明的模型版本；未声明时，已保存请求保留重放限制。模型采样、`limits.maxVisionOutputTokens`、`limits.maxReferenceImages` 或 `limits.maxReferenceBytes` 变化会形成新的审核器标识。正式搜图与裁图使用变更后的审核方法前，需要创建新 candidate 并发布对应 release。已有 release 保留原审核方法。

密钥值保存在 DSH 凭据中。本插件只保存凭据引用，初始名称为 `VISUAL_CURATOR_SOURCE_KEY` 和 `VISUAL_CURATOR_VISION_KEY`；修改 JSON 字段并不会保存密钥。来源和媒体使用有界的公网 HTTPS 请求，并检查重定向与 DNS。显式配置的本地视觉 origin 是本地模型的受支持例外。不提供任意请求脚本、模型指定端点或远端收藏夹写入。

预算限制实际尝试次数、字节和耗时。重试消耗同一任务预算；外部请求中断后保留已预留配额，因为供应商可能已经计费。实现报告费用未知，不强制执行货币额度，也不预测最终账单。

“模型&图库设置”将视觉表单与多账号 Unsplash 浏览分开。“添加账号”在本机独立 Chrome 或 Edge 窗口打开 `https://unsplash.com/login`。在官网完成验证与登录后，Host 仅读取影响 Unsplash API URL 的 Cookie，核验当前用户，再交由 DSH 凭据服务保存。密码留在官网，不读取个人浏览器配置。登录窗口与图库请求使用相同的 User-Agent，导航提交后即开始检测；访客 Cookie 不触发账号校验，官网访问校验未通过时会持续显示原因。点击遮罩保留登录弹窗，取消、关闭按钮或 Escape 请求结束连接。每次登录使用临时配置目录，捕获完成、取消或超时后关闭窗口。“更新会话”核对已保存用户 ID；再次添加已连接的官网身份会更新原有会话，保留账号 ID、凭据引用、备注、列表位置与默认选择，不增加重复卡片。更新会话时若登录了其他身份，会单独提示账号不匹配。配置只保存账号 ID、备注、用户 ID、用户名和凭据引用。`source.provider` 设为 `unsplash`，`source.unsplash.accounts` 保存这些账号描述，`source.unsplash.defaultAccountId` 选择一个搜索账号或以 `null` 使用公开搜索。账号连接与默认选择即时保存。“高级设置”通过弹窗打开原 HTTP JSON 来源，使用 `source.provider: generic`。

图片工作区的“引用图库收藏夹”打开按账号隔离的弹窗，账号栏保持固定高度，内容区域独立滚动；窄屏使用高度受限的横向账号栏。选择收藏夹后读取全部分页，上限为 `limits.maxGalleryReferenceFiles`（默认 10,000）。每个有效分页收到后立即显示，取消的选择在追加分页和重试后保留，只有全部分页成功后才允许登记引用。默认选中可用的非付费图片，预览每次触底追加 `limits.pageSize` 张图片。“取消读取”保留预览并允许重试完整读取。引用沿用当前素材集及正例或反例角色，每批遵守 `maxImportFiles` 且读取最新版本。

确认加入后由 Host 持有引用任务，关闭弹窗、切换素材集或刷新页面不停止后续批次。素材集菜单和工作区显示同一任务的已确认数量及阶段；“停止引用”保留成功结果，未知回执停止后续写入。每个素材集同时仅一个引用任务，执行期间不能分析或归档该素材集。Host 重启将未结束任务标记中断，不自动重放；普通引用不会启动模型。图片列表按当前素材集触底加载，角色总数、已加载数量和本次引入进度分别统计；追加引用不使既有分页失效，失败保留图片并提供重试。进度读取不重复构建完整工作区快照。

图库页面登记远程引用，不下载、转码或保存图片字节。记录保留经过白名单验证的公开预览 URL、账号与来源标识，以及提供方报告的尺寸。分析时以 `image_url` 将这些链接交给视觉 API，模型服务必须能够读取它们。`remote-url-v1` 标识链接描述，不是像素字节摘要。远程观察不伪造字节测量，参考数据包包含链接及重放限制；裁图和字节导出需要已验证的字节图片。已有本地路径和字节导入仍可读取。显式 `gallery-import` API 继续默认使用原字节模式，图库 UI 会提交 `mode: remote-reference`。UI 写入前确认 Host 支持远程登记，旧 Host 会停止操作，避免静默下载图片。

登记过程显示账号核验、逐项引用和保存阶段及处理数量。“取消引用”中止尚未完成的详情请求，并停止后续图片和批次；已开始的原子提交完成后，成功前缀仍保留在素材集中。回执无法确认时停止后续批次，不自动重试。取消、进度和元数据按所属账号及 Session 隔离；离开页面停止轮询并请求取消。

每个账号分别提供收藏夹 Collections 和收藏图片 Bookmarks 视图。私有读取以会话核对保存的用户 ID，成功核验按 `source.unsplash.identityCacheTtlMs` 复用（默认 180000；设为零禁用成功缓存）。只有 API 实例、账号 ID 和预期用户 ID 都相同才能复用，凭据或传输配置变化会更换实例；过期、显式刷新和认证拒绝会让复用失效。字节导入与显式账号校验仍进行新鲜核验，单个等待者取消不会中止其他等待者共享的核验。进入收藏夹后，搜索按图片标题和摄影师覆盖全部元数据分页，清空搜索恢复收藏夹；“全站搜索”仍搜索 Unsplash 全站。适配器兼容数组与 results 对象，continuation 保留页内偏移和 ID 摘要，避免截断额外图片；半页内容变化时必须显式刷新。

图库元数据按账号身份、收藏夹或搜索范围、分页及配置版本缓存，同一浏览器标签页刷新后也可复用。`source.unsplash.cache` 配置 `ttlMs`（默认 300000）、`maxPages`（120）和 `maxBytes`（2097152）。“刷新当前列表”先让该列表分页失效再重新读取。过期分页和旧连接配置不会命中；缓存达到上限时淘汰较早的分页。不缓存图片字节、Cookie 或授权参数；浏览器禁用会话存储时，内存缓存仍遵守相同的分页与字节上限。导入和登录操作始终请求 Host。

上方设置概览可以向上滚走；图库使用完整滚动视口高度，到达顶部留白后保持位置，结果列表独立滚动。紧凑工具栏与左侧全站搜图行对齐，不重复显示账号名称；图库 Tab 使用小图标、浅色选中背景和共享滑动下划线，收藏夹路径与批量选择共用一条紧凑工具栏。加载时使用收藏夹或图片骨架屏，面板高度保持一致。收藏夹和图片列表接近底部时自动追加下一批，保留已有卡片与选择，不显示分页按钮；屏幕外卡片延后绘制。收藏夹引用预览也随滚动逐批显示已枚举的元数据。右键图片或按 Shift+F10 直接打开大图，不显示中间菜单或覆盖图标；共享大图预览使用内置透明图片叠层素材显示加载动画，成功后淡入，失败时可重试，支持 Escape 关闭并返回焦点。“全选已加载”覆盖当前已加载且符合筛选的非付费图片，取消时保留范围外选择。图库导入按 `maxImportFiles` 分批提交并读取新修订号，结果不明时停止后续批次。底部操作栏集中显示目标素材集和引用操作，在窄窗口分成两行。收藏夹引用弹窗复用同一缓存、骨架屏与预览组件。

选择图片及目标素材集，再使用“加入素材集”或“加入并分析”。登记固定来源与账号身份，保留逐图收据并添加正例远程引用，不复制像素；本地路径引用保留原图位置。图库登记使用 references-only，不授权导出图片字节。Unsplash+ 图片保留付费标记，预览不能替代可交付原图。分析与参考数据包复用自动模型档案流程。来源标识 `unsplash` 通过固定风格搜图使用选定账号；没有显式检索词时，档案搜索提示成为召回关键词。初筛、裁图规划和终审均接收固定的匹配提示词与可替代规则分组。搜索裁图沿用已提交源审，终审仍检查实际裁后像素。结果按保存的最终偏好分和稳定图片 ID 排序；读取投影不改写不可变选择，也不调用模型。

Unsplash Web 适配器依据所提供接口包的读取行为与真实响应实现。它需要系统 curl，可通过 `source.unsplash.curlBinary` 配置程序，通过 `source.unsplash.userAgent` 配置请求标识。官网登录使用 `playwright-core` 和已安装浏览器，不下载浏览器。`source.unsplash.login.browser` 可为 `auto`、`msedge` 或 `chrome`；`executablePath` 可指定部署方管理的程序，`timeoutMs`、`launchTimeoutMs` 和 `pollIntervalMs` 限制登录等待、启动与轮询。Host 需要本机图形会话显示该窗口。没有 Python 依赖。每次 API 请求使用独立的临时 Cookie 文件、公网 DNS 检查、HTTPS、响应限制及同源重定向；会话值不进入进程参数或任务 JSON。访问校验与请求共享截止时间。网页接口可以独立于官方 API 变化；会话过期、访问校验及限流会明确报告。连接多个账号不会自动合并配额或轮换身份。

### 建立固定风格

插件详情页使用与 AFP 相同的原生布局：图标、示例、说明、分组可选功能及开关，共十二项。技能包括参考图与风格、风格分析与校准、按风格找图、智能裁图与构图、人工反馈整理、数据集与 Skill 导出。工具分为只读工具、找图与裁图、反馈建议与导出，合计仍为八个 Agent 工具，关闭某组仅撤销该组注册。

设置侧栏、全局面板、会话 Tab 三个页面入口默认关闭，在原生插件详情页启用入口后即可打开工作台。素材集使用原图路径引用，以网格或列表浏览完整画面，按文件名和参考类型筛选；筛选不改变分析输入。紧凑顶栏保留 logo 素材集菜单、模型状态和刷新，搜索框位于图片工作区与模型&图库设置 Tab 上方；Tab 沿用对话主题和滑动下划线。素材集菜单提供“删除当前素材集”和“全部删除训练集”及确认弹窗；批量删除固定确认名单、显示已确认进度，并在首个失败项停止。此前提交的移除仍然保留，重试复用各项操作 ID，确认后新增的训练集不会被删除。删除流程复用既有归档操作并检查显示的修订号，保留原始图片、任务历史和导出资料。删除后选择剩余可用素材集，删除最后一项后显示空工作区；图库导入目标排除已移除的素材集。右侧视觉规则面板撑满整个工作台高度，按维度只读展示当前采用规则，独立滚动，通过完整档案入口调整；收起后焦点返回展开按钮。模型&图库设置占满可用内容宽度，左右保留 24px，窄容器收紧至 16px，并沿用共享 Tab、响应式表单和固定保存行。图库账号导航使用紧凑双行布局和小尺寸默认标签。高级图库与登录表单使用 13px 字段文字和 14px 标题；高级表单限制内容滚动区域并保留操作按钮。弹窗打开时暂停背后的档案边框装饰动画，关闭后恢复。页面使用 DSH 组件、语义主题色和共享折叠动画；关闭入口不会删除数据或停止任务。

本地流程为“引用图片 → 视觉 API 分析 → 自动整理并采用规则 → 按需调整 → 生成参考数据集”。每张参考图在配置的图片与字节限制内分析，跨图归纳接收全部观察和固定判断，代表像素交替覆盖正反例。第二版归纳输出可替代的风格组及默认规则选择。模型档案保留图片依据、选择理由与模型来源，不创建人工确认标签，也不覆盖人工草稿规则。题材信息、缺少依据和冲突的参考项默认停用。用户选择和描述调整保存为不可变版本，重新分析时保留；依据消失时停用对应规则。重新分析失败时保留此前可用档案。

完整分析自动保存模型档案。风格档案弹窗左侧显示整理并选中的规则，右侧联动对应参考图和模型观察；可选调整自动保存，无需逐条人工审核。两栏独立滚动，窄窗口在规则与依据之间切换；底部固定显示保存、导出状态与生成数据集操作。第二版数据包将 style-profile.json、samples.jsonl、references.json、SKILL.md 和带校验和的清单封装为一个 JSON 文件，使用原路径资源引用，不包含图片副本或训练后权重。这类仅引用的参考数据包无需人工发布或数据划分；原有第一版人工监督导出继续使用已发布版本、人工标签和已确认划分。Agent 找图和裁图可在 releaseId 参数中传入有效 modelProfile.id，固定该版本并检查实际候选像素；模型档案仅接受 purpose 为 reference、kind 为 style 或 skill 的导出，训练数据与图片字节权限保持独立。

过程弹窗采用只读对话布局：右侧为已保存的用户输入和有序图片，左侧为模型实际输出。输入进入阅读区时按需读取，与进度轮询独立；较长任务指令可原位展开，完整用户消息、系统提示词和图片身份保留在“输入详情”中。气泡沿用现有聊天主题，图片预览复用会话图库；模型推理直接调用 UI Chat 的 root 范围 `conversation.chat.reasoning.content` Factory，使用共享紧凑 Markdown 与流式渲染；展开和运行标题效果由共享 DisclosureRow 提供。推理与响应原文默认折叠，模型参数放在运行日志中。读取输入不会创建聊天或调用模型。新消息显式关联实际请求，重试保持独立身份；未关联的历史请求单独列出，缺失输入不补造。远程预览仅表示提交的 URL，不代表已核验供应商取得的像素。输入沿用输出的任务和图片授权，可选 requestId 保持旧消息可读且不重写。

不同素材集可并行分析，受 `limits.maxConcurrentAnalyses`（默认 2）限制，并通过共享的 `maxConcurrentRequests` 约束视觉请求；超出名额进入可取消的队列，同一素材集最多存在一个未结束分析。任务服务拒绝受理时，对应任务保存明确失败，后续队列不会丢失。分析期间可自由切换素材集，当前搜索与裁图进度仍会更新。本地图片逐批读取，取消后不再读取后续批次；菜单显示已提交数量，关闭任务对话后 Host 继续执行。

对话按图片观察批次和风格总结追加模型消息，不替换之前的输出。每条消息可展开接口返回的推理文本，已校验 JSON 展示为可读的逐图观察和风格正文，原始响应另行折叠。只有读者停留在消息末尾时才跟随输出；向上滚动保持阅读位置，并提供“回到最新输出”。模型输出与运行日志通过可键盘操作的页签切换，只滚动当前阅读区；从日志返回时恢复正文阅读位置。未完成的终态批次默认折叠，仍可展开查看接口已返回的内容。弹窗使用不透底的主题表面，顶部集中展示状态与保存计数。逐图观察按本批输入编号排列，授权的完整缩略图与文件名、维度图标和正文对齐；窄屏将维度标签放在正文上方。风格归纳分开显示结论、支持与反例图片、建议规则及匹配提示词。没有保存预览时明确显示缺失，不改写模型文字。输入详情默认展示任务指令与发送图片，完整消息和图片身份保留在各自页签。打开的对话按 `processPollIntervalMs`（默认 500 毫秒）刷新，关闭后停止详情读取。新任务的 `vision.supportsStreaming` 默认 true，兼容 SSE 与 JSON 响应；拒绝流式请求的服务需要关闭此选项，不会自动另发付费请求。有界消息正文与过程记录由 `maxProcessTextChars`、`maxProcessEvents` 限制，并随检查点保存，不逐 token 改写 manifest；只展示接口明确返回的内容。

工作台用一条紧凑状态行显示当前准备步骤与分析进度。“分析过程”紧邻主分析按钮，尚无任务时禁用。主分析按钮在运行时禁止重复启动并显示加载动画，完成后用于查看风格档案，并以边框流光高亮；重新分析入口保留在档案弹窗内，减少动态效果的偏好会让边框保持静态。任务记录固定在底部，使用共享折叠动画向上展开高度受限的面板，入口位置保持稳定；紧凑任务行集中展示类型、状态和已保存计数，相邻详情区在排序与分页结果上方展示本地化指标及操作；窄窗口上下排列列表与详情。加载数量、预览说明与分析范围提示位于面板底部。完整风格名称和观察保留在档案弹窗中，次要详情关闭时把空间留给图片。

风格档案使用共享 Modal、较实的主题底色、规则与依据两栏及固定底部操作。素材集预览分页时，档案仍展示相应原图及保存的观察；支持示例与反例依据分开标记。只读侧栏不提供添加、保存、审核或发布控件。

“添加引用”提供统一的“引用本地图片 / 文件夹”和“引用图库收藏夹”入口。本地系统窗口支持单选或多选 JPEG、PNG、WebP 原图，也可引用整个文件夹并包含子目录。取消保留当前素材集和结果；离开页面中止选择窗口，并停止未提交的引用。可选的“按路径引用”菜单接受图片或文件夹路径，方便重复测试；“引用并分析”只在引用成功后启动分析，路径不可读时保留弹窗且不调用模型。原图保留在原位置，不复制到插件存储。插件只保存路径、原图指纹和可复现的处理参数；预览和分析图按需在内存中生成，尺寸由 `previewMaxDimension` 限制。每次读取都验证原图指纹；文件移动、缺失或变更后会明确失败，不复用旧缓存作为证据。视觉 API 接收按路径读取的图片内容，不获得本机文件访问权限。两种选择方式均保存实际原始路径，不上传浏览器选中的图片字节。已有字节导入记录保持可读。

引用结果按 `pageSize` 分页显示原始路径、大小、状态和本地化原因。不支持的文件会跳过，损坏、超限或不可读文件单独报告；`maxLocalReferenceFiles` 限制目录枚举数量。每批遵守 `maxImportFiles` 和 `maxImportBytes`，提交后使用最新修订号；无法确认响应时停止后续批次，关闭页面则停止未提交工作。紧凑网格随可用宽度增加列数，文件名悬浮提示保留完整路径。

1. 创建风格，导入 JPEG、PNG 或静态 WebP 参考图。选择正例、反例或待判断意图，并指定整体偏好或具体维度。只参考色彩的样例不会为构图或主体打标签。混合批次保留成功项并逐项报告拒绝文件。
2. 分析参考图，获取模型观察和待确认规则建议。程序测量、模型估计与不确定性分别保存。在草稿中确认 required 规则、检查支持图和反例，并解决 required 冲突。
3. 创建 candidate，在具备独立标签时进行对比。发布 provisional 或 evaluated release；evaluated 只表示完成了所声明的对比，不代表自动达成质量目标。发布不选择默认版本；默认选择和回退均需显式操作。
4. 创建独立用途修订，指定精确约分比例、匹配的输出像素、安全区和保护内容。搜图与裁图任务始终使用选定 release、用途、recipe、参考图片字节及预算。

### 复核结果和纠正

搜索结果分别保留原图与成图审核。偏好分不能抵消 required 失败；unknown 和技术失败不会成为审美拒绝标签。只有不重复的最终合格图片计入目标，不足结果保留真实停止原因。缺少足够原图像素的预览不能满足成图像素要求。

人工裁图有两次确认：先完成调整，保存并复核真实派生图；再明确允许作为学习样例。关闭预览、下载、接受一批结果或取消拖动都不会产生理想裁图标签。人工保留的合法但带视觉警告图片，与自动合格结果分开标识。系统不通过放大、拉伸或扩图满足不可能的裁剪要求。

反馈默认只作用于当前任务。明确选择纳入当前风格 candidate 后，纠正才可能用于下一草稿；题材不符、本次不需要和 unknown 与风格拒绝分别记录。改判追加新反馈并移动唯一有效头。旧 release 和导出保留原记录。Agent 建议不会变成人工身份确认。

复核队列字段标记不确定判断、技术失败、人工与模型分歧，以及等待人工判读的新来源组。`limits.reviewSampleRate` 还会根据图片摘要可重复地抽取普通通过或拒绝图片；每个任务在启动时固定抽检比例。队列归属不修改反馈或 release，新来源组也不代表已识别出新的语义类别。

### 限定范围和恢复任务

Client 创建的 profile 任务和 Agent 创建的 Session 任务分别拥有归属。授权的 owner 操作需显式打开所属 Session 通道，才能读取其任务、图片或导出。将 Session 结果保存到 profile 样例库会创建独立关联，原 Session 归属保持不变。

离开页面后任务继续执行。取消分析会确认停止请求、打断在途调用并保留已提交结果，排空完成前显示正在取消；主动取消的分析不会自动恢复。系统中断的新分析保留原 runId、配置、截止时间、已花额度及检查点，初始化时创建新 attempt 并继续未处理批次；已提交模型响应从回执重放，不重复调用接口。结果未知的请求保留预留额度，续跑时仍可能再次计费。旧 cancelled 任务保持取消状态。搜图与裁图仍使用显式暂停、恢复及供应商版本检查，卸载行为保持原义。

### 划分、对比和导出

确认 family 成员后，再分配 learning、development 或 holdout。原图、精确重复及其派生图共享 family。尚未确认的近似分组不能证明数据独立；已参与分析或校准的 family 不能成为独立 holdout。holdout 不进入归纳和训练导出；查看其错误并据此修改规则时，需要新建 manifest，将相关 family 移出 holdout。

选择相关来源组并明确确认合并后，重新打开划分表单。合并保存不可变 family 别名和成员确认，原 asset 记录保持不变。旧划分若因合并出现跨集合冲突便不能继续使用，需要创建新划分并将合并组保留在同一集合。

对比保存固定 release/candidate、图片、用途、反馈头、原始计数及分母。召回分母保留全部人工正例，包括待复核、技术失败和未处理状态；精确率统计有人工标签的合格结果。分母为零时显示 unavailable。预算耗尽后仍保存含全部固定输入及明确停止结果的部分报告。仅做图片对比不会生成裁图，也不能证明裁图破坏指标；缺少相应独立裁图监督时，这些指标保持 unavailable。对比不会改变默认 release。

导出支持风格包、classification/preference/crop JSONL 和 Skill Markdown。下载是版本化 JSON 封装：`files` 保存文本内容及 checksum；只有经授权的 with-bytes 导出才在 `resources` 中保存 Base64 媒体字节。文件 checksum 是精确 UTF-8 内容的 SHA-256；业务记录摘要另用带版本的规范 JSON。默认仅导出引用。附带图片字节必须有已记录授权并通过完整性检查；缺失、损坏或未授权字节会使导出失败，不生成被标成完整的缺损包。

Client 的 `reference-analyze` 可选 `buildDataset: true` 启用跨图归纳；省略时保留原逐批分析行为。`export-start` 的 `kind: "style"`、`purpose: "reference"` 可选 `analysisRunId`，要求该任务完整完成，并且分析时的图片、维度意图和人工判断与所选 release 一致。原记录枚举与 schemaVersion 保持不变；版本化档案保存在已有 Run 的 JSON checkpoint 中，原风格导出和人工监督数据格式保持可读。机器观察不会混入 classification/preference/crop 人工监督行。

training 导出只含 learning family，并保留请求时固定的合格人工反馈 ID。后续改判不会重写已有快照。偏好平局和两者均不合适保留原值。生成的 Skill 指明 release 与所需资源；图片不可用时要求报告缺失，且只产生可下载产物。它不修改 Home 指令、不在 Session 中启用、不训练模型，也不包含模型权重。

<a id="model-experience"></a>
## 模型体验

可选工具条目提供有界风格读取、搜图/裁图启动、任务读取、Agent 建议及导出启动/读取，不暴露人工确认、发布、默认切换或分组确认命令。长操作返回任务句柄；启动确认不代表图片合格。工具结果包含安全 ID 和经授权资源引用；辅助视觉请求在插件所属的任务请求日志中保存实际图片顺序、摘要、提示词、模型/版本声明及校验后输出。Session 工具结果关联该任务；派发前仍核对 Session 归属，不写入实验性 Session 记录。

启用工具时，声明会增加模型工具 schema 上下文。本 bundle 不向每次请求注入风格，也不修改 Home 指令。每次视觉调用消耗自身文本和图片预算；前缀缓存行为及供应商精确 token 计费取决于配置的 Provider，本包未测量这些值。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

仅支持已配置 HTTP JSON 来源和兼容多图视觉协议。不提供任意站点爬取、付费原图获取、图像生成、分割、Embedding/向量检索、模型训练或远端收藏写入。系统只审核已召回候选，不能声明完整图库召回。原图质量、许可、导出授权和审美适用性需要用户自行核验。

keyless fixture 验证流程控制和精确图片几何，不验证真实来源/模型部署、供应商账单、广泛视觉质量或用户参考图适用性。只有提供真实端点、响应映射、凭据引用、模型能力和授权样例后，才能验证相应属性。仅做图片评估时，尚无支持的裁图指标保持 unavailable。profile 锁只协调同一台机器的进程，不支持独立主机共享存储的锁协调。
