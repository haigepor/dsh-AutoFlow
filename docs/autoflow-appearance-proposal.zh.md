# AutoFlow 外观设置页方案

[English](autoflow-appearance-proposal.md) | 中文

这是设计方案，配有 [SVG 页面示意图](assets/autoflow-appearance-concept.svg)。页面沿用现有全窗口设置页：左侧导航保持稳定，右侧内容独立滚动。图中的选项用于说明视觉与交互方式，不表示每个选项都已经实现。

![采用图形化选项卡的外观设置页](assets/autoflow-appearance-concept.svg)

## 当前行为与归属

通用设置目前通过 `settings.general.item` 接收 `ui-theme` 提供的亮色/暗色/跟随系统选项和会话正文字号。`ui-theme` 在 Host 用户设置文档中只持久化 `preference` 与 `fontSize`。设置页导航来自注册的 `settings.section` 条目，因此 `ui-theme` 可提供新的 `appearance` 分区，无需在设置页外壳中硬编码位置。`ui-layout` 将解析后的主题应用到文档，功能包 CSS 使用主题语义令牌。

先迁移已有的主题与字号控件，可以保持当前的存储方式和即时生效行为。通用设置随后停止渲染这两行，保留其他无关设置。外观分区沿用其他设置分区的左侧高亮、折叠图标对齐、内容宽度、标题间距和亮暗背景。

## 视觉结构

| 分组 | 示意选项 | 交互与范围 |
| --- | --- | --- |
| 主题 | 跟随系统、浅色、深色 | 三张缩略窗口预览。描边和角标表示已保存偏好；跟随系统按设备当前明暗状态解析。 |
| 颜色预设 | 默认、暖珊瑚、极简灰、暗夜、玫瑰花园、潮光、日落霞光、森林低语 | 色块预览调色板；每套预设需要亮暗两组令牌和明确的重置行为。名称与配色目前是设计候选。 |
| 字体 | 跟随系统、无衬线、衬线 | 预览实际回退字体栈。字体家族与现有会话正文字号分别设置。 |
| 圆角 | 自动、直角、微圆、标准、柔和 | 每张卡片画出对应的角形。比例化调整组件圆角，圆形和胶囊形保持原形。 |
| 密度 | 紧凑、默认、宽松、超大 | 用线条预览纵向间距，不暗中改变字号。 |
| 侧边栏 | 内嵌、浮动、独立 | 缩略布局解释位置差异。该设置属于侧边栏和布局，需要先设计折叠与标题栏行为才能开放操作。 |
| 布局 | 默认、紧凑、全屏布局 | 预览内容比例，不改变功能导航。 |
| 内容宽度 | 全宽、居中 | 在当前窗口尺寸下直观显示宽度取舍。 |
| 方向 | 从左到右、从右到左 | RTL 需要组件和语言环境全面适配；目前只作为概念展示。 |

所有分组使用一致的选中表达：细强调色描边、角上的小勾选标记、SVG 缩略图下方的名称，以及清晰的悬浮与键盘焦点状态。缩略图负责传达选项区别，不作无意义装饰。窄窗口下卡片减少列数并换行，右侧内容滚动，侧边栏保持稳定。选中状态还需要原生单选语义或 `aria-checked`，不能只靠颜色表达。

## 实现顺序

1. 由 `ui-theme` 注册 `appearance` 设置分区，把现有主题选择与字号控件迁入，保持原持久化与即时更新逻辑；同一改动中移除通用设置中的注册，保证控件只出现一次。
2. 定义持久化取值、默认值、亮暗令牌映射、跨系统安全的字体回退栈和可逆的重置行为后，再增加颜色预设与字体家族。颜色预设与亮色/暗色/跟随系统分别保存。
3. 将圆角和密度定义为共享主题比例，通过语义令牌更新，而非在各组件散落覆写。分别审查亮暗模式下的菜单、卡片、输入框、弹窗、焦点环以及降低透明度设置。
4. 将侧边栏形式、页面布局、内容宽度和方向作为独立的布局与无障碍改动。导航、响应式、窗口拖拽以及 RTL 文本和键盘行为未准备好之前，不开放成可操作选项。

图形化候选项在拥有真实状态前，不应在运行页面中伪装成已生效的配置：可以暂不显示，或明确标识为预览。现有两项设置继续即时保存；后续选项遵循相同的状态同步与重连行为。重置仅恢复本组的已文档化默认值，不影响其他分组。

## 验收标准

- 切换跟随系统、浅色和深色后，重新打开设置仍保留偏好；跟随系统会响应设备明暗变化。
- 每套颜色预设在亮暗模式下均可读，选中、悬浮、禁用、焦点、错误和菜单状态使用一致的配色。
- 字体与圆角预览和实际页面一致；窄窗口、折叠导航、Windows/macOS 标题栏及降低透明度设置均可用。
- 后续选项只有具备持久化、双语文案、键盘操作和聚焦浏览器证据后才算实现。
