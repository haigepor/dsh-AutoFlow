# 视觉策展任务准备与风格匹配

[English](guide.md) | 中文

## 变更

新的模型画像找图和裁剪任务从当前启用规则编译执行说明，并检查终图风格满足比例。limits.minStyleMatchRatio 默认 0.75，未知证据需要复核。调整后的画像不再执行旧匹配提示或自动沿用旧检索词。已有任务和人工发布版本保留固定行为。新增 recipe 字段及请求版本不支持在旧插件中恢复新任务。

## 迁移

1. 在工作台选择当前画像，创建或选择输出用途。先“检查任务”，再“开始找图”；Agent 可在原启动工具前调用 visual_task_prepare。
2. 旧分析提示不再符合调整后的规则时，明确填写检索词。limits.minStyleMatchRatio 仅影响新任务，表示规则满足比例，不是概率。
3. 根据保存的入选身份识别交付图片，不以 pass 判断代替。通过工具卡片及原授权通道打开 Session 任务。
4. 降级前完成或取消新任务。保留存储数据，不重写旧 recipe，也不在旧插件中恢复新策略任务。核对最终入选与结束原因符合工作台计数。
