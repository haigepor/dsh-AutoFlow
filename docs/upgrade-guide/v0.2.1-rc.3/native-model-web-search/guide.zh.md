# 模型原生联网搜索

[English](guide.md) | 中文

## 变更

此前 `web_search` 始终使用配置的网页搜索后端。现在，匹配到原生搜索能力的模型会使用自身的提供方和凭据，除非该模型条目设置了 `nativeWebSearch: false`。未知模型继续使用配置的后端，不支持的协议不能启用原生搜索。模型发现阶段捕获的提供方默认值与用户覆盖值分别保存。

原生调用记录 `web/native-search-llm-request`。已有会话仍可读取；不认识此必需事件的旧读取方会拒绝包含它的新日志。[持久化变更确认](../../../persistence-changes/2026-10-28-native-model-web-search.zh.md)记录了保持版本不变的决定。

## 迁移

1. 打开包含原生搜索的日志前，将会话读取方与应用一起升级。
2. 在“模型”页编辑模型，检查“模型能力 > 原生联网搜索”。若要保持原来的搜索后端，取消勾选，该模型会保存 `nativeWebSearch: false`；“恢复自动匹配”移除手动覆盖值。
3. Codex 订阅文本模型也可在订阅模型编辑中调整同一选项。搜索复用选中账号，无需 DeepSeek 密钥。搜索支持现在参与账号能力分组；发现后若已保存的 `dsh-cap:…` 别名不可用，请重新选择当前能力组。上游模型 ID 不变。
4. 保存并重新打开模型，确认勾选状态。搜索应返回来源 URL；提供方拒绝时会明确显示，不会切换到其他凭据。
