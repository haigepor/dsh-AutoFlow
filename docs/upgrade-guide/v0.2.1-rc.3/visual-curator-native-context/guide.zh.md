# 视觉策展原生上下文设置

[English](guide.md) | 中文

## 变更

新原生任务继承注册模型的上下文容量、输出与推理默认值，插件输出限制不再覆盖它们。原生压力策略要求时，profile 的 Compaction 服务在归纳前压缩观察文本，每次压缩调用计入任务预算。已有冻结任务与显式备用 HTTP 保留原参数。

## 迁移

1. 在设置 → 模型中，为所选视觉模型分别设置上下文容量和输出默认值；两者是独立参数。
2. 保持原生 token 计量启用。视觉策展复用可见的 Compaction 后端；聊天使用私有作用域时，插件挂载隔离的原生 Basic 实例。可选 `compaction` 设置沿用原生 Basic 策略字段。选择并保存模型，新原生配置使用 `vision.useModelDefaults: true`。
3. 新建小规模分析并检查保存的原生请求，容量与参数应匹配所选路由。已有失败快照保留原上限，不会原地迁移。
4. 需要 HTTP 输出覆盖的部署继续使用 `vision.backend: compatible`。原生压缩服务缺失、容量无效或摘要失败时，明确报告错误并保留已保存观察。
