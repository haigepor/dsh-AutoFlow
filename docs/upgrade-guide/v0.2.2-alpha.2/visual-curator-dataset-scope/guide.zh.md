# 视觉策展数据集范围

[English](guide.md) | 中文

## 变更

视觉策展 0.2.9 将自动风格画像和已完成的参考数据集归属于训练集及应用 profile。由会话创建的数据集可在该 profile 的其他会话和已配置模型中选择。旧数据集保留原有文件和校验和，不再要求切换到创建它的会话。不同训练集继续分开，应用 profile 隔离、私有图片和会话任务日志权限继续检查。

此前依靠会话区分训练数据访问范围的用户，应改用不同的应用 profile。

## 迁移

1. 完成正在运行的任务，更新视觉策展至 0.2.9 或包含它的新桌面版，再重启应用。若旧桌面的插件更新按钮在发送请求前失败，先更新桌面端。
2. 打开对应训练集，再进入「数据集」。已有完整数据包无需重新分析或改写存储即可继续使用。
3. 打开「按此画像找图」，选择所需的历史完整包和已配置模型，再启动任务。任务固定该包的参考图、规则和提示词；仅观察包不能作为完整找图标准。
4. 需要独立访问范围的训练集放在不同的 `dsh` profile 中。本次更新不迁移会话日志、图片或其他 profile。
