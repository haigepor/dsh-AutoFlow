# Visual Curator 观察数据包

[English](guide.md) | 中文

## 变更

Visual Curator 支持单独导出正例或反例观察。这类格式 2 数据包保存 `sampleScope`，不包含可执行的风格规则，不能作为按风格找图的数据集。未标记 `sampleScope` 的已有数据包仍表示完整风格参考包，原记录保持不变。

数据集列表响应新增 `sampleScope` 以及正例、反例和待定数量。逐图观察读取支持 `sampleRole` 筛选，分页令牌仅用于对应的筛选条件。旧版插件读取器不支持新增的观察记录。

## 迁移

1. 等待当前任务结束，同时更新 Visual Curator Host 与客户端，重启 DSH 后刷新页面。无需修改数据目录或重新分析。
2. 自定义数据集客户端需要读取新增数量，并在后续分页中传递相同的 `sampleRole`。省略导出范围或观察筛选时，仍使用完整参考包或全部观察。
3. 在风格档案中生成仅含一种角色的观察数据包，核对角色数量。按风格找图时选择完整参考包。读取已保存的观察数据包时继续使用新版读取器。
