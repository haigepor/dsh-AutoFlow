# Visual Curator 找图排除与预览

[English](guide.md) | 中文

## 变更

新找图任务在 `fixed.searchExclusions` 中保存精确参考图及历史入选排除策略，并在检查点保存排除决定。Unsplash 按跨账号、跨尺寸链接不变的来源和照片 ID 识别同图；本地图还比较已验证的字节摘要。同一授权素材集中此前已入选的图片和已知参考图在视觉评审前跳过。未保存该策略的已有任务保留原行为，续传时也不改变；历史匹配结果不会改写。

预览并发独立于找图预算，使用 `source.unsplash.previewConcurrency` 配置，为 1 到 4 的整数，默认 2。保存的任务配置包含该字段；旧版严格读取器无法读取全部新配置及排除检查点。

## 迁移

1. 等待当前工作结束，同步更新 Visual Curator Host 和客户端，重启 DSH 后刷新页面。更新后创建的任务继续使用新版读取器，无需手动编辑数据目录。
2. 新建找图任务以采用固定排除策略，可在已保存计数中查看 `excludedNegative`、`excludedReference` 和 `excludedPrevious`。排除图不消耗视觉评审次数，已发生的检索和下载仍消耗原预算；已有任务及其续传不会获得后续参考图变化。
3. 默认保留预览并发，按部署条件需要再调整。打开图片列表，确认图片加载期间任务控件仍可响应。完整预览和模型评审地址保留原分辨率，列表缩略图使用较小版本。
