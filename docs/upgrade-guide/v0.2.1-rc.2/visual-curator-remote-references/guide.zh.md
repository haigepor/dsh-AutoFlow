# 视觉策展图库引用使用远程 URL

[English](guide.md) | 中文

## 变更

图库页面登记公开预览链接，不再逐张下载和归一化选中的图片。新图片版本使用 `remote-reference`，并以 `remote-url-v1` 标识链接描述摘要；旧插件构建无法读取这些新记录。已有字节导入与原始路径引用仍可读取，不需要转换。

视觉 API 接收远程 `image_url`，模型服务必须能够访问白名单内的 Unsplash CDN 链接。远程引用不能建立本地字节校验、实测尺寸或逐字节重放保证；参考数据集包含链接和该限制，裁图与字节导出仍需字节图片。

成功的账号核验按 `source.unsplash.identityCacheTtlMs` 复用，默认 180000 毫秒；显式刷新、凭据变化及认证失败要求重新核验。字节导入保留新鲜核验。

引用任务由 Host 持有，关闭弹窗和刷新页面后仍可读取进度；Host 重启将未完成任务标记中断，不自动重放。新增任务 manifest 不转换已有素材或 Session 记录。降级前停止引用并等待最终回执，保留完整数据目录备份。

新分析任务保存自动恢复意图、有界过程消息及固定配置；新任务默认 high 并请求流式输出，已有快照保持原参数。系统中断只自动恢复带有恢复意图的分析，主动取消和旧 cancelled 任务保持停止。旧插件解析器无法读取新增任务字段，降级时需保留匹配的数据备份。

## 迁移

1. 如果需要回退旧插件，在建立远程引用前备份该配置的 `~/.dsh/profiles/<profile>/visual-curator` 目录。更新插件，并重启现有 Host 以加载新后端；已有图片不需要转换。
2. 如果部署要求每次请求都核验账号，在其 `visual-curator` 配置行设置 `config.source.unsplash.identityCacheTtlMs: 0`，继续为不同账号保存独立描述和凭据引用。
3. 引用一个收藏夹，确认弹窗显示逐项进度和“取消引用”，取消后保留成功前缀；再确认分析请求将远程 URL 发送给配置的模型服务，参考数据包包含 `remoteSource` 及 `pixelDigest: null`。
4. 创建这些记录后继续使用新插件。恢复旧构建时必须一起恢复对应目录备份，不要删字段或把远程记录改写成本地像素记录。

5. 确认分析中修改推理强度后，旧任务仍使用原级别；启动另一素材集并取消其中一项，再重启 Host，只有带恢复意图的中断分析继续，并保留已完成观察。接口不支持 high 或流式时，可选服务默认或关闭流式输出。
