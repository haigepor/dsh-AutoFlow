# 视觉策展图片目录

[English](guide.md) | 中文

## 变更

视觉策展可将图片文件保存在当前配置的 `visual-curator` 目录以外。当前配置通过 `image-storage-location:v1` 保存存储位置和迁移进度；图片记录仍使用相对路径。旧版插件不会读取该位置，因此无法访问已经迁移的图片库。继续使用默认目录的配置无需迁移。

## 迁移

1. 结束或停止正在执行的图片任务。打开“图片存储”，选择一个空的本地文件夹，核对目标目录后开始迁移。请保持源磁盘和目标磁盘连接。
2. 后台任务会复制图片、校验 SHA-256、保存新位置，再清除已校验的旧副本。可以关闭弹窗。意外关闭后，重启同一配置即可继续；如果显示失败，先修复磁盘或文件问题，再点击“继续迁移”。
3. 确认显示“图片目录迁移完成”，检查生效目录，并打开一张已保存原图和历史成品。任务元数据及当前配置的写入锁仍位于原配置目录。
4. 降级到不支持自定义目录的插件前，先通过此弹窗迁移回当前配置原有的 `visual-curator` 目录，并确认完成。迁移尚未完成时，不要手动编辑位置清单或删除任一目录。
