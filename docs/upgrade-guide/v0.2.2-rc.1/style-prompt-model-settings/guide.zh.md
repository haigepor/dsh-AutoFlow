# 风格提示词使用原生模型设置

[English](guide.md) | 中文

## 变更

风格提示词此前在分析和文本生成中传入插件自己的输出上限和温度。现在仅提交选中的提供方与模型，与 AFP 图片策展的原生模型默认模式一致。原生 LLM 解析模型的输出上限、温度和推理设置。

插件仍接受现有 profile patch 中的 `maxOutputTokens` 和 `temperature`，但在解析配置时丢弃它们。已保存的任务历史保留原始请求设置。

## 迁移

1. 打开**设置 → 模型**，在风格提示词使用的各个模型上配置输出上限及其他参数。
2. 可从 `cordis.patch.yml` 或启动 overlay 的 `style-prompt` 条目中删除 `maxOutputTokens` 和 `temperature`。保留这些键时，现有配置仍可加载。
3. 重启应用后，显式重新运行分析或提示词节点。新任务保存的请求会使用选中的原生模型设置，旧失败任务保持原状。截断响应仍会校验失败，系统不会自动重试。
